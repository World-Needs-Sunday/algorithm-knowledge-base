## 题目描述

Marton 的朋友 Cero 有一个由 $N$ 个正整数组成的数组。

首先 Cero 会在黑板上写下这个数组中的第一个数字。接下来他会在之前写下的所有数的左边或者右边写下一个数字。重复以上操作得到一个序列。

请注意，根据上述方法构造出的两个序列相同当且仅当每一个数字写下的顺序完全相同。例如，`1,1` 可能和 `1,1` 不同——前者的第二个数在第一个数的左边，后者的第二个数在第一个数的右边。

求这些数组成的所有序列中，最长严格递增子序列长度的最大值 $M$，以及所有最长严格递增子序列长度等于 $M$ 的序列中，最长严格递增子序列个数的总和。考虑到答案可能很大，只需输出对 $10^9 + 7$ 取模的值。

### 输入格式

第一行包含一个正整数 $N$。

接下来的一行包含 $N$ 个正整数，表示按顺序给出的这个数组的各个元素。

### 输出格式

仅一行，输出最长子序列长度以及总个数模上 $10^9 + 7$ 的值。

### 数据规模与约定

- 对于 30% 的数据，满足 $N \le 20$
- 对于 50% 的数据，满足 $N \le 10^3$
- 对于 100% 的数据，满足 $N \le 2 \times 10^5$，数组中的每个元素 $\le 10^9$

## 解题思路

### 第一步：构造转化（本题最核心的难点）

题目描述的构造过程是：先写第一个数，之后每个数只能放在当前序列的**最左端或最右端**。直接枚举所有可能的序列是不可行的（共有 $2^{n-1}$ 种），必须找到等价的数学刻画。

**关键观察**：每个可能的序列，都可以看作是从原序列中选择一个子序列，将该子序列**翻转**后拼接到剩余部分的左侧。

```
原序列:       A1  A2  A3  A4  A5  A6  A7
                        ↓
选择子序列:        A2     A4     A6  (选中的元素按原序)
                        ↓
翻转子序列:   A6     A4     A2         (逆序)
                        ↓
拼接得到:     A6  A1  A4  A3  A2  A5  A7
              ↑↑↑↑↑                    ↑↑↑↑↑
              翻折过来的部分              未翻折的部分
```

换句话说，每个可能的序列 = 一个"翻转前缀" + 一个"原始后缀"。翻转前缀是原序列某个子序列的逆序，原始后缀是剩下的元素按原序排列。

### 第二步：LIS 结构分析

有了上述转化，我们分析可能序列的 LIS（最长严格上升子序列）结构：

- 翻转前缀部分（从原序列中选出的子序列的逆序）在原序列中是**严格下降**的（因为逆序后上升 = 原序下降）
- 原始后缀部分在原序列中是**严格上升**的
- 一个可能序列的 LIS，由"翻转前缀中贡献的上升段"和"原始后缀中贡献的上升段"拼接而成

更精确地说：对于原序列的某个位置 $i$，可能序列的 LIS 可以表示为：

- 一个以 $i$ 结尾（向左方向）的**严格下降子序列**（贡献翻转前缀部分）
- 一个以 $i$ 开头（向右方向）的**严格上升子序列**（贡献原始后缀部分）
- 两段在位置 $i$ 处衔接（$i$ 同时属于两段，因此长度减 1）

因此，最长 LIS 长度为：

$$M = \max_{i=1}^{n} \left( \text{len}_a[i] + \text{len}_b[i] - 1 \right)$$

其中：
- $\text{len}_a[i]$ = 以 $i$ 结尾的、向左方向的最长严格下降子序列长度（即在原序列中从 $i$ 向左看，$A[i]$ 能接在哪些比它大的元素后面）
- $\text{len}_b[i]$ = 以 $i$ 开头的、向右方向的最长严格上升子序列长度

### 第三步：方案数计算

对于每个满足 $\text{len}_a[i] + \text{len}_b[i] - 1 = M$ 的位置 $i$，设 $\text{cnt}_a[i]$ 和 $\text{cnt}_b[i]$ 分别为对应方向的方案数，则：

$$\text{cnt}(i) = \text{cnt}_a[i] \times \text{cnt}_b[i] \times 2^{n - M}$$

其中 $2^{n-M}$ 的含义是**不在 LIS 中的元素**的放置方式：

**情况 1：$A_1$ 属于 LIS**

- 不在 LIS 中的元素有 $n - M$ 个
- 每个元素可以翻到左边或不翻（2 种选择）
- 方案数：$2^{n-M}$

**情况 2：$A_1$ 不属于 LIS**

- 不在 LIS 中的元素有 $n - M$ 个（包括 $A_1$）
- $A_1$ 必须翻到左边（只有 1 种选择，因为它不在 LIS 中却必须出现在翻转前缀中）
- 其他 $n - M - 1$ 个元素各有 2 种选择
- 衔接元素（同时属于两段的那个元素）不是 $A_1$，所以它可以跟着任一序列，翻不翻都可以，额外乘以 2
- 方案数：$1 \times 2^{n-M-1} \times 2 = 2^{n-M}$

两种情况方案数相同，均为 $2^{n-M}$，因此统一乘以 $2^{n-M}$ 即可。

> **注意**：需要去重——同一个位置 $i$ 可能被 $\text{cnt}_a$ 和 $\text{cnt}_b$ 以不同方式计入，但由于我们按位置 $i$ 遍历，且 $i$ 是 LIS 的衔接点（唯一确定），因此不存在重复计数。

### 第四步：树状数组优化

求 $\text{len}_a$、$\text{cnt}_a$、$\text{len}_b$、$\text{cnt}_b$ 时，不能使用贪心+二分的 LIS 做法（因为贪心只维护一个最优解，无法统计方案数）。应使用**树状数组**维护"以值 $v$ 结尾的最长长度及方案数"。

- **正序树状数组**（求向右的 LIS）：从右向左扫描，查询 $< A[i]$ 的最大长度及方案数
- **倒序树状数组**（求向左的 LDS）：从右向左扫描，查询 $> A[i]$ 的最大长度及方案数（通过值域翻转实现）

由于值域可达 $10^9$，需要先**离散化**。

## 逐行代码解析

### 树状数组结构

```cpp
struct treearr
{
    vector<int> len;    // len[idx] = 树状数组位置 idx 处维护的最大长度
    vector<int> cnt;    // cnt[idx] = 对应的方案数
    int sz, ans_len, ans_cnt;
```

这个树状数组同时维护两个信息：**最大长度**和**对应的方案数**。与普通树状数组不同，`add` 操作不是简单累加，而是"取 max 并合并计数"。

```cpp
    void add(int idx, int num, int t_cnt)
    {
        if (num > len[idx]) len[idx] = num, cnt[idx] = t_cnt;
        else if (num == len[idx]) cnt[idx] = (cnt[idx] + t_cnt) % mod;
    }
```

- 如果新来的 `num` 更大，直接覆盖，方案数替换为 `t_cnt`
- 如果 `num` 等于当前最大，方案数累加

```cpp
    void insert(int idx, int num, int t_cnt)
    {
        while (idx <= sz)
        {
            add(idx, num, t_cnt);
            idx += lowbit(idx);
        }
    }
```

标准树状数组单点更新：沿 `idx += lowbit(idx)` 向上更新所有覆盖该位置的节点。

```cpp
    void get(int idx)
    {
        ans_len = 0, ans_cnt = 0;
        while (idx)
        {
            if (len[idx] > ans_len)
            {
                ans_len = len[idx];
                ans_cnt = cnt[idx];
            }
            else if (len[idx] == ans_len) ans_cnt = (ans_cnt + cnt[idx]) % mod;
            idx -= lowbit(idx);
        }
    }
```

前缀查询：沿 `idx -= lowbit(idx)` 向下查询 $[1, \text{idx}]$ 范围内的最大长度及方案数。同样地，遇到更长的就替换，遇到等长的就累加。

### 主函数

```cpp
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    int n;
    cin >> n;
    vector<int> fac(n + 1);
    fac[0] = 1;
    for (int i = 1; i <= n; i++) fac[i] = (fac[i - 1] << 1) % mod;
```

预处理 $2$ 的幂次表 `fac[i]`（即 $2^i \bmod \text{mod}$），用于后续方案数计算中的 $2^{n-M}$。

```cpp
    vector<int> A(n + 1);
    for (int i = 1; i <= n; i++) cin >> A[i];
    vector<int> tmp(A);
    sort(tmp.begin() + 1, tmp.end());
    tmp.erase(unique(tmp.begin() + 1, tmp.end()), tmp.end());
```

**离散化**：排序 + 去重，将值域从 $[1, 10^9]$ 压缩到 $[1, m]$（$m$ 为不同值的个数）。离散化后才能用树状数组维护。

```cpp
    treearr arr_a(tmp.size());  // 正序：维护向右的严格上升子序列
    treearr arr_b(tmp.size());  // 倒序：维护向左的严格下降子序列
    vector<int> len_a(n + 1), cnt_a(n + 1);
    vector<int> len_b(n + 1), cnt_b(n + 1);
```

两个树状数组分别维护两个方向：
- `arr_a`：查询 $< A[i]$ 的最大长度（向右 LIS），通过值域翻转实现"严格小于"
- `arr_b`：查询 $< A[i]$ 的最大长度（向左 LDS），直接用原值

```cpp
    for (int i = n; i >= 1; --i)
    {
        A[i] = lower_bound(tmp.begin() + 1, tmp.end(), A[i]) - tmp.begin();
        int a = tmp.size() - A[i] + 1, b = A[i];
```

**从右向左扫描**：先离散化 $A[i]$，然后计算两个查询位置：
- `a = m - A[i] + 1`：值域翻转，使得查询 `[1, a-1]` 等价于查询"值 $> A[i]$"（向左的严格下降）
- `b = A[i]`：原值，查询 `[1, b-1]` 等价于查询"值 $< A[i]$"（向右的严格上升）

```cpp
        arr_a.get(a - 1);
        len_a[i] = arr_a.ans_len + 1;
        cnt_a[i] = arr_a.ans_cnt ? arr_a.ans_cnt : 1;
        arr_a.insert(a, len_a[i], cnt_a[i]);
```

**求向左的严格下降子序列**（即翻转前缀的贡献）：
- `arr_a.get(a - 1)`：查询值 $> A[i]$ 的元素中，最大长度及方案数
- `len_a[i] = ans_len + 1`：在之前最优解基础上延伸 1
- `cnt_a[i]`：若查询结果为空（`ans_cnt == 0`），说明 $A[i]$ 是第一个，方案数为 1
- `arr_a.insert(a, ...)`：将当前元素插入树状数组

```cpp
        arr_b.get(b - 1);
        len_b[i] = arr_b.ans_len + 1;
        cnt_b[i] = arr_b.ans_cnt ? arr_b.ans_cnt : 1;
        arr_b.insert(b, len_b[i], cnt_b[i]);
    }
```

**求向右的严格上升子序列**（即原始后缀的贡献）：同理，用原值 $b = A[i]$ 查询。

```cpp
    int ans_len = 0, ans_cnt = 0;
    for (int i = 1; i <= n; i++)
    {
        int len = len_a[i] + len_b[i] - 1;
        int cnt = (((((long long)cnt_a[i] * cnt_b[i]) % mod) * fac[n - len]) % mod);
        if (len > ans_len) ans_cnt = cnt, ans_len = len;
        else if (len == ans_len) ans_cnt = (ans_cnt + cnt) % mod;
    }
    cout << ans_len << ' ' << ans_cnt;
    return 0;
}
```

**合并答案**：遍历每个位置 $i$，计算拼接后的 LIS 长度 `len = len_a[i] + len_b[i] - 1`（减 1 因为位置 $i$ 被两段各算了一次），方案数 `cnt = cnt_a[i] * cnt_b[i] * 2^(n-len)`。

取所有位置中长度最大的方案数之和。注意乘法用 `long long` 中间转换避免溢出。

## 复杂度分析

### 时间复杂度

| 操作 | 复杂度 | 说明 |
|---|---|---|
| 离散化（排序+去重） | $O(n \log n)$ | 对 $n$ 个元素排序 |
| 逆序扫描（求 len/cnt） | $O(n \log n)$ | 每个位置 2 次树状数组查询 + 2 次更新，每次 $O(\log n)$ |
| 合并答案 | $O(n)$ | 遍历所有位置 |
| **总计** | $O(n \log n)$ | 离散化 + 树状数组主导 |

### 空间复杂度

| 数据 | 空间 | 说明 |
|---|---|---|
| 离散化数组 `tmp` | $O(n)$ | 去重后的值域 |
| 两个树状数组 | $O(n)$ | 各 $n+1$ 大小的 `len` 和 `cnt` |
| DP 数组 | $O(n)$ | `len_a`, `cnt_a`, `len_b`, `cnt_b` 各 $n+1$ |
| 幂次表 `fac` | $O(n)$ | 预处理 $2^0$ 到 $2^n$ |
| **总计** | $O(n)$ | 线性空间 |

## 常见陷阱与注意事项

1. **构造转化是本题核心**
   - 题目描述的"左右放数"操作等价于"选子序列翻转后拼接"
   - 这个转化是整道题的突破口，没有这个观察无法继续

2. **不能用贪心+二分求 LIS**
   - 贪心+二分只维护最优解的末尾值，无法统计方案数
   - 必须用树状数组同时维护最大长度和方案数

3. **值域翻转技巧**
   - 求严格下降子序列时，将值 $v$ 映射为 $m - v + 1$，这样"查询 $> v$"就变成了"查询 $< (m-v+1)$"，统一用树状数组的前缀查询

4. **$A_1$ 的特殊性**
   - $A_1$ 是第一个被写入的数，它决定了"翻折"的起点
   - 方案数推导中 $A_1$ 是否属于 LIS 影响中间过程，但最终两种情况方案数相同（均为 $2^{n-M}$）

5. **离散化必须去重**
   - `sort` + `unique` 保证相同值映射到同一位置
   - 严格上升/下降要求"不等于"，离散化后用 `b - 1` / `a - 1` 查询即可

6. **乘法溢出**
   - `cnt_a[i] * cnt_b[i]` 两个 `int` 相乘可能溢出，必须先转 `long long`
   - 代码中 `((((long long)cnt_a[i] * cnt_b[i]) % mod) * fac[n - len]) % mod` 逐步取模

7. **从右向左扫描**
   - 因为我们需要"以 $i$ 结尾向左"和"以 $i$ 开头向右"的信息，而树状数组查询的是"之前已插入的元素"
   - 从右向左扫描时，已插入的是 $i$ 右边的元素，查询结果正好是"以 $i$ 为起点的向右信息"

## 对比与扩展

| 方法 | 时间 | 空间 | 能否统计方案数 | 适用场景 |
|---|---|---|---|---|
| 朴素 DP | $O(n^2)$ | $O(n)$ | 能 | 小数据，$n \le 5000$ |
| 贪心+二分 | $O(n \log n)$ | $O(n)$ | 不能 | 只需长度，不需方案数 |
| **树状数组（本算法）** | $O(n \log n)$ | $O(n)$ | **能** | 需要长度+方案数 |
| 线段树 | $O(n \log n)$ | $O(n)$ | 能 | 同树状数组，常数稍大 |

### 扩展

- **LIS 方案数问题**：本题的树状数组技巧可直接用于"求 LIS 长度及方案数"的标准问题
- **LCS 方案数**：类似的"维护最大值+计数"思路也可用于最长公共子序列方案数
- **区间 DP 中的计数**：许多需要同时维护最优值和方案数的 DP 问题都可以借鉴这种"树状数组同时维护 len 和 cnt"的技巧
