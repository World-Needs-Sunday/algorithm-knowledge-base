## 题目描述

在平面直角坐标系第一象限有一个矩形，左下角 $(0,0)$，右上角 $(n,m)$。进行 $q$ 次切割操作：

- **纵向切割**（$op=1$）：沿直线 $x=k$ 切割，将矩形在 $x$ 方向进一步分割
- **横向切割**（$op=2$）：沿直线 $y=k$ 切割，将矩形在 $y$ 方向进一步分割

每次切割贯穿整个区域。每次切割完成后，求当前所有小矩形中面积的最大值。

### 输入格式

- 第一行：$n, m, q$（$1 \le n, m \le 10^9$，$1 \le q \le 5 \times 10^5$）
- 接下来 $q$ 行：每行 $op, k$（$op=1$ 时 $1 \le k < n$；$op=2$ 时 $1 \le k < m$）
- 保证不会在同一位置切割两次

### 输出格式

输出 $q$ 行，第 $i$ 行表示第 $i$ 次切割后的最大小矩形面积。

---

### 数据范围

- $1 \le n, m \le 10^9$，$1 \le q \le 5 \times 10^5$
- $op = 1$ 时 $1 \le k < n$；$op = 2$ 时 $1 \le k < m$
- 保证不会在同一位置切割两次

## 样例

> 本题为 ICPC 2026 Wuhan 赛题，官方样例暂未取得。以下示例由本文档自造，并已用「最大横向间隙 × 最大纵向间隙」的独立精确解法验证。

### 样例输入

```
5 4 3
1 2
2 3
1 4
```

### 样例输出

```
12
9
6
```

- 第 1 次切割（$x = 2$）：横向间隙为 $2, 3$，纵向间隙为 $4$，最大面积 $3 \times 4 = 12$。
- 第 2 次切割（$y = 3$）：横向最大间隙仍为 $3$，纵向间隙变为 $3, 1$，最大面积 $3 \times 3 = 9$。
- 第 3 次切割（$x = 4$）：横向间隙变为 $2, 2, 1$，纵向最大间隙仍为 $3$，最大面积 $2 \times 3 = 6$。

## 一、解题思路：核心观察——二维降为一维

### 1.1 切割的贯穿性

纵向切割 $x=k$ 贯穿整个高度，横向切割 $y=k$ 贯穿整个宽度。这意味着：

- 所有纵向切割线 + 左右边界 $x=0, x=n$ → 把宽度 $n$ 分成若干「宽度段」
- 所有横向切割线 + 上下边界 $y=0, y=m$ → 把高度 $m$ 分成若干「高度段」
- 任意小矩形 = 一个宽度段 $\times$ 一个高度段

### 1.2 最大面积 = max_x $\times$ max_y

**上界**：任意小矩形宽 $\le$ max_x，高 $\le$ max_y，面积 $\le$ max_x $\times$ max_y。

**可达性**：取最大宽度段对应的竖条和最大高度段对应的横条，因为所有切割线贯穿整个区域，这两个条带一定相交，交出的小矩形面积恰好 $= \text{max\_x} \times \text{max\_y}$。

因此问题拆成两个独立的一维问题：分别维护 $x$ 方向和 $y$ 方向的最大间隔长度。

---

## 二、正序的困难

正序模拟每次切割时，需要：
1. 找到 $k$ 落在哪个宽度段中
2. 删除旧段，插入两个新段
3. 动态维护全局最大值

这需要平衡树或线段树，代码量大且容易出错。

---

## 三、逆序思考：切割变合并

### 3.1 核心转化

| 正序 | 逆序 |
|---|---|
| 切割：一个间隔分成两个 | 撤销：两个相邻间隔合并成一个 |
| 间隔分裂，最大值可能减小 | 间隔合并，最大值只增不减 |

逆序过程中，间隔只会合并，**全局最大间隔单调不减**，因此只需一个变量记录最大值即可，无需任何复杂数据结构维护全局最大。

### 3.2 算法流程

1. 读入所有 $q$ 次操作
2. 收集所有切割坐标，分别加入 $X$ 和 $Y$ 数组（含边界 $0$ 和 $n$/$m$）
3. 排序 $X$ 和 $Y$，得到所有切割都存在时的最终状态
4. 初始化并查集，每个「缝隙」$i$ 对应 $X[i-1]$ 到 $X[i]$，长度为 $X[i] - X[i-1]$
5. 从 $i = q$ 到 $1$ 逆序处理：
   - 先记录答案：$ans[i] = \text{max\_x} \times \text{max\_y}$
   - 撤销第 $i$ 次操作：在对应坐标数组中二分找到切割点下标 $idx$，合并缝隙 $idx$ 和 $idx+1$
   - 更新对应方向的 max
6. 正序输出 $ans[1]$ 到 $ans[q]$

## 四、「缝隙」与并查集

### 4.1 缝隙定义

以 $x$ 方向为例，排序后的坐标数组 $X = [0, 3, 7, 10]$，缝隙编号从 1 开始：

| 缝隙编号 | 范围 | 长度 |
|---|---|---|
| 1 | $[0, 3]$ | 3 |
| 2 | $[3, 7]$ | 4 |
| 3 | $[7, 10]$ | 3 |

### 4.2 撤销切割 = 合并缝隙

如果切割点 $k$ 在 $X$ 中的下标是 $idx$，那么它左侧缝隙编号是 $idx$，右侧是 $idx+1$。撤销这条切割线就是合并缝隙 $idx$ 和 $idx+1$。

用并查集维护：每个缝隙是一个集合元素，集合的「大小」就是这段缝隙的总长度。合并时长度相加，与新 max 比较更新。

## 五、代码逐行解析

### 5.1 全局变量

```cpp
int n, m, q, max_x, max_y;
vector<int> X, Y, op, k;           // 坐标数组、操作类型、切割位置
vector<unsigned long long> ans;     // 答案（面积最大 10^18，用 ull）
vector<int> a, b, a_sz, b_sz;      // 并查集父数组 + 大小数组
```

面积最大 $10^9 \times 10^9 = 10^{18}$，`int` 最大约 $2.1 \times 10^9$，必须用 64 位整数。

### 5.2 并查集核心

```cpp
int find(int i, vector<int>& t)
{
    if (t[i] != i)
        t[i] = find(t[i], t);   // 路径压缩
    return t[i];
}

int unity(int i, vector<int>& t, vector<int>& sz)
{
    int a_i = find(i, t);
    int b_i = find(i + 1, t);
    sz[a_i] += sz[b_i];    // 合并大小
    t[b_i] = a_i;          // 挂到左侧
    return sz[a_i];        // 返回合并后的大小
}
```

只做路径压缩，不做按秩合并。本题数据量下完全足够。

### 5.3 初始化

```cpp
void init()
{
    X.emplace_back(0);  X.emplace_back(n);   // 边界
    Y.emplace_back(0);  Y.emplace_back(m);
    op.assign(q + 1, 0);
    k.assign(q + 1, 0);
    ans.assign(q + 1, 0);
}
```

坐标数组先放入边界 $0$ 和 $n$（或 $m$），后续再追加所有切割坐标。

### 5.4 并查集初始化

```cpp
void init_t(vector<int>& t, vector<int>& sz, vector<int>& xy, int& mmax)
{
    t.assign(xy.size() + 1, 0);
    sz.assign(xy.size() + 1, 0);
    for (int i = 1; i < xy.size(); i++)
    {
        t[i] = i;
        sz[i] = xy[i] - xy[i - 1];   // 缝隙长度
        mmax = max(mmax, sz[i]);     // 初始最大间隔
    }
}
```

缝隙 $i$ 对应坐标 $xy[i-1]$ 到 $xy[i]$。此时所有切割线都存在，缝隙最细碎，max 是初始值。

### 5.5 逆序处理

```cpp
for (int i = q; i >= 1; --i)
{
    ans[i] = (unsigned long long)max_x * max_y;   // 先记录当前答案
    if (op[i] == 1)     // 纵向切割，撤销 x 方向
    {
        int idx = lower_bound(X.begin(), X.end(), k[i]) - X.begin();
        max_x = max(max_x, unity(idx, a, a_sz));
    }
    else                // 横向切割，撤销 y 方向
    {
        int idx = lower_bound(Y.begin(), Y.end(), k[i]) - Y.begin();
        max_y = max(max_y, unity(idx, b, b_sz));
    }
}
```

**关键细节**：先记录答案，再撤销操作。因为逆序循环开始时的状态对应「正序执行完第 $q$ 次操作后的状态」，记录 $ans[q]$ 后撤销第 $q$ 次操作得到第 $q-1$ 次操作后的状态，以此类推。

`lower_bound` 二分找到切割点 $k$ 在排序后坐标数组中的位置 $idx$，合并缝隙 $idx$ 和 $idx+1$。

## 六、完整小例子

### 输入

```
n=10, m=10, q=3
op=1, k=3    (纵向切 x=3)
op=2, k=5    (横向切 y=5)
op=1, k=7    (纵向切 x=7)
```

### 收集坐标并排序

- $X = [0, 3, 7, 10]$（边界 + 纵向切割）
- $Y = [0, 5, 10]$（边界 + 横向切割）

### 初始缝隙（所有切割都存在）

$x$ 方向缝隙：$[0,3]=3$，$[3,7]=4$，$[7,10]=3$ → max\_x = 4
$y$ 方向缝隙：$[0,5]=5$，$[5,10]=5$ → max\_y = 5

### 逆序处理

| 逆序步 | 撤销操作 | 合并后 | max_x | max_y | ans[i] |
|---|---|---|---|---|---|
| i=3 | 撤销 x=7 | 合并缝隙2+3 → 长度7 | 7 | 5 | $4 \times 5 = 20$ |
| i=2 | 撤销 y=5 | 合并缝隙1+2 → 长度10 | 7 | 10 | $7 \times 5 = 35$ |
| i=1 | 撤销 x=3 | 合并缝隙1+2 → 长度10 | 10 | 10 | $7 \times 10 = 70$ |

### 正序输出

```
70    (第1次切割后)
35    (第2次切割后)
20    (第3次切割后)
```

**验证第 1 次切割后**：只有 $x=3$ 一刀，$x$ 缝隙 $[0,3]=3, [3,10]=7$ → max\_x=7；$y$ 缝隙 $[0,10]=10$ → max\_y=10；面积 $= 7 \times 10 = 70$ ✓

## 七、复杂度分析

| 操作 | 时间 |
|---|---|
| 收集坐标并排序 | $O(q \log q)$ |
| 初始化并查集 | $O(q)$ |
| 逆序处理（二分 + 并查集） | $O(q \log q)$（二分 $O(\log q)$，并查集近似 $O(1)$） |
| **总计** | **$O(q \log q)$** |

空间复杂度 $O(q)$。对于 $q \le 5 \times 10^5$，完全通过。

## 八、常见陷阱与注意事项

1. **面积溢出**：$n, m$ 最大 $10^9$，乘积最大 $10^{18}$，必须用 `unsigned long long` 或 `long long`，不能用 `int`
2. **op 方向不要搞反**：$op=1$ 是纵向切割 $x=k$，影响 $x$ 方向；$op=2$ 是横向切割 $y=k$，影响 $y$ 方向
3. **坐标数组必须加边界**：$X$ 要包含 $0$ 和 $n$，$Y$ 要包含 $0$ 和 $m$，否则首尾缝隙会丢失
4. **缝隙编号与坐标下标的关系**：切割点 $k$ 在排序数组中的下标是 $idx$，合并的是缝隙 $idx$ 和 $idx+1$
5. **逆序记录答案的时机**：先记录当前 $max\_x \times max\_y$，再撤销当前操作。如果顺序搞反，答案会对应错误的状态
6. **题目保证切割线不重复**：所以每个切割点只会被撤销一次，二分查找一定能找到且唯一
7. **按秩合并非必须**：本题只加路径压缩即可，数据量下完全足够

## 九、核心思想总结

> **一句话**：二维切割问题降维为两个独立的一维问题，正序切割变逆序合并，用并查集维护缝隙合并，只需一个变量记录最大间隔。
>
> 三层思维跳跃：
> 1. **降维**：贯穿性切割 $\Rightarrow$ 二维 $\to$ 两个一维，最大面积 $= \text{max\_x} \times \text{max\_y}$
> 2. **离线逆序**：正序分裂 $\to$ 逆序合并，最大间隔单调不减 $\to$ 只需一个变量
> 3. **离散化 + 并查集**：大坐标 $\to$ 排序离散化为缝隙 $\to$ 并查集 $O(1)$ 合并
>
> 这道题是「离线逆序 + 并查集」的经典应用，展示了如何通过改变处理顺序将动态分裂问题转化为静态合并问题。
