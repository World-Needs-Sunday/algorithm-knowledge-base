## 题目描述

给定一个长度为 $n$ 的数组 $a$。你可以执行任意次操作（可以 0 次）：

选择下标 $i$（满足 $2 \le i \le n-1$），要求 $a_{i-1}$ 和 $a_{i+1}$ **奇偶性相同**。把 $a_i$ 修改为：

$$a_i \leftarrow a_{i-1} - a_i + a_{i+1}$$

求经过任意次操作后，能得到的**字典序最小**的数组。

### 输入格式

多组测试用例。

- 第一行：$t$（$1 \le t \le 10^4$）测试用例数量
- 每组：
  - 第一行：整数 $n$（$3 \le n \le 2 \times 10^5$）
  - 第二行：$n$ 个整数 $a_1, a_2, \ldots, a_n$（$-10^9 \le a_i \le 10^9$）

保证所有测试用例的 $n$ 总和不超过 $2 \times 10^5$。

### 输出格式

每组输出最终字典序最小的数组。

## 解题思路

### 第一步：三个基础观察

**观察 1：两个端点永远不动。** 操作只改写中间位置，$a_1$ 与 $a_n$ 从头到尾不变。$a_1$ 恰好是字典序比较的第一个分量，它已固定，所以目标等价于让 $a_2$ 到 $a_n$ 这一段的字典序尽量小。

**观察 2：每个位置的奇偶性不变。** 合法条件保证 $a_{i-1} + a_{i+1}$ 是偶数，新值 $a_{i-1} - a_i + a_{i+1}$ 与 $-a_i$ 同余，故与旧值同奇偶。但奇偶只是必要条件，不能直接刻画所有可达状态。

**观察 3：操作是自逆的。** 对同一位置连做两次恢复原状。因此只需问"哪些状态彼此连通"，不必关心操作顺序。

### 第二步：核心转化——换到差分数组上看

**为什么想到差分**：操作公式同时牵扯相邻三项，而合法条件比较的却是相距为 2 的两项。"改动一个值、条件看跨位邻居"是差分的典型场景。

设差分 $d_j = a_{j+1} - a_j$，共 $n-1$ 项。给定 $a_1$，原数组与差分一一对应：$a_k = a_1 + \sum_{j=1}^{k-1} d_j$。

**操作在差分上的效果**：一次操作只改 $a_i$。但 $a_i$ 同时是 $d_{i-1}$ 的右端点和 $d_i$ 的左端点，所以 $a_i$ 一变，两个差分都必须重算：

$$d'_{i-1} = a'_i - a_{i-1} = a_{i+1} - a_i = d_i$$
$$d'_i = a_{i+1} - a'_i = a_i - a_{i-1} = d_{i-1}$$

即：**一次操作等价于差分数组上交换相邻的 $d_{i-1}$ 与 $d_i$**。

**合法条件翻译**：$a_{i-1}$ 与 $a_{i+1}$ 同奇偶 $\iff$ $d_{i-1} + d_i$ 为偶 $\iff$ $d_{i-1}$ 与 $d_i$ 同奇偶。

于是问题完全等价于：**每次可以交换差分数组中相邻且奇偶性相同的两项（任意多次），求能得到的最优差分序列。**

### 第三步：可达状态刻画——极大同奇偶连续段

**不变量**：交换双方同奇偶，交换后每个位置上数的奇偶不变，所以差分的"逐位奇偶模式"永不改变。据此把差分切成若干**极大同奇偶连续段**（段内奇偶全同、相邻段奇偶不同）：

- 每段占据的位置集合永远固定（段边界两侧奇偶不同，永远无法交换越界）
- 每段内数字的多重集守恒
- 段内任意相邻两项同奇偶，交换随时合法；相邻交换足以实现段内任意排列（冒泡原理）

**定理**：差分序列 $d'$ 可达，当且仅当它与 $d$ 的奇偶模式相同，且每个极大同奇偶段上的多重集相同。

### 第四步：字典序最小化

**a 的字典序比较 $\iff$ d 的字典序比较**：设两个候选差分的第一个不同位置是 $k$，则两边前 $k-1$ 项前缀和相等，第 $k$ 处前缀和之差恰为 $d_k$ 与 $d'_k$ 之差。

**逐段独立取升序**：各段占据的位置集合固定且互不重叠，互不干扰。固定多重集放到固定位置上，字典序最小的放法是**升序排序**。

**最终结论**：把差分数组按极大同奇偶连续段切开，每段内部升序排序，再用固定的 $a_1$ 逐项累加还原，即为字典序最小的答案。

### 存储约定

本实现不另开差分数组，而是把原数组 A 原地改造成差分，并整体右移一位：

| 阶段 | A[1] | A[2] 到 A[n] |
|---|---|---|
| 读入后 | $a_1$ | 原始 $a$ 值 |
| 原地做差后 | $a_1$（不变） | 相邻差分 |
| 分段排序后 | $a_1$（不变） | 每段升序的差分 |
| 前缀和后 | $a_1$（原样输出） | 答案 $a_2$ 到 $a_n$ |

A[1] 兼任哨兵与种子，A[0] 恒为 0 使做差时第一项无需特判。

## 逐行代码解析

### 原地做差（从右往左）

```cpp
for (int i = n; i >= 1; i--) A[i] -= A[i - 1];
```

**方向是正确性的关键**：算位置 $i$ 的差分时，左邻位置必须还保存着原始 $a_{i-1}$。若从左往右做，左邻已被改成差分，算出的会变成二阶差分。从右往左则保证每个左邻仍是原始值。

### 分段查找与排序

```cpp
for (int i = 2; i <= n;)
{
    int j = i;
    while (j + 1 <= n && ((A[i] & 1) == (A[j + 1] & 1))) j++;
    sort(A.begin() + i, A.begin() + j + 1);
    i = j + 1;
}
```

- **起点是下标 2 而非 1**：A[1] 是冻结的 $a_1$，绝不能卷进排序
- **判奇偶用位运算 `& 1`**：C++ 中负数取模得负，用 `% 2 == 1` 会把两个负奇数误判为不同奇偶
- **用段首元素代表整段奇偶**：段内必然全同，比较段首即可
- 找到段 $[i, j]$ 后直接 `sort` 升序排序

### 前缀和还原输出

```cpp
for (int i = 1; i <= n; i++)
{
    A[i] += A[i - 1];
    cout << A[i] << ' ';
}
cout << '\n';
```

从 A[1]（即 $a_1$）出发，从左到右累加：位置 $k$ 输出 $a_1 + \sum_{j=1}^{k-1} d_j$，即新的 $a_k$。每段步长和守恒保证了所有墙（含 $a_n$）自动回到原值。

## 复杂度分析

### 时间复杂度

| 操作 | 复杂度 | 说明 |
|---|---|---|
| 原地做差 | $O(n)$ | 从右到左一次扫描 |
| 找段 + 排序 | $O(n \log n)$ | 所有段排序总量不超过对整个差分排一次序 |
| 前缀和还原 | $O(n)$ | 从左到右一次扫描 |
| **总计** | $O(n \log n)$ | 排序主导 |

### 空间复杂度

| 数据 | 空间 | 说明 |
|---|---|---|
| 数组 A | $O(n)$ | 长度 $n+1$，原地四用 |
| **总计** | $O(n)$ | 线性空间 |

## 常见陷阱与注意事项

1. **做差方向必须从右往左**
   - 若从左往右做，左邻已被改成差分，算出的变成二阶差分，全盘皆错

2. **找段起点是下标 2 而非 1**
   - A[1] 是冻结的 $a_1$，卷进排序会破坏端点不变性

3. **判奇偶必须用位运算 `& 1`**
   - C++ 中 `-3 % 2` 得 `-1`，用 `% 2 == 1` 会把负奇数误判为"非奇数"
   - `(x & 1)` 对正负数都正确：奇数得 1，偶数得 0

4. **全程使用 `long long`**
   - 差分绝对值可达 $2 \times 10^9$（超出 `int` 范围）
   - 前缀和累计可达 $10^{14}$ 量级

5. **排序对象是差分，不是原数组**
   - 划分依据是差分的数值奇偶，与符号、大小无关（$-3$ 与 $5$ 同为奇数，$0$ 与 $-8$ 同为偶数）

6. **划分一次即可，不需要迭代重找**
   - 段内元素本来就同奇偶，排序只是段内置换，不改变任何位置上的奇偶，段边界不变

7. **不能在原数组上直接按逐位奇偶贪心**
   - 反例：$a = (0, 1, 4)$，差分 $(1, 3)$ 全奇一段。$a_2$ 只能取 1 或 3，并非任意奇数。真正的约束是"段的多重集"，必须先转差分再分段

## 对比与扩展

| 方法 | 时间 | 空间 | 特点 |
|---|---|---|---|
| **差分分段排序（本算法）** | $O(n \log n)$ | $O(n)$ | 差分转化 + 分段独立排序 |
| 暴力 BFS | $O(\text{状态数})$ | 指数级 | 枚举所有可达状态，不可行 |
| 原数组逐位贪心 | $O(n)$ | $O(n)$ | 似是而非，无法处理段的多重集约束 |

### 扩展

- **差分思想的应用**：将"修改一个值"转化为"交换两个差分"，是差分数组的经典技巧。类似思想可用于区间操作、回文构造等问题
- **奇偶不变量**：许多操作问题的合法性条件可以转化为奇偶约束，进而转化为"同奇偶连续段内自由排列"的模型
- **字典序最小化**：固定多重集的字典序最小排列就是升序排序，这一结论在许多贪心问题中反复出现
