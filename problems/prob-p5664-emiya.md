## P5664 Emiya 家今天的饭

## 一、题目描述

Emiya 共掌握 $n$ 种**烹饪方法**，会使用 $m$ 种**主要食材**做菜。每道菜使用恰好一种烹饪方法与恰好一种主要食材。

$a_{i,j}$ 表示使用烹饪方法 $i$ 和主要食材 $j$ 能做出的**不同菜的道数**。

从所有菜中选出一个**非空子集**构成一桌饭，要求：

1. **至少做一道菜**（$k \ge 1$，$k$ 为选出的菜数）
2. **每道菜的烹饪方法互不相同**（每种烹饪方法至多用一次）
3. **每种主要食材至多在一半的菜中被使用**，即对每种食材 $j$：$c_j \le \lfloor \frac{k}{2} \rfloor$，其中 $c_j$ 为使用食材 $j$ 的菜数

求满足所有要求的搭配方案数，对质数 $998244353$ 取模。

### 输入格式

第一行两个整数 $n, m$。

接下来 $n$ 行，每行 $m$ 个整数，第 $i+1$ 行的 $m$ 个数依次为 $a_{i,1}, a_{i,2}, \cdots, a_{i,m}$。

### 输出格式

一行一个整数，表示所求方案数对 $998244353$ 取模的结果。

### 数据范围

- $1 \le n \le 100$
- $1 \le m \le 2000$
- $0 \le a_{i,j} < 998244353$

---

## 二、样例

### 样例 1

**输入：**
```
2 3
1 0 1
0 1 1
```

**输出：**
```
3
```

**解释：** 所有只有 1 道菜的方案都不合法（因为唯一食材占比 $1 > \lfloor 1/2 \rfloor = 0$）。合法的 3 种方案都是 2 道菜且食材不同：(1,1)+(2,2)、(1,1)+(2,3)、(1,3)+(2,2)。

### 样例 2

**输入：**
```
3 3
1 2 3
4 5 0
6 0 0
```

**输出：**
```
190
```

**解释：** 做 2 道菜有 100 种方案，做 3 道菜有 90 种方案，合计 190。

---

## 三、解题思路

### 核心洞察一：先去掉 Yazid 条件——乘法原理

暂时忽略"每种食材至多占一半"的约束，只考虑：

- 每种烹饪方法至多用一次
- 可以不选

对第 $i$ 种烹饪方法，局部选择有：

- **完全不用**：$1$ 种
- **选一道菜**：选一个食材 $j$，有 $a_{i,j}$ 种具体菜，共 $\sum_{j=1}^{m} a_{i,j} = s_i$ 种

因此第 $i$ 行共有 $s_i + 1$ 种选择。各行独立，由乘法原理：

$$
\text{总方案（含空集）} = \prod_{i=1}^{n} (s_i + 1)
$$

> ⚠️ 注意：是 $s_i + 1$ 不是 $s_i$，"不用"也算一种选择。也不是 $2^{s_i} - 1$，因为"烹饪方法互不相同"限定每行最多选一道菜。

---

### 核心洞察二：超标食材至多只有一个

这是整道题最关键的观察。

**反证**：假设存在两种食材 $j_1$ 和 $j_2$ 都超标，即 $c_{j_1} > \lfloor k/2 \rfloor$ 且 $c_{j_2} > \lfloor k/2 \rfloor$，则：

- 若 $k$ 为偶数：$c_{j_1} + c_{j_2} \ge 2 \cdot (k/2 + 1) = k + 2 > k$
- 若 $k$ 为奇数：$c_{j_1} + c_{j_2} \ge 2 \cdot ((k-1)/2 + 1) = k + 1 > k$

但每道菜只含一种主要食材，所以 $c_{j_1} + c_{j_2} \le k$，矛盾。

**结论：一个方案中，最多只有一种食材超标。**

这条定理的价值在于：**不合法方案可以按"哪种食材超标"分成互不相交的 $m$ 类**，因此可以直接相加，不需要复杂的容斥系数。

设 $S_j$ 为"食材 $j$ 超标"的方案数，则：

$$
\text{合法方案} = \text{总方案} - 1 - \sum_{j=1}^{m} S_j \pmod{q}
$$

其中 $-1$ 是去掉空集。

---

### 核心洞察三：超标 = 差值大于 0

对固定的食材 $j$，定义差值：

$$
d = c_j - (k - c_j) = 2c_j - k
$$

- $c_j$：含食材 $j$ 的菜数
- $k - c_j$：不含食材 $j$ 的菜数

**结论：$c_j > \lfloor k/2 \rfloor \iff d > 0$**

证明（奇偶分情况）：

- $k$ 偶：$\lfloor k/2 \rfloor = k/2$，$c_j > k/2 \iff 2c_j > k \iff d > 0$
- $k$ 奇：$\lfloor k/2 \rfloor = (k-1)/2$，$c_j > (k-1)/2 \iff 2c_j > k-1 \iff 2c_j \ge k+1 \iff d > 0$

**为什么这一步是决定性的？** 原本判断超标需要同时知道 $k$ 和 $c_j$ 两个量（二维状态），现在只需一个差值 $d$（一维状态）。DP 的状态维度直接塌缩了一半。

---

### 核心洞察四：差值 DP 的设计

固定食材 $j$ 后，对第 $i$ 种烹饪方法，有三种选择：

| 选择 | 对差值 $d$ 的影响 | 权重（方案数） |
|------|-------------------|---------------|
| 完全不用第 $i$ 种烹饪方法 | $0$ | $1$ |
| 用它做一道**含 $j$** 的菜 | $+1$ | $a_{i,j}$ |
| 用它做一道**不含 $j$** 的菜 | $-1$ | $s_i - a_{i,j}$ |

差值 $d$ 的范围是 $[-n, n]$（因为烹饪方法互不相同，总菜数 $k \le n$，故 $|d| \le k \le n$）。

整体偏移 $n$，用下标 $k' = d + n \in [0, 2n]$ 存储（避免负下标）。

**状态定义：**

$$
dp[i][k'] = \text{处理完前 } i \text{ 种烹饪方法，偏移后差值下标为 } k' \text{ 的方案数}
$$

**初始状态：**

$$
dp[0][n] = 1 \quad \text{（什么都没选，} d=0\text{，一种方案）}
$$

**转移方程：**

$$
\begin{aligned}
dp[i][k'] &+= dp[i-1][k'] \quad &\text{（不用第 } i \text{ 种）} \\
dp[i][k'] &+= dp[i-1][k'-1] \times a_{i,j} \quad &\text{（用且含 } j\text{，} d+1\text{）} \\
dp[i][k'] &+= dp[i-1][k'+1] \times (s_i - a_{i,j}) \quad &\text{（用且不含 } j\text{，} d-1\text{）}
\end{aligned}
$$

**食材 $j$ 超标的方案数：**

$$
S_j = \sum_{k'=n+1}^{2n} dp[n][k']
$$

即 $d > 0$ 的所有方案数之和。

---

### 最终答案

$$
\text{答案} = \left( \prod_{i=1}^{n} (s_i + 1) - 1 - \sum_{j=1}^{m} S_j \right) \bmod 998244353
$$

注意负数处理：$((ans \bmod q) + q) \bmod q$。

---

## 四、逐行代码解析

```cpp
#include<bits/stdc++.h>
using namespace std;
const long long q = 998244353;
long long ans = 1;
vector<vector<long long>> A, dp;
vector<long long> sum_n;
```

- `q`：模数 $998244353$
- `A[i][j]`：烹饪方法 $i$ + 食材 $j$ 的菜的道数
- `sum_n[i]`：第 $i$ 行的总和 $s_i = \sum_{j=1}^{m} a_{i,j}$
- `dp[i][k']`：前 $i$ 种烹饪方法、偏移后差值下标为 $k'$ 的方案数

```cpp
void init(int n,int m)
{
    ans = 1;
    A.assign(n + 1, vector<long long>(m + 1, 0));
    sum_n.assign(n + 1, 0);
    dp.assign(n + 1, vector<long long>(2 * n + 2, 0));
}
```

初始化数组。注意 `dp` 的第一维是 $n+1$（烹饪方法数），第二维是 $2n+2$（偏移后差值范围 $[0, 2n]$）。

```cpp
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            cin >> A[i][j];
            A[i] %= q;
            sum_n[i] = (A[i][j] + sum_n[i]) % q;
        }
    }
```

读入矩阵，边读边取模，同时计算每行和 `sum_n[i]`。

```cpp
    for (int i = 1; i <= n; i++) ans = (ans * (sum_n[i] + 1)) % q;
```

计算**含空集的总方案数**：$\prod (s_i + 1)$。注意是 $s_i + 1$（"不用"也算一种选择）。

```cpp
    dp[0][n] = 1;
```

DP 初值：什么都没选时，差值 $d=0$（偏移后下标为 $n$），方案数为 $1$。

```cpp
    for (int j = 1; j <= m; j++)
    {
        for (int i = 1; i <= n; i++)
        {
            for (int k = 0; k <= 2 * n; k++)
            {
                dp[i][k] = dp[i - 1][k];
                if (k != 0) dp[i][k] = (dp[i][k] + (dp[i - 1][k - 1] * A[i][j]) % q) % q;
                if (k != 2 * n) dp[i][k] = (dp[i][k] + (dp[i - 1][k + 1] * ((sum_n[i] - A[i][j] + q) % q)) % q) % q;
            }
        }

        for (int i = n + 1; i <= 2 * n; i++) ans -= dp[n][i];
    }
```

对每种食材 $j$ 独立跑一遍 DP：

1. **不用第 $i$ 种烹饪方法**：`dp[i][k] = dp[i-1][k]`
2. **用且含食材 $j$**：差值 $+1$，从 $k-1$ 转移过来，权重 $A[i][j]$
3. **用且不含食材 $j$**：差值 $-1$，从 $k+1$ 转移过来，权重 $s_i - a_{i,j}$

注意 `(sum_n[i] - A[i][j] + q) % q`：减法后加 $q$ 再取模，避免负数。

跑完 $n$ 行后，把 $d > 0$（下标 $n+1$ 到 $2n$）的方案数从答案中减去。

```cpp
    ans -= 1;
    while (ans < 0) ans += q;
    cout << ans;
```

最后去掉空集（$-1$），处理负数后输出。

> 💡 关于 `dp` 不复用清零的说明：代码中 `dp` 没有在每个 $j$ 之间清零，但依然正确。原因是第 0 行始终保持 `dp[0][n] = 1`，而第 $1..n$ 行每轮都被完整重算（赋值而非累加）。这是结构上的巧合，更稳妥的写法是每轮重置或使用滚动数组。

## 五、复杂度分析

### 时间复杂度：$O(n^2 m)$

- 外层枚举食材：$O(m)$
- 中层枚举烹饪方法：$O(n)$
- 内层枚举差值状态：$O(n)$
- 总运算量：$m \times n \times 2n = O(n^2 m)$

代入最大数据：$2000 \times 100 \times 200 \approx 4 \times 10^7$ 次简单运算，1 秒内轻松通过。

### 空间复杂度：$O(n^2)$

- `dp` 数组：$(n+1) \times (2n+2)$ 个 `long long`，约 $100 \times 200 \times 8 \text{B} \approx 160 \text{KB}$

**可优化：** 由于 `dp[i]` 只依赖 `dp[i-1]`，可以用滚动数组把空间降到 $O(n)$。

## 六、常见陷阱与注意事项

1. **总方案漏了"不用"**  
   第 $i$ 种烹饪方法的局部选择是 $s_i + 1$，不是 $s_i$。"完全不用"也算一种选择。

2. **DP 初值写成 0**  
   `dp[0][n] = 1` 而不是 0。"一道菜都不选"本身是一种方案，初值是计数不是布尔。

3. **dp 第一维写错**  
   DP 是沿烹饪方法（$n$）推进，第一维必须是 $n+1$，不是 $m+1$。$m$ 是外层循环次数，不是 DP 阶段数。

4. **权重写错**  
   "含 $j$"的权重是 $a_{i,j}$，"不含 $j$"的权重是 $s_i - a_{i,j}$。不要写成 $s_i \times (m-1)$ 之类毫无依据的式子。权重必须能在题面里逐字对应。

5. **累加区间反了**  
   超标对应 $d > 0$，即**下标大于 $n$**（$n+1$ 到 $2n$），不是下标 $1$ 到 $n$。加了偏移之后，"下标"和"差值"是两个概念，不要混淆。

6. **$s_i - a_{i,j}$ 可能为负**  
   模意义下的减法要加 $q$ 再取模：`(sum_n[i] - A[i][j] + q) % q`。

7. **最终答案可能为负**  
   多次做减法后 `ans` 可能变成负数，最后要用 `(ans % q + q) % q` 修正。

8. **空集只减一次**  
   空集的 $d=0$（下标 $n$），不会被任何 $S_j$ 包含，所以最后的 $-1$ 只需要减一次。

9. **$k=1$ 时必然不合法**  
   只有 1 道菜时，唯一的食材占比 $1 > \lfloor 1/2 \rfloor = 0$，必然超标。这是样例 1 中单菜方案全不合法的原因。

10. **超标食材至多一个**  
    这是容斥的前提，也是这道题最核心的观察。没有这个结论，就无法把不合法方案简单相加。

---

## 七、一句话总结

> **"每种食材至多占一半"通过"超标者至多一个"变成了可加的容斥项；再通过"含 $j$ 菜数 $-$ 不含 $j$ 菜数 $> 0$"把二维条件塌缩成一维差值 DP。前者给了容斥的合法性，后者给了 DP 的可行性——两个观察缺一不可。**
