## 题目描述

（Codeforces Round 1135 (Div. 2) D 题，来源经用户确认）

给定正整数 $n$ 和 $m$。

一个划分是一个由 $m$ 个正整数组成的数组 $p$，满足 $p_1+p_2+\cdots+p_m=n$。

对于任意长度为 $n$ 的数组 $b$ 和一个划分 $p$，定义 $f(b,p)$ 为一个长度为 $m$ 的数组 $c$，其中：

- $c_1$ 是 $b$ 的前 $p_1$ 个元素之和；
- $c_2$ 是接下来的 $p_2$ 个元素之和；
- $\cdots$
- $c_m$ 是最后 $p_m$ 个元素之和。

对于长度为 $n$ 的数组 $d$，令 $e$ 为将 $d$ 反转后得到的数组。如果 $f(d,p)=f(e,p)$，则称划分 $p$ 是 $d$ 的一个特殊划分。

给定一个长度为 $n$ 的数组 $a$。你需要回答 $q$ 个独立的询问。对于每个询问，给定两个整数 $i$ 和 $v$。令 $a_i:=a_i+v$，然后输出数组 $a$ 的特殊划分数量。由于答案可能很大，请输出答案对 $10^9+7$ 取模后的结果。

注意，询问是独立的，也就是说，每次询问之后，$a$ 都会恢复到原始值。

### 输入格式

每个测试点包含多组测试数据。第一行包含测试数据组数 $t$（$1\le t\le 10^4$）。接下来是各组测试数据的描述。

每组测试数据的第一行包含三个整数 $n$、$m$ 和 $q$（$1\le m\le n\le 2\cdot 10^5$，$1\le q\le 2\cdot 10^5$）——分别是数组 $a$ 的长度、划分的长度和询问数量。

第二行包含 $n$ 个整数 $a_1,a_2,\dots,a_n$（$|a_i|\le 10^9$）。

接下来的 $q$ 行，每行包含两个整数 $i$ 和 $v$（$1\le i\le n$，$|v|\le 10^9$）。

保证所有测试数据中 $n$ 的总和以及 $q$ 的总和都不超过 $2\cdot 10^5$。

### 输出格式

对于每个询问，输出一个整数——该询问对应的数组 $a$ 的特殊划分数量，对 $10^9+7$ 取模。

### 数据范围

- $1\le t\le 10^4$；$1\le m\le n\le 2\cdot 10^5$；$1\le q\le 2\cdot 10^5$；
- $|a_i|\le 10^9$；$|v|\le 10^9$；
- 所有测试数据的 $\sum n\le 2\cdot 10^5$、$\sum q\le 2\cdot 10^5$。

## 解题思路

### 一、题目在问什么

给定数组 $a$ 和划分长度 $m$。「划分」就是把 $a$ 按顺序切成 $m$ 段；「特殊划分」要求**把 $a$ 与它的反转数组 $e$ 用同一组切点各切一遍之后，逐段之和完全相同**。每个询问临时把 $a_i$ 加 $v$，问当前数组的特殊划分数量（询问独立，改完即恢复）。

数据规模是解题的第一信号：$n,q$ 各自总和 $\le 2\times10^5$，多组测试——预处理可以花 $O(n\log n)$，但**每个询问必须 $O(\log n)$ 级**，不可能每问把数组重算一遍。所以整题的骨架是：**一次预处理把信息备好 → 每个询问 $O(\log n)$ 增量维护一个关键计数 $K$ → 答案用一个组合数公式输出**。

### 二、第一步：把「划分」翻译成「切点」

一个长度为 $m$ 的划分 $p_1+\cdots+p_m=n$，等价于在数组的 $n-1$ 个空隙里选 $m-1$ 个切点：

```
位置:   0     x1    x2   ...   x_{m-1}     n
数组:   |────|─────|───── ... ─────|────────|
段号:      1     2     3     ...    m-1      m
```

即 $0=x_0<x_1<\cdots<x_{m-1}<x_m=n$，第 $j$ 段是 $a_{x_{j-1}+1}$ 到 $a_{x_j}$。之后所有讨论都围绕**切点**进行——这是全题的第一个转折：计数「划分」变成计数「切点组合」。

### 三、第二步：把「段和相等」翻译成「切点函数值相等」

设前缀和 $S[k]=a_1+\cdots+a_k$，区间和 $=S[r]-S[l-1]$。

**原数组第 $j$ 段的和**：$S[x_j]-S[x_{j-1}]$。

**反转数组第 $j$ 段的和**：反转数组的第 $j$ 段对应原数组下标 $n-x_j+1$ 到 $n-x_{j-1}$（反转把"前 $x_j$ 个"映射成"原数组最后 $x_j$ 个"），其和为

$$S[n-x_{j-1}]-S[n-x_j]$$

**两段相等**：$S[x_j]-S[x_{j-1}]=S[n-x_{j-1}]-S[n-x_j]$，移项得

$$S[x_j]+S[n-x_j]\;=\;S[x_{j-1}]+S[n-x_{j-1}]$$

定义**切点函数** $T(x)=S[x]+S[n-x]$，则相邻切点满足 $T(x_j)=T(x_{j-1})$；对每个相邻对都成立，即

$$T(x_0)=T(x_1)=\cdots=T(x_m)$$

而两个端点天然有 $T(0)=S[0]+S[n]=S[n]$、$T(n)=S[n]+S[0]=S[n]$。因此**所有内部切点 $x_1,\dots,x_{m-1}$ 都必须落在 $T(x)=S[n]$ 上**。

### 四、第三步：好点判据 $D(x)=0$

定义

$$D(x)=S[x]+S[n-x]-S[n]=T(x)-S[n]$$

那么**内部切点 $x\in[1,n-1]$ 是好点（可作为切点）当且仅当 $D(x)=0$**。

这个等价是**充要**的，两个方向都要检查：

- **正向**：若划分特殊，则上面推导保证每个内部切点 $T(x_j)=S[n]$，即 $D(x_j)=0$。
- **反向**：若选出的 $m-1$ 个内部切点都满足 $D(x)=0$，则所有切点的 $T$ 值都等于 $S[n]$，任意相邻对 $T(x_j)=T(x_{j-1})$ 成立，反推回去每一段的原数组和都等于反转数组对应段和，划分就是特殊的。

**从小情况验证这个判据**：

- **$m=2$**：只有一个内部切点 $x$。原数组两段和是 $S[x]$ 与 $S[n]-S[x]$；反转数组两段和是 $S[n]-S[n-x]$ 与 $S[n-x]$。第一段相等给出 $S[x]=S[n]-S[n-x]$，第二段相等给出 $S[n]-S[x]=S[n-x]$，两个条件移项后**都是同一个式子** $S[x]+S[n-x]=S[n]$，即 $D(x)=0$。
- **$m=3$**：内部切点 $x_1<x_2$。第一段相等给 $D(x_1)=0$，第三段相等给 $D(x_2)=0$，中间段相等给 $T(x_2)=T(x_1)$——只要 $x_1,x_2$ 都是好点，中间段自动成立。
- **一般 $m$**：同理，每个相邻段相等给一条 $T(x_j)=T(x_{j-1})$，全部归结为「内部切点全是好点」。

### 五、第四步：答案是组合数

设内部位置 $1..n-1$ 中好点的个数为 $K$，答案是

$$\binom{K}{m-1}$$

（若 $K<m-1$ 则答案为 0。）

**为什么是组合数而不是排列数**：切点必须**从小到大**排列，从 $K$ 个好点中选出 $m-1$ 个位置后，它们的顺序唯一确定，所以是"选"不是"排"。$x=0$ 与 $x=n$ 不是内部切点，不参与选择（虽然它们恒满足 $D=0$）。

### 六、第五步：询问对 $D(x)$ 的影响——单点修改只平移一个对称区间

询问 $a_i\mathrel{+}=v$ 后，前缀和变为 $S'[t]=S[t]+v\cdot[i\le t]$，且 $S'[n]=S[n]+v$。代入 $D$ 的定义逐项相减：

$$D'(x)-D(x)=v\big([i\le x]+[i\le n-x]-1\big)$$

其中 $[\cdot]$ 是指示函数。记 $A=[i\le x]$、$B=[i\le n-x]$，增量就是 $v(A+B-1)$，只可能取三个值：$+v$、$-v$、$0$。

**分类讨论**（$A,B$ 的取值只取决于 $x$ 与 $i$、$n-i$ 的相对位置）：

| 情形 | 受影响区间 $I$ | 区间内 $D$ 的变化 | 区间外 |
|---|---|---|---|
| $2i\le n$（即 $i\le n-i$） | $[\,i,\ n-i\,]$ | 全部 $+v$ | 不变（$A+B-1=0$） |
| $2i>n$（即 $i>n-i$） | $[\,n-i+1,\ i-1\,]$ | 全部 $-v$ | 不变（$A+B-1=0$） |

**情形一（$2i\le n$）逐段验证**：

- $x\in[i,n-i]$：$x\ge i$ 且 $n-x\ge i$，$A=B=1$，增量 $v(1+1-1)=v$；
- $x<i$：$A=0$；而 $x<i\le n-i$ 说明 $x\le n-i$，$B=1$，增量 $v(0+1-1)=0$；
- $x>n-i$：$B=0$；而 $x>n-i\ge i$ 说明 $A=1$，增量 $v(1+0-1)=0$。

**情形二（$2i>n$）逐段验证**：

- $x\in[n-i+1,\,i-1]$：$x<i$ 且 $x>n-i$，$A=B=0$，增量 $v(0+0-1)=-v$；
- $x\le n-i$：$A=0$（因 $x<i$）、$B=1$，增量 0；
- $x\ge i$：$A=1$、$B=0$（因 $x\ge i>n-i$），增量 0。

几何直觉：两个镜像点 $i$ 与 $n-i$ 把数轴切成三段，**中间那段**被整体平移，两头不动；区间必然关于 $n/2$ 对称。当 $2i>n$ 时中间段可能退化成空（如 $n=5,i=3$：$[3,2]$ 为空），代码里 `L > R` 直接返回 0。

### 七、第六步：好点数 $K$ 的更新公式

修改只让区间 $I$ 内的 $D$ 整体平移到 $D+v$ 或 $D-v$。能"过线"变成好点的只有两类点：

| 情形 | $I$ 内 $D$ 变化 | 失去好点身份的点 | 新增好点 | $K'$ |
|---|---|---|---|---|
| $2i\le n$ | $+v$ | $D=0$ 的点 | $D=-v$ 的点 | $K-\#\{D=0\}+\#\{D=-v\}$ |
| $2i>n$ | $-v$ | $D=0$ 的点 | $D=+v$ 的点 | $K-\#\{D=0\}+\#\{D=+v\}$ |

（计数都在区间 $I$ 内进行；$v=0$ 时 $K'=K$ 直接短路。）注意端点 $0,n$ 虽恒有 $D=0$，但不在计数范围内。

### 八、第七步：两个查询怎么做到 $O(\log n)$

- **区间内 $D=0$ 的个数**：预处理前缀计数 $pref0[x]=pref0[x-1]+[D(x)=0]$，$O(1)$ 差分回答。
- **区间内 $D=val$ 的个数**：预处理 `map<long long, vector<int>> mp`，$mp[d]$ 存所有 $D(x)=d$ 的位置 $x$（$x$ 从小到大枚举，vector 天然有序）。查询即 `upper_bound(R) - lower_bound(L)`，$O(\log n)$。
- **组合数**：预处理阶乘与逆阶乘（费马小定理 + 倒推），$O(1)$ 回答 $\binom{K'}{m-1}$。

### 九、为什么这样做是对的（逐条对应）

1. 好点判据（第三步）是充要的，所以"数特殊划分"与"数好点组合"严格等价；
2. 组合数（第四步）由切点有序性保证，不重不漏；
3. 增量公式（第五步）的分类**覆盖了全部 $x$**，且区间外增量为 0——影响严格局部；
4. 更新公式（第六步）只统计恰好跨过 0 线的点：平移 $v$ 后能变成 0 的只有原来 $=-v$（情形一）或 $=+v$（情形二）的点，所以好点数变化量恰是"新增个数 − 失去个数"。

## 逐行代码解析

代码拆成 3 个模块，按顺序拼接即完整程序。

### 模块 1 阶乘、逆阶乘与快速幂

```cpp
#include<bits/stdc++.h>
using namespace std;
const long long mod = 1e9 + 7;
const int MAXN = 200005;
long long fact[MAXN], invfact[MAXN];

long long fastpow(long long a, long long b, long long q)
{
    if (b == 0) return 1;
    long long ans = 1;
    long long gap = a;
    while (b)
    {
        if (b & 1) ans = (ans * gap) % q;
        gap = (gap * gap) % q;
        b >>= 1;
    }
    return ans;
}

void init()
{
    fact[0] = 1;
    for (int i = 1; i < MAXN; i++)
        fact[i] = fact[i - 1] * i % mod;
    invfact[MAXN - 1] = fastpow(fact[MAXN - 1], mod - 2, mod);
    for (int i = MAXN - 2; i >= 0; i--)
        invfact[i] = invfact[i + 1] * (i + 1) % mod;
}


```

- `MAXN = 200005`：$n\le2\times10^5$，好点数 $K\le n-1$，组合数上标 $K$、下标 $m-1$ 全部落在 $[0,200004]$，够用。
- `fastpow` 的 $b=0$ 分支先返回 1，$b\ge1$ 时用 $b\&1$ 逐位检查、$gap$ 平方、$b$ 右移——标准二进制快速幂，所有乘法即时取模防溢出。
- `init`：$fact[i]=i!$ 递推；`invfact[MAXN-1]` 用费马小定理 $x^{mod-2}$ 求 $(MAXN-1)!$ 的逆元，再倒推 `invfact[i] = invfact[i+1] * (i+1)` 得到全部逆阶乘。**顺序不能反**：正推阶乘、倒推逆阶乘。
- 模数 $10^9+7$ 是质数，费马小定理成立。

### 模块 2 组合数函数

```cpp
long long fn(long long s, long long k)
{
    if (s < 0 || k < 0 || k > s) return 0;
    int n = (int)s, r = (int)k;
    return fact[n] * invfact[r] % mod * invfact[n - r] % mod;
}


```

- 参数用 `long long` 接收，先做范围检查：$s<0$、$k<0$、$k>s$ 一律返回 0——这同时处理了「$K<m-1$ 答案 0」和「$m=1$ 时 $\binom{K}{0}=1$」（$k=0$ 不越界，走正常路径）。
- `s,k` 转 `int` 后按下标取 `fact/invfact`：$s\le2\times10^5$ 不溢出 int，转换安全。
- 返回 $fact[n]\cdot invfact[r]\cdot invfact[n-r]$ 两次取模，先乘后模顺序固定，防溢出。

### 模块 3 主函数与询问处理

```cpp
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    init();

    int T;
    cin >> T;
    while (T--)
    {
        int n, m, q;
        cin >> n >> m >> q;

        vector<long long> a(n + 1, 0);
        for (int i = 1; i <= n; i++)
        {
            cin >> a[i];
            a[i] += a[i - 1];
        }

        vector<long long> D(n + 1, 0);
        map<long long, vector<int>> mp; 
        vector<int> pref0(n + 1, 0); 

        for (int x = 1; x <= n - 1; x++)
        {
            D[x] = a[x] + a[n - x] - a[n];
            mp[D[x]].push_back(x);
            pref0[x] = pref0[x - 1] + (D[x] == 0);
        }

        int K = pref0[n - 1];

        auto countZero = [&](int L, int R) -> int {
            if (L > R) return 0;
            return pref0[R] - pref0[L - 1];
            };

        auto countVal = [&](long long val, int L, int R) -> int {
            if (L > R) return 0;
            auto it = mp.find(val);
            if (it == mp.end()) return 0;
            const auto& vec = it->second;
            return upper_bound(vec.begin(), vec.end(), R)
                - lower_bound(vec.begin(), vec.end(), L);
            };

        while (q--)
        {
            int i;
            long long v;
            cin >> i >> v;

            long long newK = K;

            if (v != 0)
            {
                if (2LL * i <= n)
                {
                    int L = i, R = n - i;
                    newK -= countZero(L, R);
                    newK += countVal(-v, L, R);
                }
                else
                {
                    int L = n - i + 1, R = i - 1;
                    newK -= countZero(L, R);
                    newK += countVal(v, L, R);
                }
            }

            cout << fn(newK, m - 1) << '\n';
        }
    }
    return 0;
}
```

- 每组测试读入 $n,m,q$ 后，把 `a` **就地变成前缀和**（`a[i] += a[i-1]`）：此后 `a[x]` 就是 $S[x]$，代码里 $D[x]=a[x]+a[n-x]-a[n]$。
- 只枚举 $x=1..n-1$ 计算 $D[x]$：端点 $0,n$ 不是内部切点。同时 `mp[D[x]].push_back(x)`（$x$ 递增枚举，vector 天然有序）与 `pref0[x] = pref0[x-1] + (D[x]==0)`。
- `K = pref0[n-1]` 是原始好点数；两个 lambda `countZero` / `countVal` 都先判 `L > R`（空区间返回 0），`countVal` 在 `mp` 中找不到键时也返回 0。
- 询问处理完全按推导：`v != 0` 时才动 `newK`；`2LL*i <= n` 用 long long 比较防 `2*i` 溢出；两种情况分别是 `K' = K - cnt0 + cnt(-v)` 与 `K' = K - cnt0 + cnt(v)`。
- 询问独立天然满足：每次都用未修改的 `K`、`D`、`mp`、`pref0` 计算，从不真正改动数组。

## 复杂度分析

- 预处理：前缀和 $O(n)$；建 $D$、`mp`、`pref0` 共 $O(n)$（`mp` 插入 $O(\log n)$，总 $O(n\log n)$）；阶乘预处理全局一次 $O(MAXN)$。
- 每次询问：两次 `countZero`（$O(1)$ 前缀差）+ 一次 `countVal`（`mp.find` $O(\log n)$ + 两次二分 $O(\log n)$）→ $O(\log n)$。
- 每组数据总时间 $O((n+q)\log n)$；空间：$D$、`pref0`、`mp`（共 $n-1$ 个位置）均为 $O(n)$，`fact/invfact` 全局 $O(MAXN)$。

## 常见陷阱与注意事项

1. **把端点算进好点**：$D(0)=D(n)=0$ 恒成立，但内部切点只取 $1..n-1$；枚举时把 0 或 n 算进 $K$ 会让答案凭空多 $\binom{K+2}{m-1}$。
2. **好点数的更新式方向**：情况一加 $v$ 时找的是 $D=-v$ 的点；情况二减 $v$ 时找的是 $D=+v$ 的点。把两种情况的目标值写反（如情况二找 $-v$）必错。
3. **区间端点**：情况一 $I=[i,n-i]$、情况二 $I=[n-i+1,i-1]$；情况二的区间可能为空（如 $n=5,i=3$ 时 $L=3>R=2$），`L>R` 必须先判。
4. **$2i$ 溢出**：$n\le2\times10^5$ 时 `2*i` 在 int 内其实安全，但代码用 `2LL * i <= n` 防患于未然；改回 int 时要注意别把 `2*i` 和 `n` 混用类型。
5. **前缀和与 $D$ 的数值范围**：$|a_i|\le10^9$、$n\le2\times10^5$，前缀和可达 $2\times10^{14}$，$D$ 同样量级且**可为负**——`D` 与 `mp` 的键必须 `long long`，不能用 `int` 或 `unsigned`。
6. **$v=0$ 短路**：不短路的话 `countVal(0, L, R)` 会把 $D=0$ 的点既从 $K$ 减掉又加回来，答案不变但多两次查询；更危险的是有人会写错成只减不加。
7. **$m=1$ 特例**：无内部切点，任意数组的唯一划分 $[n]$ 永远特殊，答案 $\binom{K}{0}=1$；组合数函数的 $k=0$ 分支自然返回 1，别额外特判出 0。
8. **$K<m-1$**：组合数函数里 `k > s` 返回 0，正好覆盖；若手写组合数忘了这个判断，数组下标越界。
9. **询问独立性**：每次询问基于原始数组，不要把上一次的 `newK` 当成下一次的 `K` 继续迭代——「独立」在题意和实现里都要守住。
10. **map 键的 vector 必须有序**：$x$ 从小到大 push 保证了这一点，二分才成立；若改成逆序枚举再去二分会得到垃圾结果。
11. **阶乘上界**：`MAXN` 只比 $2\times10^5$ 多 5；若 $n$ 上限提高而忘记同步改 `MAXN`，`fact[n]` 越界 UB。
12. **取模时机**：`fastpow` 与组合数中每次乘法后立即 `% mod`，$10^9$ 级的两个数相乘是 $10^{18}$ 级、恰好贴 `long long` 上限附近，必须先乘后模但中间不攒大数。
13. **`countVal` 找不到键**：`mp.find` 返回 `end` 时直接返回 0，别解引用迭代器。

## 对比与扩展

**T(x) 的对称性（预提案 2，经确认写入）**：$T(x)=S[x]+S[n-x]=T(n-x)$，好点集合天然关于 $n/2$ 镜像对称；单点修改影响的区间 $[i,n-i]$ 或 $[n-i+1,i-1]$ 也正是以 $n/2$ 为中心的对称区间——这不是巧合：指示函数 $[i\le x]+[i\le n-x]$ 在镜像点 $x\leftrightarrow n-x$ 处取值相同，增量 $A+B-1$ 只可能在「穿过 $i$ 与 $n-i$ 的区间」内偏离 0。理解这层对称性后，两个分类区间可以直接按「镜像对」记忆。

**map 与离散化（预提案 1，经确认写入）**：`map` 查找/二分均为 $O(\log n)$；若要进一步压常数，可先把所有出现的 $D$ 值（含每个询问的目标值 $\pm v$）离散化后用 `vector<vector<int>>` + `unordered_map` 或排序数组定位，均摊 $O(1)$ 定位 + 二分不变；在 $n,q$ 各 $2\times10^5$ 且多测的场景下，离散化版本通常快 1.5~2 倍。本代码的 `map` 版已足以通过原题时限。

**可复用套路**：「段和相等」类条件先写成前缀和差、再合并成切点函数 $T(x)$ 相等；端点处函数值相等的结构会让问题坍缩成「内部切点都满足一个标量等式」，从而变成计数问题；而单点修改对这类前缀和型判据的影响总是**区间平移**，配合「按值分桶 + 二分计数」即可 $O(\log n)$ 维护好点个数。凡「询问独立 + 单点改 + 计数」的题，都要问一句：修改影响的区间长什么样、哪些点会跨过判定线。
