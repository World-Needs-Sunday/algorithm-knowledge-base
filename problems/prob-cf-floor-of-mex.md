## 题目描述

定义函数：

$$f(S, x) = \text{mex}(\{\lfloor y/x \rfloor : y \in S\})$$

其中 $S$ 是非负整数集合，$x$ 是正整数，$\text{mex}(C)$ 表示集合 $C$ 中最小的未出现非负整数。

Farmer John 选择了一个子集 $A \subseteq \{0, 1, \dots, n-1\}$，然后对每个 $k = 1, 2, \dots, n$ 计算：

$$a_k = f(A, k)$$

现在集合 $A$ 被隐藏了，只给你数组 $a_1, a_2, \dots, a_n$。你的任务是构造任意一个集合 $B \subseteq \{0, 1, \dots, n-1\}$，使得对所有 $1 \le k \le n$ 都有 $f(B, k) = a_k$。

题目保证一定存在合法解。

### 输入格式

- 第一行：测试用例数 $t$（$1 \le t \le 10^4$）
- 每组测试用例：
  - 第一行：整数 $n$（$1 \le n \le 10^5$）
  - 第二行：$n$ 个整数 $a_1, a_2, \dots, a_n$（$0 \le a_i \le n$）

保证所有测试用例的 $\sum n \le 10^5$。

### 输出格式

每组用例输出两行：
- 第一行：集合 $B$ 的大小 $m$
- 第二行：$m$ 个不同整数，表示 $B$ 中的元素（顺序任意）
- 若 $m = 0$，第二行为空行

## 一、MEX 的关键性质

$\text{mex}(C) = v$ 当且仅当：
- $0, 1, 2, \dots, v-1$ 都在 $C$ 中
- $v$ 不在 $C$ 中
- 大于 $v$ 的数是否在 $C$ 中**不影响** mex 值

这是本题最核心的出发点。我们要让 $f(B, k) = a_k$，等价于：
1. $\{0, 1, \dots, a_k-1\}$ 必须全部出现在 $\{\lfloor y/k \rfloor : y \in B\}$ 中
2. $a_k$ 一定不能出现在 $\{\lfloor y/k \rfloor : y \in B\}$ 中

---

## 二、核心思路：反向标记「禁止元素」

### 2.1 哪些数绝对不能放进 B？

如果某个数 $y$ 满足 $\lfloor y/k \rfloor = a_k$，那么 $y$ **绝对不能**放进 $B$。

原因很简单：如果 $y \in B$，那么 $a_k$ 就会出现在集合 $\{\lfloor z/k \rfloor : z \in B\}$ 中，这样 mex 就不可能等于 $a_k$ 了。

### 2.2 禁止区间

对于固定的 $k$，满足 $\lfloor y/k \rfloor = a_k$ 的所有 $y$ 构成一个连续区间：

$$a_k \le \frac{y}{k} < a_k + 1$$

$$a_k \cdot k \le y < (a_k + 1) \cdot k$$

即禁止区间为：

$$[a_k \cdot k,\ (a_k + 1) \cdot k - 1]$$

由于 $y$ 只能取 $0$ 到 $n-1$，所以实际禁止区间要与 $[0, n-1]$ 取交集：
- 若 $a_k \cdot k \ge n$，禁止区间完全在范围外，跳过
- 否则右端点截断为 $\min((a_k+1) \cdot k - 1,\ n-1)$

### 2.3 安全元素

如果某个 $y$ 对所有 $k = 1, 2, \dots, n$ 都不会产生 $a_k$（即不被任何禁止区间覆盖），那么 $y$ 就是「安全元素」，可以放心放进 $B$。

我们的构造策略：**把所有安全元素都放进 B**。

---

## 三、为什么这样构造一定正确？

题目保证原集合 $A$ 存在且合法。我们用四条引理证明构造的正确性：

### 引理 1：A 中每个元素都是安全元素

**证明**：假设 $A$ 中存在 $y$ 和某个 $k$ 使得 $\lfloor y/k \rfloor = a_k$，那么 $a_k$ 就出现在 $f(A,k)$ 的集合里，mex 就不可能是 $a_k$，与 $a_k = f(A,k)$ 矛盾。

### 引理 2：A ⊆ B

因为 $B$ 收集了所有安全元素，而 $A$ 的元素都安全，所以 $A$ 是 $B$ 的子集。

### 引理 3：B 不会产生 a_k

$B$ 中每个元素都是安全元素，安全元素对所有 $k$ 都满足 $\lfloor y/k \rfloor \neq a_k$，所以 $a_k$ 不会出现在 $f(B,k)$ 的集合中。

### 引理 4：0 到 a_k-1 都会出现在 B 产生的集合中

原集合 $A$ 满足 $f(A,k) = a_k$，所以 $0, 1, \dots, a_k-1$ 在 $A$ 中已经全部出现。又因为 $A \subseteq B$，加入更多元素不会让已出现的值消失，所以这些值仍然都出现。

**结论**：对任意 $k$，$0$ 到 $a_k-1$ 都出现，$a_k$ 不出现，所以 $\text{mex} = a_k$。构造正确。

## 四、高效实现：差分数组

### 4.1 为什么不用暴力？

如果对每个 $y$ 枚举所有 $k$ 检查，时间复杂度 $O(n^2)$，对于 $n=10^5$ 会超时。

### 4.2 差分标记

反过来，对每个 $k$，用差分数组标记它的禁止区间。每个 $k$ 只产生一个区间，总共 $n$ 个区间，差分标记是 $O(1)$ 每个。

```
diff[L] += 1
diff[R + 1] -= 1
```

最后做前缀和，`cur == 0` 的位置就是没被任何禁止区间覆盖的安全元素。

### 4.3 完整算法流程

1. 初始化差分数组 `diff[0..n]` 为 0
2. 对每个 $k = 1$ 到 $n$：
   - $L = a_k \cdot k$，若 $L \ge n$ 则跳过
   - $R = (a_k + 1) \cdot k - 1$，若 $R \ge n$ 则 $R = n - 1$
   - `diff[L]++`，`diff[R+1]--`
3. 前缀和遍历，收集所有 `cur == 0` 的下标作为答案

## 五、代码逐行解析

```cpp
#include<bits/stdc++.h>
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    
    int t;
    cin >> t;
    while (t--)
    {
        int n;
        cin >> n;
        vector<int> A(n, 0);     // 差分数组，大小 n（注意下标 0..n-1）
        vector<int> ans;
        ans.reserve(n);
```

`A` 用作差分数组。注意这里的实现有一个细节：数组大小是 $n$（下标 $0$ 到 $n-1$），而不是 $n+1$。这是因为代码中只在 `(x+1)*i < n` 时才做右端点减一操作，如果 $R+1 = n$ 就直接跳过了（因为超出数组范围，但前缀和不会遍历到 $n$，所以不影响）。

```cpp
        for (int i = 1; i <= n; i++)
        {
            int x;
            cin >> x;
            if (1LL * i * x < n) A[i * x] += 1;       // 左端点：L = a_k * k
            if (1LL * (x + 1) * i < n) A[(x + 1) * i] -= 1;  // 右端点+1：R+1 = (a_k+1)*k
        }
```

这里 $i$ 对应题目中的 $k$，$x$ 对应 $a_k$。

- `i * x` 就是 $a_k \cdot k$，即禁止区间左端点 $L$
- `(x + 1) * i` 就是 $(a_k+1) \cdot k$，即禁止区间右端点 $+1$

**注意**：必须用 `1LL` 强制转换为 `long long` 再乘，否则 `int` 乘法会溢出。

```cpp
        if (!A[0]) ans.emplace_back(0);
        for (int i = 1; i < n; i++)
        {
            A[i] += A[i - 1];   // 前缀和：A[i] 现在表示 i 被多少个禁止区间覆盖
            if (!A[i]) ans.emplace_back(i);  // 没被覆盖 → 安全元素 → 加入 B
        }
```

前缀和后，`A[i]` 的值表示第 $i$ 个数被多少个禁止区间覆盖。值为 0 说明是安全元素，可以加入答案集合。

```cpp
        cout << ans.size() << '\n';
        for (int i : ans) cout << i << ' ';
        cout << '\n';
    }
}
```

输出集合大小和元素。

|---|---|---|
| 差分标记 | $O(n)$ | $O(n)$ |
| 前缀和收集答案 | $O(n)$ | — |
| **总计** | **$O(n)$ 每组** | **$O(n)$** |

总时间复杂度 $O(\sum n)$，$\sum n \le 10^5$，完全通过。

## 七、完整小例子

### 输入

```
n = 3
a = [1, 2, 1]   (a_1=1, a_2=2, a_3=1)
```

### 差分标记

| k | a_k | L = a_k·k | R = (a_k+1)·k - 1 | 操作 |
|---|---|---|---|---|
| 1 | 1 | 1 | 1 | diff[1]++, diff[2]-- |
| 2 | 2 | 4 | 5 | L=4 ≥ n=3，跳过 |
| 3 | 1 | 3 | 5 | L=3 ≥ n=3，跳过 |

差分数组初始全 0，标记后：
- diff[1] = 1
- diff[2] = -1

### 前缀和

| y | 前缀和 cur | 是否安全 |
|---|---|---|
| 0 | 0 | ✓ 加入 B |
| 1 | 1 | ✗ 被禁止 |
| 2 | 0 | ✓ 加入 B |

### 输出

```
2
0 2
```

### 验证

- $k=1$：$\lfloor 0/1 \rfloor=0, \lfloor 2/1 \rfloor=2$ → 集合 $\{0,2\}$ → mex = 1 = a_1 ✓
- $k=2$：$\lfloor 0/2 \rfloor=0, \lfloor 2/2 \rfloor=1$ → 集合 $\{0,1\}$ → mex = 2 = a_2 ✓
- $k=3$：$\lfloor 0/3 \rfloor=0, \lfloor 2/3 \rfloor=0$ → 集合 $\{0\}$ → mex = 1 = a_3 ✓

## 八、常见陷阱与注意事项

1. **int 溢出**：$a_k \cdot k$ 可能超过 int 范围（$n=10^5$ 时最大约 $10^{10}$），必须用 `long long` 计算。代码中用 `1LL * i * x` 保证 64 位乘法
2. **禁止区间的边界**：$[a_k \cdot k,\ (a_k+1) \cdot k - 1]$，左闭右闭。差分数组右端点是 $R+1 = (a_k+1) \cdot k$
3. **跳过超出范围的区间**：如果 $L \ge n$，禁止区间完全在候选范围外，直接跳过，不要标记
4. **差分数组大小**：代码中数组大小为 $n$，右端点若等于 $n$ 则不标记（因为前缀和只跑到 $n-1$），这是正确的
5. **题目保证有解**：不需要验证构造是否合法，直接输出所有安全元素即可
6. **空集输出**：若 $B$ 为空，第二行也要输出一个空行
7. **k 从 1 开始**：题目中 $k = 1, 2, \dots, n$，注意数组下标的对应关系

## 九、核心思想总结

> **一句话**：把所有「会让某个 $a_k$ 出现在 mex 集合中」的数禁止掉，剩下的数全部放进 $B$。
>
> 为什么可行？因为原集合 $A$ 的元素一定都是安全的（否则就不满足 $f(A,k)=a_k$），所以 $A \subseteq B$。加入更多安全元素不会破坏 mex 值（不会产生 $a_k$），而 $0$ 到 $a_k-1$ 已经由 $A$ 保证出现。
>
> 这是一道典型的「反向思考」题：不从正面构造满足条件的集合，而是先排除所有不合法的元素，剩下的自然全部合法。
