## 题目描述

给定一张 $n$ 个点、$m$ 条边的无向图，每条边有一个长度（边权）。你可以**任意选择一个入口（起点）**，然后按下列规则依次开发道路，直到把所有点都开发出来：

1. 每次只能开发一条连接「**已开发区域**」与「**未开发点**」的道路；
2. 若某条道路连接父节点 $u$ 与子节点 $v$，则它的代价为 $w(u,v) \times dep[v]$，其中 $dep[v]$ 表示从入口到 $v$ 的路径长度（经过的边数）。

等价地说：入口的深度为 $0$，它的直接后继深度为 $1$，依此类推；**深度为 $k$ 的点，连接它和它父节点的那条边要乘以 $k$**。目标是最小化开发所有点的总代价。

### 输入格式

> 朋友资料未附正式输入格式说明，以下按所附代码的读入逻辑整理。

第一行两个整数 $n, m$，分别表示点数和边数。接下来 $m$ 行，每行三个整数 $u, v, w$，表示一条连接 $u$ 与 $v$、长度为 $w$ 的无向边。

### 输出格式

一行一个整数，表示开发所有点的最小总代价。

### 数据范围

- $n \le 12$
- $m \le 1000$
- 边权 $\le 5 \times 10^5$

## 样例

### 样例 1

**输入：**
```
4 5
1 2 1
1 3 3
1 4 1
2 3 4
3 4 1
```

**输出：**
```
4
```

**解释：** 选入口 $1$。第 $0$ 层为 $\{1\}$；第 $1$ 层可加入 $\{2\}$、$\{4\}$ 或 $\{2,4\}$，其中同时加入 $2$ 与 $4$ 的代价为 $1 \times 1 + 1 \times 1 = 2$（$2$ 和 $4$ 都连到 $1$，深度为 $1$）；第 $2$ 层加入 $\{3\}$，此时 $3$ 可以连到 $1$（代价 $3 \times 2 = 6$）、连到 $4$（代价 $1 \times 2 = 2$）或连到 $2$（代价 $4 \times 2 = 8$），取最优连到 $4$，总代价 $= 2 + 2 = 4$，与输出一致。

> 注：朋友资料未给出官方样例的原始输入文本，上述输入为按题解给出的边集与代码读入格式补全；输出 $4$ 已通过编译实测验证。

## 解题思路

### 一、题目在问什么，数据范围给出什么信号

题目要在一张无向图上任选入口，按「只能从已开发区域向未开发点修路、代价 = 边权 × 该点深度」的规则把所有点开发出来，求最小总代价。其中「深度」即该点到入口经过的边数。

数据范围 $n \le 12$ 是整道题最显眼的信号：$2^n = 4096$、$3^n = 531441$，意味着我们可以**枚举点集、枚举子集**，也就是用**状压 DP**。

### 二、为什么是状压，而不是贪心 / 最小生成树

初看像「求最小代价连通所有点」，容易想到 Prim/Kruskal 之类的最小生成树。但本题每条边的代价不是固定边权，而是「边权 × 深度」，深度又取决于整棵树的形状和根的位置：

- 同一个点，放在第 $1$ 层和第 $5$ 层，连到父节点的边代价差很多倍；
- 一条「现在看很便宜」的边，如果迫使某些点被放到很深的层，整体反而更贵。

所以局部贪心没有最优子结构，必须把「哪些点已经开发、深度走到第几层」都记下来搜索。$n$ 很小，正好可以枚举子集做 DP。（暴力枚举所有生成树在 $n=12$ 时数量巨大，不可行。）

### 三、关键性质一：最终道路一定是一棵树

每个点（除入口外）恰好被「第一次开发它的那条路」连进来，一条路恰好新增一个点，所以总共恰好 $n-1$ 条路，且连通、无环——最终道路集就是一棵以入口为根的树。于是每条边 $(u,v)$（$u$ 是父，$v$ 是子）的贡献为 $w(u,v) \times dep[v]$。

### 四、关键性质二：可以按深度「一层一层」扩展

同一层（深度相同）的点之间没有连边——如果有，父子深度应该差 $1$ 而不是相同。于是整个开发过程可以看成：第 $0$ 层放根，第 $1$ 层放根的儿子，第 $2$ 层放第 $1$ 层的儿子……这样 DP 就能**按层推进**，而不是枚举树的每条边。

### 五、关键性质三：同一层的新点互不干扰

当从「已覆盖点集 $T$」扩展出新的一层 $S \setminus T$（这些新点深度都是 $i$）时，每个新点 $v$ 可以**独立**地从 $T$ 里挑一个父节点：$v$ 选谁，不影响别的点选谁，也不影响深度因子 $i$（大家都乘同一个 $i$）。所以这一层的新增代价可以拆开求和：

$$
cost(T, S) = \sum_{v \in S \setminus T} \min_{u \in T} w(u, v)
$$

其中 $\min_{u \in T} w(u,v)$ 就是 $v$ 连到集合 $T$ 的最小边权；若 $v$ 与 $T$ 中任何点都不相连，则该值不存在，对应转移不合法。

### 六、状态设计与转移方程

设 $dp[i][S]$ 表示「已经开发了前 $i$ 层（深度 $0 \sim i$ 的点），这些点组成的集合为 $S$」时的最小总代价。

转移考虑新加入的第 $i$ 层：设上一层覆盖的集合是 $T$（$T \subsetneq S$），新增点集是 $S \setminus T$，这些点深度都是 $i$，于是：

$$
dp[i][S] = \min_{T \subsetneq S} \left( dp[i-1][T] + i \times cost(T, S) \right)
$$

根层 $i=0$：$dp[0][\{u\}] = 0$（只开发入口，代价为 $0$）。由于入口可以任选，对每个 $u$ 都作为根跑一遍，最终答案取覆盖全集的任意层最小值，即 $\min_i dp[i][\{1,2,\dots,n\}]$。

### 七、为什么这样转移是对的（正确性）

- **上界方向（能覆盖最优解）**：任取一棵最优树，按 BFS 顺序把点按深度分层。第 $i$ 层每个点 $v$ 的真实父节点一定在第 $i-1$ 层、属于集合 $T$，所以 $\min_{u\in T}w(u,v) \le w(\text{真实父节点}, v)$，于是 DP 给出的代价不会超过最优树的总代价。
- **下界方向（DP 的每条路径都是合法方案）**：DP 的每步都是「把新点 $v$ 连到上一层的某个点」，按深度 $0,1,2,\dots$ 依次连边，自然构成一棵以入口为根的树，且总代价就是 DP 记录的值。因此 DP 不会「凭空算小」。
- 两方向夹逼，DP 的最小值恰好等于最优总代价。

### 八、预处理 $cost[T][S]$

$cost(T,S)$ 会被反复用到，先一次性算好存进 `cot[T][S]`：枚举目标集合 $i$（即 $S$），枚举它的非空真子集 $j$（即 $T$），对每个新点 $t \in i \oplus j$ 求 $t$ 到 $j$ 的最小边权并累加；若某个 $t$ 连不到 $j$，则整组 `cot[j][i] = inf` 表示该扩展不合法。这样转移时就能 $O(1)$ 取到 $cost(T,S)$。

## 逐行代码解析

### 头文件与全局变量

```cpp
#include<bits/stdc++.h>
#define endl '\n'
#define fi first
#define se second
#define lowbit(x) (x&(-x))
#define int long long
using namespace std;
typedef pair<int,int> PII;
typedef long long ll;
const int N=15,M=(1<<12);
int n,m,cnt;
int cot[M][M],dp[N][M],G1[N][N];
inline int read();
inline void write(int x);
```

- `#define int long long` 把代码里所有 `int` 替换为 `long long`，使 `memset(0x3f)` 得到的 INF 哨兵变成 $0x3f3f3f3f3f3f3f3f$ 这样的极大值，避免与真实答案（边权 × 深度 × 边数）混淆。
- `G1[u][v]` 存 $u,v$ 之间的最小边权（重边取 min）；`cot[j][i]` 存从集合 $j$ 扩展一层到集合 $i$ 的边权和（不乘深度）；`dp[i][S]` 存前 $i$ 层覆盖点集 $S$ 的最小代价。
- $M = 2^{12} = 4096$，用于把「点集」压成一个不超过 $M$ 的整数下标。

### main：读入、初始化与建边

```cpp
signed main(){
//    freopen(".in","r",stdin);
//    freopen(".out","w",stdout);
    ios::sync_with_stdio(false);
    cin.tie(nullptr);cout.tie(nullptr);
    cin>>n>>m;

    memset(G1,0x3f,sizeof G1);
    memset(dp,0x3f,sizeof dp);
    int inf=dp[0][0];
    cnt=inf;
    if(n==1){
        cout<<0;return 0;
    }
    for(int i=1;i<=m;i++){
        int u,v,w;cin>>u>>v>>w;
        G1[u][v]=min(G1[u][v],w);
        G1[v][u]=min(G1[v][u],w);
    }
```

- 关同步后读入 $n,m$；`memset(...,0x3f,...)` 把 `G1`、`dp` 初始化为 INF，`inf = dp[0][0]` 记录该哨兵值，`cnt` 作为最终答案初值也设为 `inf`。
- `if(n==1)` 特判：单点无需开路，直接输出 $0$ 并返回（发生在读边之前）。
- 读入 $m$ 条边时对正反两个方向都做 `min`，处理**重边**（同一对点保留最小边权）。

### 预处理 cot[j][i]

```cpp
    for(int i=1;i<(1<<n);i++){
        for(int j=i;j;j=(j-1)&i){
            if(j==i) continue;
            for(int t=1;t<=n;t++){
                int tmp=inf;
                if(!(((i^j)>>(t-1))&1)) continue;
                for(int l=1;l<=n;l++){
                    if((j>>(l-1))&1) tmp=min(tmp,G1[l][t]);
                }
                if(tmp>=inf){
                    cot[j][i]=inf;break;
                }else cot[j][i]+=tmp;
            }
        }
    }
```

- 外层枚举目标集合 $i$（$S$），内层用 `for(int j=i;j;j=(j-1)&i)` 枚举 $i$ 的所有**非空真子集** $j$（$T$），并 `continue` 跳过 `j==i`（新层不能为空）。
- `i^j` 即 $S \setminus T$，`(((i^j)>>(t-1))&1)` 判断点 $t$ 是否属于新层；是才继续。
- 对每个新点 $t$，`tmp = min_{l∈j} G1[l][t]` 求出 $t$ 连到集合 $j$ 的最小边权；`tmp >= inf` 说明 $t$ 无法连到 $j$，整组置 `inf` 并 `break`；否则累加进 `cot[j][i]`。

### DP 主循环：枚举根并逐层转移

```cpp
    for(int u=1;u<=n;u++){
        memset(dp,0x3f,sizeof dp);
        dp[0][1<<(u-1)]=0;
        for(int i=1;i<n;i++){
            for(int j=1;j<(1<<n);j++){
                for(int k=j;k;k=(k-1)&j){
                    if(j==k) continue;
                    if(cot[k][j]!=inf) dp[i][j]=min(dp[i][j],dp[i-1][k]+i*cot[k][j]);
                }
            }
            cnt=min(cnt,dp[i][(1<<n)-1]);
        }
    }
```

- 枚举每个点 $u$ 作为入口：`dp[0][1<<(u-1)] = 0` 表示第 $0$ 层只含根、代价为 $0$。
- 深度 $i$ 从 $1$ 到 $n-1$；对每个状态 $j$（$S$）枚举其非空真子集 $k$（$T$，跳过 $k==j$）。
- 若 `cot[k][j] != inf`，则按转移方程 `dp[i][j] = min(dp[i][j], dp[i-1][k] + i*cot[k][j])` 更新：新增层深度为 $i$，代价 = 上一层 $dp[i-1][k]$ + $i$ × 该层边权和。
- 每层结束用覆盖全集 $(1<<n)-1$ 的 `dp[i][...]` 更新答案 `cnt`。

## 复杂度分析

### 时间复杂度：$O(3^n \cdot n^2)$

- 预处理 `cot`：枚举所有「集合 + 子集」对，共 $3^n$ 组；每组内部枚举新点 $t$（$O(n)$）并求 $t$ 到 $j$ 的最小边权（$O(n)$），故为 $O(3^n \cdot n^2)$。当 $n=12$ 时 $3^{12}=531441$，乘 $n^2=144$ 约 $7.6 \times 10^7$，可过（代码里还有若干剪枝）。
- DP 转移：对每个根（$n$ 个）× 深度（$n$ 层）× 状态与子集（合计 $3^n$ 组），共 $O(n^2 \cdot 3^n)$，与预处理同阶。
- 总复杂度 $O(3^n \cdot n^2)$。

### 空间复杂度：$O(4^n)$

- `cot[M][M]` 是空间大头，$M = 2^n$，故 $M^2 = 4^n$。当 $n=12$ 时约 $16.7 \times 10^6$ 个 `long long`（因 `#define int long long` 每项 8 字节），约 128 MB，需留意内存限制。
- `dp[N][M]` 为 $O(n \cdot 2^n)$，`G1[N][N]` 为 $O(n^2)$，相对可忽略。

## 常见陷阱与注意事项

1. **重边**：输入可能有多条连接同一对点的边，必须取最小边权（代码用 `G1[u][v]=min(G1[u][v],w)` 及反向）。漏掉会算大甚至算错。
2. **不连通 / 无法扩展**：若某个新点 $v$ 与集合 $T$ 中所有点都不相连，则该转移不合法，`cot[j][i]` 要置为 `inf`，并在转移时用 `cot[k][j] != inf` 跳过，否则会把 `inf` 当真值加进去。
3. **深度因子的起点**：深度 $i$ 从 $1$ 开始乘（第 $1$ 层深度为 $1$），根层深度 $0$ 没有代价。写成从 $0$ 开始乘会把根层也计入代价。
4. **枚举子集的边界**：`for (int j = i; j; j = (j-1)&i)` 枚举 $i$ 的**非空**子集（$j=0$ 时退出循环），且必须 `continue` 跳过 `j == i`（新层不能为空）。DP 内 `for (int k = j; ...)` 同理要跳过 `k == j`。
5. **根要枚举**：入口可以任选，不同根会得到不同的树与代价，必须对每个点作为根各跑一遍 DP 取最小值，不能只跑一个根。
6. **$n=1$ 特判**：单点不需要开路，代价为 $0$；代码在 `n==1` 时直接输出 $0$ 并返回（注意它发生在读边之前，此时后续边不会被读入）。
7. **内存**：`cot` 是 $4^n$ 大小且因 `#define int long long` 每项 8 字节，$n=12$ 时约 128 MB，注意内存限制；若卡内存可把 `cot` 改回 `int` 或改为按需计算。
8. **INF 的取值**：`memset(..., 0x3f, ...)` 后 `int` 已被替换为 `long long`，`inf` 是 $0x3f3f3f3f3f3f3f3f$；判断「不可达」要用 `tmp >= inf`，不要拿 `0x3f3f3f3f` 这类 int 值去和 long long 比较。

## 对比与扩展

| 方法 | 时间 | 空间 | 说明 |
|---|---|---|---|
| 分层状压 DP（本题） | $O(3^n n^2)$ | $O(4^n)$ | 利用「按层扩展 + 子集枚举」，$n \le 12$ 可过 |
| Prim/Kruskal 贪心 | $O(m \log n)$ | $O(n)$ | 错误——深度乘法没有最优子结构 |
| 暴力枚举生成树 | $n^{n-2}$ 数量级 | $O(n)$ | 不可行 |

### 扩展

- 「**按深度分层 + 子集枚举**」的状压套路也见于其他「带层数/步数惩罚的连通、覆盖」类题，核心是把「选父节点」拆成「每层独立求和」。
- 预处理「点到集合的最小边权」是常见优化：把「枚举父节点」从转移内挪到预处理，避免每次转移都 $O(n^2)$ 重算。
- 若放宽「每层至少一个点」或调整深度因子的定义，仍可沿用 `dp[层][集合]` 框架，只需修改转移的深度因子与合法性判断。
- 子集枚举技巧 `for (sub = S; sub; sub = (sub-1)&S)` 是状压 DP 的基础，广泛用于需要「枚举集合所有子集」的场景。
