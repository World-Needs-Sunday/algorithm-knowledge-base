## 题目描述

给定一个仅含 $0$ 和 $1$ 的数组 $a_1, a_2, \ldots, a_n$ 和一个长度为 $n$ 的二进制字符串 $s$。依次执行 $n$ 个操作，第 $i$ 个操作：

- 若 $s_i = 1$，对 $a$ 执行一次**正向冒泡**：从左到右扫描，若 $a_i > a_{i+1}$ 则交换
- 若 $s_i = 0$，对 $a$ 执行一次**反向冒泡**：从右到左扫描，若 $a_i > a_{i+1}$ 则交换

对 $n+1$ 个状态（初始状态 + 每次操作后的状态），分别输出数组 $a$ 的**逆序对数**。

> **逆序对**：满足 $1 \le i < j \le m$ 且 $c_i > c_j$ 的下标对 $(i, j)$ 的个数。

### 正向冒泡示例

对 $[1, 1, 0]$ 执行正向冒泡：$[1, 1, 0] \to [1, 1, 0]$（$1 \le 1$，不换）$\to [1, 0, 1]$（$1 > 0$，交换）。结果：$[1, 0, 1]$。

### 反向冒泡示例

对 $[1, 1, 0]$ 执行反向冒泡：从右往左，$i = 1$：$a_1 = 1 > a_2 = 1$? 否，不换；然后看 $i = 0$... 实际上反向冒泡从 $i = m-1$ 到 $i = 1$：$[1, 1, 0] \to [1, 0, 1]$（$a_2 = 1 > a_3 = 0$，交换）$\to [0, 1, 1]$（$a_1 = 1 > a_2 = 0$，交换）。结果：$[0, 1, 1]$。

## 输入格式

- 第一行：$t$（$1 \le t \le 10^4$）— 测试组数
- 每组：
  - 第一行：$n$（$1 \le n \le 5 \times 10^5$）
  - 第二行：$a_1, a_2, \ldots, a_n$（$a_i \in \{0, 1\}$）
  - 第三行：$s$（$s_i \in \{0, 1\}$，$|s| = n$）

保证所有测试组的 $n$ 之和不超过 $5 \times 10^5$。

## 输出格式

每组输出 $n+1$ 个空格分隔的整数，第 $i$ 个表示前 $i-1$ 次操作后的逆序对数。

## 样例

### 样例输入

```
1
6
1 1 0 0 1 0
1001
```

### 样例输出

```
7 4 2 0 0
```

### 样例推演

初始数组 $a = [1,1,0,0,1,0]$，$s = [1,0,0,1]$：

| 步骤 | 操作 | 数组变化 | 逆序对 | 说明 |
|------|------|---------|--------|------|
| 初始 | — | $[1,1,0,0,1,0]$ | 7 | 3 个 0，各自前面有 2, 2, 3 个 1 |
| 1 | 正向 | $[1,0,0,1,0,1]$ | 4 | 最左 1 冲到队尾，穿过 3 个 0 |
| 2 | 反向 | $[0,1,0,0,1,1]$ | 2 | 最右 0 搬到队首，减去最大账 2 |
| 3 | 正向 | $[0,0,0,1,1,1]$ | 0 | 水位再涨 1，剩余 2 根柱子全没顶 |
| 4 | 反向 | $[0,0,0,1,1,1]$ | 0 | 已有序，空操作 |

## 解题思路

### 核心建模：逆序对 = 每个 0 的"账"

01 数组中，逆序对 $=$ 前面的 $1$ 与后面的 $0$ 组成的对。按 $0$ 归账：第 $i$ 个 $0$ 前面有几个 $1$，它就贡献几对。

设 $d_i$ 为第 $i$ 个 $0$ 前面的 $1$ 的个数，则：

$$\text{inv} = \sum_{i=1}^{\text{cnt0}} d_i$$

**建表**：一遍扫描，`cnt1` 遇 $1$ 加一、遇 $0$ 记账（`inv += cnt1; count[cnt1]++; A.push_back(cnt1)`）。

**两条免费性质**（省掉排序和堆）：

1. `cnt1` 只增不减 $\Rightarrow$ $d$ 沿位置非降 $\Rightarrow$ $A[1 \ldots \text{cnt0}]$ 天然有序
2. "当前最大的账"永远是幸存段的最后一根 $A[k]$

### 正向操作（$s_i = 1$）：水位 +1

正向冒泡使最左的 $1$ 一路向右穿过挡道的 $0$。$0$ 在最左 $1$ 右边 $\Leftrightarrow$ 它的 $d \ge 1$。每被穿过一次，那个 $0$ 前面恰好少一个 $1$ $\Rightarrow$ 所有 $d \ge 1$ 的账各减 $1$，$d = 0$ 的不动。

复合 $T$ 次后：$d \to \max(d - T, 0)$，减到 $0$ 封底不为负。

### 反向操作（$s_i = 0$）：删掉最大账

反向冒泡使最右的 $0$ 搬到队首。搬家只挪这一根 $0$，其他元素相对次序不变 $\Rightarrow$ 其他 $0$ 的账不动；搬家这根前面变成没有 $1$，账 $\to 0$。而 $d$ 沿位置非降，最右 $0$ 恰好是账最大的 $\Rightarrow$ 反向 $=$ 删掉当前最大的一笔账。

### 懒标记（水位模型）

逐个减账是每次 $O(n)$。改成记账不记账面：

| 变量 | 含义 |
|------|------|
| `lazy1 = T` | 正向操作总次数 $=$ 水位 |
| `lazy0` | 已拆掉的柱子数（反向操作次数） |
| `A` | 冻结的账本，柱子真实高度 $= \max(A_i - T, 0)$ |
| 幸存柱 | $A[1 \ldots k]$，$k = \text{cnt0} - \text{lazy0}$ |

**总不变式**（一切正确性的核心）：

$$\text{inv} = \sum_{i=1}^{k} \max(A_i - \text{lazy1}, 0)$$

且它等于真实数组的逆序对数。柱子同步沉降（都减同一个 $T$）、拆的又总是最高的，所以幸存者永远是前缀。

**正向**：水位 $+1$；`inv` 减去"涨水前还露在水面上的幸存柱数"（它们各降 $1$）。

**反向**：拆掉 $A[k]$；`inv` 减去它当时的露出高度 $= A[k] - \text{lazy1}$。

### 吸收态：inv = 0（本代码的灵魂）

$\text{inv} = 0$ $\Leftrightarrow$ 全部幸存柱真实高度为 $0$ $\Leftrightarrow$ 数组已排成 $00 \cdots 011 \cdots 1$。

$T$ 只涨、$k$ 只减 $\Rightarrow$ 一旦归零永远为零。有序数组上两种冒泡物理上都是空操作。代码用 `if (inv)` 罩住整个操作处理，归零后全部跳过。

**附赠安全保证**：$\text{inv} > 0$ $\Rightarrow$ 幸存非空 $\Rightarrow$ $\text{idx} \ge 1$，永不越界。

### 新产生的 0 不用记账

正向操作后数组尾部可能新增 $0$（最左 $1$ 冲到队尾变成... 实际上 1 变成在队尾，0 不会新增）。反向操作后队首新增 $0$。① 它账值 $0$，水位只涨，真实值永远 $0$；② 反向删的永远是最大值，账 $0$ 的永远轮不到它。

## 逐行代码解析

### 建表阶段

```cpp
long long inv = 0;
int cnt0 = 0, cnt1 = 0;
vector<int> count(n + 1);
vector<long long> A(1);

for (int i = 1; i <= n; i++)
{
    if (a[i] == '0')
    {
        cnt0++;
        inv += cnt1;
        count[cnt1]++;
        A.emplace_back(cnt1);
    }
    else cnt1++;
}

for (int i = 1; i <= n; i++) count[i] += count[i - 1];
```

| 行 | 代码 | 解析 |
|----|------|------|
| 1 | `long long inv = 0;` | 逆序对总数，必须 `long long`（上界 $n^2/4 \approx 6 \times 10^{10}$） |
| 2 | `int cnt0 = 0, cnt1 = 0;` | 0 和 1 的计数器 |
| 3 | `vector<int> count(n + 1);` | `count[v]` 记录 $d = v$ 的 0 的个数，后续做前缀和 |
| 4 | `vector<long long> A(1);` | 账本数组，`A[0] = 0` 作为哨兵 |
| 5-12 | `for (int i = 1; i <= n; i++)` | 一遍扫描建表 |
| 7 | `inv += cnt1;` | 遇到 0，它前面有 `cnt1` 个 1，贡献 `cnt1` 对 |
| 8 | `count[cnt1]++;` | 记录 $d = \text{cnt1}$ 的 0 多了一个 |
| 9 | `A.emplace_back(cnt1);` | 把账值压入账本（天然有序） |
| 14 | `count[i] += count[i - 1];` | 前缀和：`count[v]` 变为 $d \le v$ 的 0 的总个数 |

### 操作阶段

```cpp
int lazy0 = 0, lazy1 = 0;
cout << inv << ' ';
for (int i = 1; i <= n; i++)
{
    if (inv)
    {
        if (s[i] == '1')
        {
            lazy1++;
            int ct = cnt0 - count[lazy1 - 1] - lazy0;
            if (ct > 0) inv -= ct;
        }
        else
        {
            lazy0++;
            int idx = cnt0 - lazy0 + 1;
            if (A[idx] - lazy1 > 0) inv -= A[idx] - lazy1;
        }
    }
    cout << inv << ' ';
}
```

| 行 | 代码 | 解析 |
|----|------|------|
| 1 | `int lazy0 = 0, lazy1 = 0;` | 两个懒标记：水位和拆柱数 |
| 2 | `cout << inv << ' ';` | 输出初始逆序对数 |
| 4 | `if (inv)` | **吸收态卫兵**：inv = 0 时整个操作跳过 |
| 6 | `lazy1++;` | 正向：水位先 +1 |
| 7 | `int ct = cnt0 - count[lazy1 - 1] - lazy0;` | 计算涨水前还露面的幸存柱数 |
| 8 | `if (ct > 0) inv -= ct;` | 每根露面柱各降 1，inv 减去露面数量 |
| 10-11 | `lazy0++; int idx = cnt0 - lazy0 + 1;` | 反向：先拆一根，`idx` 指向被拆柱（拆之前的幸存数 $k$） |
| 12 | `if (A[idx] - lazy1 > 0) inv -= A[idx] - lazy1;` | 被拆柱的露出高度 $=$ inv 减少量 |

**正向分支 `ct` 逐项拆解**：

$$\text{ct} = \text{cnt0} - \text{count}[T_{\text{旧}}] - \text{lazy0}$$

- $\text{cnt0} - \text{count}[T_{\text{旧}}]$：全体 0 中 $d > T_{\text{旧}}$ 的根数
- $- \text{lazy0}$：去掉已拆的

**为什么 `count` 不用做"幸存修正"**：进入分支前提 $\text{inv} > 0$ $\Rightarrow$ 最大幸存账 $A[k] > T_{\text{旧}}$ $\Rightarrow$ 已拆的（都 $\ge A[k]$）全 $> T_{\text{旧}}$，一根都不在 $\text{count}[T_{\text{旧}}]$ 里。

**反向分支 `idx` 推导**：拆之前 $k = \text{cnt0} - \text{lazy0}_{\text{旧}} = \text{cnt0} - \text{lazy0}_{\text{新}} + 1$，正是被拆那根的下标。`A[idx]` 是账面原值，`A[idx] - lazy1` 是它被拆那一刻的真实高度。

## 复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | $O(n)$ | 建表一遍扫描 $O(n)$ + 前缀和 $O(n)$ + 每操作 $O(1)$ |
| 空间 | $O(n)$ | `count` 数组 + `A` 数组 + 输入数组 |

**关键规模分析**：
- `inv` 上界 $n^2 / 4 \approx 6 \times 10^{10}$（$n = 5 \times 10^5$），必须用 `long long`
- `A` 数组存储 `long long` 类型（虽然 $d_i \le n$ 用 `int` 足够，但为安全用 `long long`）
- `count` 数组用 `int` 足够（计数不超过 $n$）

## 常见陷阱与注意事项

### 1. A 不能预开 $n+1$ 个 0 再 `emplace_back`

如果写成 `vector<long long> A(n + 1, 0)` 再 `emplace_back`，数据整体错位（前面多出 $n+1$ 个无意义的 0）。正确姿势：`A(1)` 只放哨兵 $A[0] = 0$，且 `A` 不做前缀和（它要取单值）。

### 2. $d = 0$ 的 0 也要入 `count` 和 `A`

贡献虽恒为 $0$，但必须占坑，否则位置计数全错。`count[0]` 记录了 $d = 0$ 的 0 的个数，它们在水位 $0$ 时就"没顶"，但数量必须正确。

### 3. `lazy0` 只能数"拆成功"的反向操作

归零后的反向操作是空操作，指针不能虚移。本版用 `if (inv)` 卫兵等价实现：归零后 `lazy0` 不再增加。

### 4. 数学空操作 $\ne$ 代码空操作

有序后若照跑，`idx` 会一路左移出界，`A[idx]` 读到垃圾值再污染 `inv`（WA/RE 的真凶）。卫兵 `if (inv)` 从根上断掉这条路。

### 5. `count` 做了前缀和，`A` 没做

两个查询工具的语义不同：

| 结构 | 含义 | 用途 |
|------|------|------|
| `count[v]`（已前缀和） | 全体 0 中 $d \le v$ 的根数 | $O(1)$ 知道水位下没顶多少根 |
| `A[0 \ldots \text{cnt0}]` | $A[0] = 0$ 哨兵，$A[1 \ldots \text{cnt0}]$ 为 $d$ 原值 | 按下标取单值（注意它不做前缀和！） |

### 6. `if (ct > 0)` 和 `if (A[idx] - lazy1 > 0)` 是冗余保险

$\text{inv} > 0$ 时必有 $\text{ct} > 0$（正向）和 $A[\text{idx}] > \text{lazy1}$（反向），留着无害，作为安全冗余。

### 7. 全 1 / 全 0 的退化输入

全 1：`cnt0 = 0`，`inv = 0`，卫兵直接接管，不越界。全 0：`cnt1 = 0`，`inv = 0`，同理。无需特判。
