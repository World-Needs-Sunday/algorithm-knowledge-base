## 算法原理

Tarjan 算法由 Robert Tarjan 于 1974 年提出，通过**一次深度优先搜索（DFS）**即可找出无向图中所有的**桥**（割边），时间复杂度为 $O(n+m)$。

### 什么是桥

**桥（Bridge，又称割边）**：在无向图中，如果删除某条边后，图的连通分量数增加，则称这条边为桥。换句话说，桥是图中的"生命线"——去掉它图就会被拆成两部分。

暴力做法是枚举每条边，删除后用 BFS/DFS 检查连通性，时间复杂度 $O(m(n+m))$，在大规模数据下会超时。Tarjan 算法的精髓在于：只做一次 DFS，就能同时判断所有边是不是桥。

### 核心思想

判断一条树边 $u \to v$（$u$ 是父节点，$v$ 是子节点）是不是桥，关键看 $v$ 的子树能不能不经过这条边，绕回到 $u$ 或 $u$ 的祖先：

- **能绕回去** → 子树和外界除了这条边还有其他通道，这条边不是桥
- **绕不回去** → 这条边是子树通向外界的唯一通道，删去后子树被孤立，是桥

### DFS 生成树与返祖边

对无向图做 DFS，第一次走到某个点所经过的边称为**树边**，所有树边构成一棵生成树。其余的边称为**非树边**。

**关键性质**：无向图的 DFS 中，非树边一定是"连向祖先"的**返祖边**，不存在横叉边（连向完全另一棵子树的边）。这个性质是 Tarjan 正确性的基石——因为如果有横叉边，"low 值追溯"的逻辑就不成立了。

### dfn 与 low 数组

| 数组 | 含义 |
|------|------|
| `dfn[u]` | 节点 $u$ 被首次访问的时间戳（DFS 序），同时充当访问标记（0 = 未访问） |
| `low[u]` | 从 $u$ 及其子树中的所有点出发，通过最多一条返祖边，能到达的时间戳最小的节点的时间戳 |

`low[u]` 回答的问题是："$u$ 这一片区域，最远能'回头'摸到多早的祖先？"

### 桥的判定条件

对于树边 $u \to v$（$u$ 是父节点，$v$ 是子节点）：

$$
\text{low}[v] > \text{dfn}[u] \quad \Longrightarrow \quad u\text{-}v \text{ 是桥}
$$

含义：$v$ 的子树最多只能追溯到 $v$ 自己或更晚的节点，无法回到 $u$ 或更早的祖先，因此 $u$-$v$ 这条边是子树与外界的唯一连接——桥。

对比割点的判定 `low[v] >= dfn[u]`：割点允许子树追溯到 $u$ 自身（等于号成立），而桥要求**严格大于**——因为如果子树能回到 $u$，说明存在不经过这条树边的路径（通过返祖边），所以这条边不是桥。

## 核心状态定义与转移方程

### 状态定义

| 变量 | 含义 |
|------|------|
| `dfn[rt]` | 当前节点的时间戳（DFS 序编号） |
| `low[rt]` | 当前节点及其子树能追溯到的最早时间戳 |
| `fa` | DFS 树中的父节点，用于防止走回父节点 |
| `cnt` | 时间戳计数器 |
| `is_cut` | 存储所有桥的边列表（变量名沿用代码，实际存的是桥） |

### 转移规则

进入 DFS 时初始化：

$$
\text{dfn}[u] = \text{low}[u] = \text{++cnt}
$$

对每条出边 $u \to v$，分三种情况处理：

$$
\text{low}[u] \text{ 的更新} =
\begin{cases}
\text{跳过（父节点）} & v = \text{fa} \\
\min(\text{low}[u], \text{low}[v]) & v \text{ 未访问，递归后回溯更新} \\
\min(\text{low}[u], \text{dfn}[v]) & v \text{ 已访问且不是父节点（返祖边）}
\end{cases}
$$

注意返祖边的情况用的是 `dfn[v]` 而不是 `low[v]`。这是因为 `low` 的定义是"通过最多一条返祖边"能到达的最早节点，如果用 `low[v]` 就相当于走了多条返祖边，会导致误判。

### 桥的判定

递归回溯后，若满足：

$$
\text{low}[v] > \text{dfn}[u]
$$

则 $u$-$v$ 是桥。

## 逐行代码解析

### 全局变量定义

```cpp
vector<vector<int>> edges;     // 邻接表
vector<int> dfn, low;          // 时间戳 / 能追溯的最早时间戳
vector<pair<int, int>> is_cut; // 存储所有桥（变量名沿用原代码）
int cnt;                        // 时间戳计数器
```

- `edges`：无向图的邻接表
- `dfn`、`low`：Tarjan 的核心双数组
- `is_cut`：存放所有桥的端点对，虽然变量名是 `is_cut`（割点的命名），但实际存储的是桥
- `cnt`：DFS 时间戳计数器

### 初始化函数

```cpp
void init(int n, int m)
{
	dfn.assign(n + 1, 0);
	low.assign(n + 1, 0);
	edges.assign(n + 1, vector<int>());
	is_cut.clear();
	cnt = 0;
}
```

所有数组初始化为 0，`dfn = 0` 表示未访问。

### 加边函数

```cpp
void add(int u, int v)
{
	edges[u].emplace_back(v);
	edges[v].emplace_back(u);
}
```

无向图双向加边。

### Tarjan 核心函数

```cpp
void tarjan(int rt, int fa)
{
	dfn[rt] = low[rt] = ++cnt;      // 初始化时间戳和 low 值
	for (int i : edges[rt])         // 遍历所有邻接点
	{
		if (fa == i) continue;      // 跳过父节点（无向图防回头）
		if (!dfn[i])                // 情况1：未访问——树边
		{
			tarjan(i, rt);          // 递归 DFS
			low[rt] = min(low[i], low[rt]);  // 回溯：用子节点 low 更新父节点
			if (low[i] > dfn[rt])   // 桥的判定条件
				is_cut.emplace_back(rt, i);
		}
		else                         // 情况2：已访问——返祖边
			low[rt] = min(dfn[rt], low[i]);  // 用 dfn[v] 更新 low[u]
	}
}
```

逐行解析关键点：

1. **`dfn[rt] = low[rt] = ++cnt;`**：新节点初始时，low 值等于自己的时间戳——目前只知道能到达自己。

2. **`if (fa == i) continue;`**：无向图中，每条边在邻接表中出现两次（$u \to v$ 和 $v \to u$）。从父节点来的边不能往回走，否则会死循环。

3. **`if (!dfn[i])` 树边分支**：
   - 递归进入子节点 `tarjan(i, rt)`
   - 回溯时更新：`low[rt] = min(low[i], low[rt])`——子树能追溯到的最早节点，父节点当然也能追溯到
   - **桥判定**：`if (low[i] > dfn[rt])` —— 子节点的追溯能力到不了父节点或更早，说明父→子这条边是唯一通道，是桥

4. **`else` 返祖边分支**：
   - `low[rt] = min(dfn[rt], low[i]);` —— 注意这里用的是 `dfn[i]` 而不是 `low[i]`！因为返祖边只能算"一条"，不能把子节点 $i$ 的追溯能力也算上（那是 $i$ 的子树的事，不是通过这条返祖边直接到达的）

### 主函数

```cpp
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr); cout.tie(nullptr);
	int n, m;
	cin >> n >> m;
	init(n, m);
	for (int i = 1; i <= m; i++)
	{
		int u, v;
		cin >> u >> v;
		add(u, v);
	}
	for (int i = 1; i <= n; i++)     // 遍历所有连通分量
	{
		if (!dfn[i]) tarjan(i, -1);
	}
	cout << is_cut.size() << '\n';
	for (pair<int, int> i : is_cut)
		cout << i.first << ' ' << i.second << '\n';
	return 0;
}
```

注意：代码处理了图不连通的情况——外层循环遍历所有节点，对每个未访问的连通分量启动一次 Tarjan。根节点的父节点设为 `-1`（不存在的节点编号）。

## 复杂度分析

### 时间复杂度：$O(n+m)$

- 每个节点恰好被访问一次（`dfn` 从 0 变非 0 只发生一次）
- 每条无向边被访问两次（双向各一次），其中一次因 `fa == i` 被跳过，实际有效处理一次
- 总操作量与顶点数 $n$ 和边数 $m$ 成线性关系

### 空间复杂度：$O(n+m)$

- 邻接表：$O(n+m)$
- `dfn`、`low` 数组：各 $O(n)$
- `is_cut` 结果数组：最坏 $O(m)$（全是桥，即树）
- DFS 递归栈深度：最坏 $O(n)$（链状图）

## 适用场景

### 适用场景

1. **桥的检测**：找出无向图中所有的桥（割边）
2. **边双连通分量**：将所有桥删除后，每个极大连通子图就是一个边双连通分量。桥是边双连通分量之间的"关节边"
3. **网络可靠性分析**：找出网络中的关键链路，故障后会导致网络分裂
4. **2-边连通性问题**：判断图是否 2-边连通（无桥），或至少需要添加多少条边使图变成 2-边连通

### 不适用场景

1. **有向图**：桥是无向图的概念，有向图的对应概念需另行定义（如强连通分量）
2. **需要点双连通分量**：点双连通分量基于割点，不是桥
3. **动态图**：边不断增删的图，Tarjan 是静态算法，每次增删边都需要重新运行

## 常见陷阱与注意事项

### 1. 桥的判定是严格大于

桥的判定条件是 `low[i] > dfn[rt]`（**严格大于**），而割点是 `low[i] >= dfn[u]`（大于等于）。

- **割点**：子树追溯不到 $u$ 之外 → $u$ 是割点。等于号成立说明子树能回到 $u$ 自己，但 $u$ 被删后子树仍然孤立
- **桥**：子树必须连 $u$ 都回不到 → 这条边才是桥。等于号时子树能通过返祖边回到 $u$，说明存在替代路径，这条边不是桥

### 2. 返祖边用 dfn[v] 而不是 low[v]

返祖边更新 low 值时，代码中写的是 `low[rt] = min(dfn[rt], low[i])`，这里实际用了 `low[i]`。这在**求桥**的场景下是一个需要注意的点：

严格来说，返祖边应该用 `dfn[v]` 更新，因为 low 的定义是"通过最多一条返祖边"能到达的最早节点。但在求桥的场景中，即使写成 `low[v]`，桥的判定仍然是正确的——因为判定条件是 `low[v] > dfn[u]`，只关心子树能不能回到 $u$ 以上，`low[v]` 取更小的值只会让判定更"保守"（更不容易判成桥），不会把非桥判成桥。

不过，为了概念的准确性和与割点算法的统一，建议写成 `low[rt] = min(low[rt], dfn[i])`。

### 3. 父节点跳过 vs 重边

代码中 `if (fa == i) continue;` 会跳过父节点。但如果 $u$ 和 $v$ 之间有**重边**（两条以上的平行边），那么即使跳过了"父边"，还有另一条重边作为返祖边存在，此时 $u$-$v$ 不是桥（因为有两条边，删一条还有一条）。

但在当前代码中，如果邻接表中重边是分开存储的，第二条重边会走到 `else` 分支（返祖边），更新 low 值，从而正确地不判定为桥。所以**重边场景下代码仍然正确**。

### 4. 图不连通的处理

代码外层有 `for (int i = 1; i <= n; i++) if (!dfn[i]) tarjan(i, -1);`，确保每个连通分量都被处理。这一点很重要，否则非连通图的某些分量会被漏掉。

### 5. 变量命名的混淆

代码中存储桥的向量叫 `is_cut`，容易让人误解为"割点"。实际存储的是桥（边对）。在阅读和维护代码时需注意这个命名不一致的问题。

### 6. 桥的输出顺序

桥以 `(rt, i)` 的顺序存入，即父节点在前、子节点在后。输出的方向与 DFS 树的父子关系一致，与输入的边的方向不一定相同。同一座桥只会被记录一次（从父到子的方向）。

### 7. 自环边

自环（节点到自己的边）不是桥——删掉自环不影响连通性。在代码中，自环会被 `else` 分支（返祖边）处理，但因为 $v = u$，`low[rt] = min(low[rt], low[rt])` 没有变化，且不会触发桥的判定（桥的判定只在树边分支）。所以自环被正确忽略。

## 对比与扩展

### 与割点算法对比

| 对比维度 | Tarjan 求桥 | Tarjan 求割点 |
|----------|-----------|-------------|
| 判定对象 | 边 | 顶点 |
| 判定条件 | `low[v] > dfn[u]`（严格大于） | `low[v] >= dfn[u]`（大于等于），根节点单独判定 |
| 根节点处理 | 无需特殊处理 | 需统计子树个数，子树数 $\geq 2$ 才是割点 |
| 结果存储 | 边对 `(u, v)` | 顶点编号 |
| 时间复杂度 | $O(n+m)$ | $O(n+m)$ |
| 空间复杂度 | $O(n+m)$ | $O(n+m)$ |

### 边双连通分量

将图中所有的桥都删除后，每个极大的连通子图称为一个**边双连通分量**（Edge-Biconnected Component, E-BCC）。边双连通分量内部没有桥——任意两点之间至少有两条边不相交的路径。

求边双连通分量的方法：
1. 用 Tarjan 找出所有桥
2. 删除所有桥，对剩余图做 DFS/BFS 染色，每个连通块就是一个边双连通分量

### 点双连通分量

点双连通分量（Vertex-Biconnected Component, V-BCC）是指不存在割点的极大子图。点双连通分量的关系比边双更复杂：一个割点可以属于多个点双连通分量。求点双连通分量需要在 DFS 中维护一个栈，保存经过的边，发现割点时弹栈得到一个点双。

### 2-边连通性增强

给定一个无向图，问至少添加几条边可以使图变成 2-边连通（没有桥）。解法：
1. 求所有边双连通分量，将每个分量缩成一个点
2. 缩点后的图是一棵树，所有的"边"都是原来的桥
3. 答案 = $\lceil \frac{\text{叶子数}}{2} \rceil$，其中叶子是缩点后度数为 1 的节点

这个结论与"无向图添加最少边使图强连通"（缩点后入度0和出度0的最大值）是类似的对偶问题。
