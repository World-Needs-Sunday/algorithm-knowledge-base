## 算法原理

边双连通分量（Edge-Biconnected Component，E-DCC）缩点是**求桥算法的自然延伸**：在 Tarjan 找出所有桥的基础上，把每个极大的"无桥子图"缩成一个"超级点"，用桥连接这些超级点，得到一棵**缩点树**。缩点后，原图中复杂的环和冗余路径被压缩成单个节点，许多问题（如 2-边连通性增强、路径上的桥计数）可以在树上高效解决。

### 边双连通分量的定义

- **边双连通（2-边连通）**：一个无向图是边双连通的，当且仅当它**没有桥**。等价地，任意两点之间至少存在两条**边不相交**的路径。
- **边双连通分量（E-DCC）**：无向图中的极大边双连通子图。"极大"意味着不能再添加任何节点使它仍然边双连通。

直观理解：把图中所有的桥都"剪断"，剩下的每个连通块就是一个边双连通分量。

### 核心思想：Tarjan + 栈划分分量

Tarjan 求桥的过程中，我们可以**利用栈记录 DFS 路径上的节点**。每当发现一条桥（子节点追溯不到父节点），就把栈中从栈顶到子节点的所有节点弹出，它们构成一个边双连通分量。

这与 SCC 缩点的"Tarjan + 栈"思路非常相似，区别在于：
- SCC 缩点判定条件是 `low[v] == dfn[u]`（强连通分量的根）
- E-DCC 缩点判定条件是 `low[v] > dfn[u]`（发现桥，桥的两侧是不同的边双连通分量）

### 缩点的意义

缩点后的图有一个关键性质：**它是一棵树（或森林）**。

证明：假设缩点后的图中有环，那么环上的"超级点"之间可以通过环的两条路径连通，说明这些超级点之间的边都不是桥（因为有替代路径），与桥的定义矛盾。因此缩点后的图无环，是一棵树。

这棵树上的每条边都对应原图中的一座桥。树上任意两点之间的路径，对应原图中这两个边双连通分量之间必须经过的所有桥。

### 算法步骤总览

1. **Tarjan 求桥 + 栈划分**：DFS 遍历，用栈保存路径节点，发现桥时弹出子节点及其以上的所有节点作为一个 E-DCC
2. **逐连通分量收尾**：每个连通分量的 Tarjan 结束后，栈中剩余节点构成该连通分量最靠近根的 E-DCC，立即弹出
3. **构建缩点图**：遍历原图每条边，若两个端点属于不同的 E-DCC，则在缩点图中加一条超级边

## 核心状态定义与转移方程

### 状态定义

| 变量 | 类型 | 含义 |
|------|------|------|
| `dfn[u]` | `int` | 节点 $u$ 的 DFS 时间戳，0 表示未访问 |
| `low[u]` | `int` | 节点 $u$ 及其子树通过最多一条返祖边能到达的最早时间戳 |
| `sk[]` | 数组（栈） | 保存当前 DFS 路径上尚未确定所属分量的节点 |
| `top` | `int` | 栈顶指针 |
| `col[u]` | `int` | 节点 $u$ 所属的边双连通分量编号 |
| `col_cnt` | `int` | 边双连通分量的总数 |
| `ans[k]` | `vector<int>` | 第 $k$ 个边双连通分量包含的所有节点 |
| `e_DCC_edges[k]` | `vector<int>` | 缩点图中第 $k$ 个超级点的邻接表 |
| `tim` | `int` | 时间戳计数器 |
| `cnt` | 局部 | 重边处理计数器（只跳第一条父边） |

### Tarjan 转移规则

与 Tarjan 求桥完全一致：

$$
\text{low}[u] =
\begin{cases}
\text{跳过（第一条父边）} & v = \text{fa} \text{ 且 } \text{cnt} = 0 \\
\min(\text{low}[u], \text{low}[v]) & v \text{ 未访问，递归回溯后} \\
\min(\text{low}[u], \text{dfn}[v]) & v \text{ 已访问（返祖边/重边）}
\end{cases}
$$

### 分量划分规则

当回溯到父节点 $u$ 时，若发现桥 $u$-$v$（$v$ 是子节点）：

$$
\text{low}[v] > \text{dfn}[u] \quad \Longrightarrow \quad \text{弹出栈中 } v \text{ 及其以上节点，构成一个 E-DCC}
$$

弹栈条件为 `while (sk[top] != v)`：`top` 指向栈顶的下一格（即已弹出但未清除的旧数据位置），逐个 `--top` 弹出 $v$ 的所有后代，当 `sk[top] == v` 时说明已弹到 $v$ 自身的位置，循环停止。此时 $v$ 已被弹出并归入该分量，而 $u$ 仍在栈中（属于父侧分量）。

### 缩点图构建规则

对原图每条边 $i$-$j$：

$$
\text{若 } \text{col}[i] \neq \text{col}[j] \text{ 且尚未加边} \quad \Longrightarrow \quad \text{在缩点图中加边 } \text{col}[i] \leftrightarrow \text{col}[j]
$$

用 `vis[v] == u` 标记法避免重复加边（同一个超级点对之间只加一条边）。

## 逐行代码解析

### 全局变量定义

```cpp
vector<vector<int>> edges, ans, e_DCC_edges;  // 原图邻接表 / 各分量节点 / 缩点图邻接表
vector<int> dfn, low, sk, col;                 // 时间戳 / low值 / 栈 / 分量编号
int tim, top, col_cnt;                          // 时间戳 / 栈顶 / 分量数
```

三组邻接表各司其职：
- `edges`：原图的邻接表
- `ans`：`ans[k]` 存第 $k$ 个边双连通分量的所有节点
- `e_DCC_edges`：缩点后的树的邻接表

### 初始化函数

```cpp
void init(int n, int m)
{
	dfn.assign(n + 1, 0);
	low.assign(n + 1, 0);
	edges.assign(n + 1, vector<int>());
	sk.assign(n + 1, 0);
	col.assign(n + 1, 0);
	ans.assign(1, vector<int>());    // ans[0] 占位，分量从 1 开始
	tim = 0;
	top = 0;
	col_cnt = 0;
}
```

注意 `ans.assign(1, vector<int>())` —— `ans` 预留了一个空的第 0 位，因为分量编号从 1 开始，这样 `ans[col_cnt]` 直接对应第 `col_cnt` 个分量。

### 加边函数

```cpp
void add(int u, int v)
{
	edges[u].emplace_back(v);
	edges[v].emplace_back(u);
}
```

无向图双向加边。

### mark 函数（入栈 + 打时间戳）

```cpp
inline void mark(int rt)
{
	dfn[rt] = low[rt] = ++tim;
	sk[top++] = rt;
}
```

将初始化时间戳和入栈操作封装成一个内联函数。新节点被访问时，先打时间戳，再压入栈中——表示这个节点"待分配分量"。

### Tarjan 核心函数

```cpp
void tarjan(int rt, int fa)
{
	int cnt = 0;
	mark(rt);                           // 打时间戳 + 入栈
	for (int i : edges[rt])
	{
		if (fa == i && !cnt)            // 只跳过第一条父边（重边处理）
		{
			++cnt;
			continue;
		}
		if (!dfn[i])                    // 树边：递归 DFS
		{
			tarjan(i, rt);
			low[rt] = min(low[i], low[rt]);
			if (low[i] > dfn[rt])       // 发现桥，划分一个边双连通分量
			{
				++col_cnt;
				ans.emplace_back();
				while (sk[top] != i)    // 弹出到 i 的位置（弹出 i 及其所有后代）
				{
					col[sk[--top]] = col_cnt;
					ans[col_cnt].emplace_back(sk[top]);
				}
			}
		}
		else                             // 返祖边 / 重边
			low[rt] = min(dfn[i], low[rt]);
	}
}
```

逐段解析：

1. **`int cnt = 0;`**：局部重边计数器，只跳过第一条父边。

2. **`mark(rt);`**：打时间戳并入栈。

3. **树边分支 + 桥判定**：
   - `low[i] > dfn[rt]` 表示 $i$ 的子树追溯不到 `rt` 或更早，`rt`-$i$ 是桥
   - 发现桥后，弹出 $i$ 及其所有后代，构成一个边双连通分量
   - `while (sk[top] != i)` —— `top` 指向栈顶的下一格（已弹出但未清除的旧数据位置）。循环体先 `--top` 再处理 `sk[top]`，即从栈顶逐个弹出 $i$ 的后代。当 `sk[top] == i` 时，说明已弹到 $i$ 自身的存储位置（$i$ 本身已在前一轮 `--top` 中被弹出），循环停止。此时 `rt` 仍在栈中，属于父侧分量
   - 弹出时设置 `col[节点] = col_cnt`，并加入 `ans[col_cnt]`

4. **返祖边分支**：用 `dfn[i]` 更新 `low[rt]`，保持 low 的正确定义。

### e_DCC 主流程函数

```cpp
void e_DCC(int n, int m)
{
	for (int i = 1; i <= n; i++)
	{
		if (!dfn[i]) tarjan(i, -1);
		if (top)                       // 每个连通分量结束后立即收尾
		{
			++col_cnt;
			ans.emplace_back();
			while (top)
			{
				col[sk[--top]] = col_cnt;
				ans[col_cnt].emplace_back(sk[top]);
			}
		}
	}

	// 构建缩点图
	e_DCC_edges.assign(col_cnt + 1, vector<int>());
	vector<int> vis(col_cnt + 1, 0);   // 标记数组，防止重复加边
	for (int u = 1; u <= col_cnt; u++)
	{
		for (int i : ans[u])           // 遍历分量 u 中的每个原图节点
		{
			for (int j : edges[i])     // 遍历该节点的所有出边
			{
				int v = col[j];        // 对端节点所属分量
				if (vis[v] == u || u == v) continue;  // 已加过 或 同一分量
				vis[v] = u;
				e_DCC_edges[u].emplace_back(v);
			}
		}
	}
}
```

分为两个阶段：

**阶段一：划分分量**

- 外层循环遍历所有节点，对每个未访问的节点启动 Tarjan
- **关键**：`if (top)` 收尾处理位于 for 循环**内部**，在每个连通分量的 Tarjan 结束后立即执行。栈中剩余的节点构成该连通分量最靠近根的边双连通分量，被弹出作为一个 E-DCC
- 这样做的原因：如果图不连通，多个连通分量的节点会先后入栈。若收尾放在循环外部，所有连通分量的剩余节点会被合并到同一个 E-DCC 中，导致划分错误

**阶段二：构建缩点图**

- 遍历每个超级点 $u$
- 对 $u$ 中的每个原图节点 $i$，遍历 $i$ 的所有出边
- 若对端节点 $j$ 属于另一个分量 $v$，且 $u$ 和 $v$ 之间还没加过边，则在缩点图中加边
- `vis[v] == u` 的技巧：用 $u$ 本身作为时间戳标记，这样每轮只需要一个 `vis` 数组而不需要每次清空

### 主函数

```cpp
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr); cout.tie(nullptr);
	int n, m;
	cin >> n >> m;
	init(n, m);
	for (int i = 1; i <= m; i++)
	{
		int u, v;
		cin >> u >> v;
		add(u, v);
	}
	e_DCC(n, m);
	cout << "e_DCC缩点后有 " << col_cnt << " 个边双连通分量" << '\n';
	for (int i = 1; i <= col_cnt; i++)
	{
		cout << "超级点" << i << "含有: ";
		for (int j : ans[i]) cout << j << ' ';
		cout << '\n';
		cout << "超级点" << i << "有" << e_DCC_edges[i].size() << "个点连接\n";
		for (int j : e_DCC_edges[i]) cout << j << ' ';
		cout << '\n';
	}
	return 0;
}
```

输出每个超级点包含的节点及其在缩点树中的邻接超级点。

## 复杂度分析

### 时间复杂度：$O(n+m)$

1. **Tarjan 求桥 + 栈划分**：每个节点入栈出栈各一次，每条边处理两次（双向），$O(n+m)$
2. **构建缩点图**：遍历每个分量的每个节点的每条边，总次数等于原图边数的两倍（无向图双向），$O(n+m)$
3. **栈操作**：每个节点恰好入栈一次、出栈一次，$O(n)$

总时间复杂度线性。

### 空间复杂度：$O(n+m)$

- 原图邻接表：$O(n+m)$
- `dfn`、`low`、`col`、`sk`：各 $O(n)$
- `ans`：存储所有节点的分量归属，总共 $O(n)$
- `e_DCC_edges`：缩点树的邻接表，有 `col_cnt - 1` 条边，$O(n)$（树的边数 = 点数 - 1）

## 适用场景

### 适用场景

1. **边双连通分量划分**：找出图中所有的边双连通分量
2. **2-边连通性增强**：给定无向图，求至少添加几条边使图变成 2-边连通（无桥）。答案 = $\lceil \frac{\text{缩点树叶子数}}{2} \rceil$
3. **路径必经边计数**：问两点之间路径上有多少座桥（必经边）。缩点后树上两点路径长度即为答案
4. **网络可靠性**：分析网络中哪些边故障会导致网络分裂，以及网络的"边连通度"结构
5. **图上问题转化为树**：将复杂图问题通过缩点转化为树上问题，利用树的性质（LCA、树形 DP、重链剖分等）高效求解

### 不适用场景

1. **点双连通分量**：需要点双连通分量（割点视角）时，应使用点双连通分量算法
2. **有向图强连通**：有向图的强连通分量用 Tarjan SCC 或 Kosaraju
3. **动态图**：边不断增删的图，缩点需要重建，不适合频繁修改

## 常见陷阱与注意事项

### 1. 弹栈条件用子节点做哨兵

发现桥时，弹栈的条件是 `while (sk[top] != i)`，其中 `i` 是子节点。`top` 指向栈顶的下一格（已弹出但未清除旧数据的位置），循环体先 `--top` 弹出元素，当 `sk[top] == i` 时说明已弹到 $i$ 自身的位置，循环停止。

此时 $i$ 及其所有后代已被弹出并归入该分量，而父节点 $rt$ 仍在栈中，属于父侧分量。

如果误用 `while (sk[top - 1] != rt)`（检查栈顶是否为父节点），在大部分情况下也能正确工作，但语义不够精确——应以子节点为哨兵，确保弹出的恰好是子节点及其后代。

### 2. 逐连通分量收尾（不能放在循环外）

每个连通分量的 Tarjan 结束后，栈中剩余的节点构成该连通分量最靠近根的边双连通分量。收尾代码 `if (top) { ... }` 必须放在外层 for 循环**内部**，在每个 `tarjan(i, -1)` 调用后立即执行。

**如果放在 for 循环外部**（所有 Tarjan 结束后才统一收尾），当图不连通时，多个连通分量的剩余节点会堆积在栈中，最终被合并为同一个 E-DCC，导致划分错误。

### 3. 重边处理与求桥一致

与求桥一样，缩点算法使用 `if (fa == i && !cnt)` 只跳过第一条父边，正确处理重边。如果重边被全部跳过，有重边的两个节点可能被错误地分到不同分量。

### 4. 缩点图的去重

构建缩点图时，同一对超级点之间可能有多条原图边对应（因为原图两个分量之间可能有多座桥）。代码中用 `vis[v] == u` 去重，确保每对超级点之间只加一条边。

如果不去重，缩点图就不是树了（会有重边），后续树上算法可能出错。

### 5. 分量编号从 1 开始

`col_cnt` 从 0 开始，每次发现新分量时 `++col_cnt`，所以分量编号是 $1, 2, \dots, \text{colCnt}$。`ans` 数组也预留了 `ans[0]` 作为占位。

如果下游代码假设分量从 0 开始编号，需要注意调整。

### 6. 图不连通时产生森林

如果原图不连通，缩点后得到的是**森林**（多棵树），每个连通分量对应一棵缩点树。做树上算法时需要遍历所有树的根。

### 7. 栈的大小

代码中 `sk.assign(n + 1, 0)` 预分配了 $n+1$ 的空间，这是足够的——每个节点最多入栈一次。但如果节点编号不是从 1 到 $n$，需要根据实际最大编号调整。

## 对比与扩展

### E-DCC 缩点 vs SCC 缩点

| 对比维度 | E-DCC 缩点（无向图） | SCC 缩点（有向图） |
|----------|---------------------|-------------------|
| 图类型 | 无向图 | 有向图 |
| 核心概念 | 边双连通（无桥） | 强连通（互相可达） |
| 判定条件 | `low[v] > dfn[u]`（桥） | `low[v] == dfn[u]`（分量根） |
| 弹栈方式 | 弹到子节点位置（不含父节点） | 弹到并包含根节点 |
| 缩点后结构 | 树 / 森林（无向） | DAG（有向无环图） |
| 典型应用 | 2-边连通增强、必经边 | 拓扑序 DP、可达性 |

### E-DCC 缩点 vs 点双连通分量（V-DCC）

| 对比维度 | E-DCC（边双） | V-DCC（点双） |
|----------|-------------|-------------|
| 删除对象 | 边（桥） | 顶点（割点） |
| 分量性质 | 任意两点有两条边不相交路径 | 任意两点有两条点不相交路径 |
| 节点归属 | 每个节点恰好属于一个 E-DCC | 割点可属于多个 V-DCC |
| 划分方式 | 删桥后各连通块 | 维护边栈，遇割点弹栈 |
| 缩点后结构 | 树 | 圆方树 |

### 扩展：2-边连通性增强问题

**问题**：给定无向图，至少添加几条边可以使图变成 2-边连通？

**解法**：
1. 求 E-DCC 并缩点，得到一棵树
2. 统计树中度为 1 的节点数（叶子数）$L$
3. 答案 = $\lceil \frac{L}{2} \rceil$

**直觉**：每添加一条边，可以连接两个叶子，使它们的度都变成 2，从而消除两个叶子。最优策略就是两两配对叶子。

### 扩展：圆方树（点双缩点）

边双缩点得到的是普通的树（节点是分量，边是桥）。点双缩点得到的结构更复杂——因为割点属于多个点双连通分量，需要用"圆方树"表示：每个点双连通分量变成一个"方点"，每个割点是"圆点"，圆点和方点之间通过割点的归属关系相连。圆方树也是一棵树，但节点类型有两种。

### 扩展：边三连通分量

比边双连通更强的概念：**边三连通**意味着删除任意两条边图仍然连通。求边三连通分量需要更复杂的算法（如基于链分解的算法），时间复杂度仍是线性但常数更大。
