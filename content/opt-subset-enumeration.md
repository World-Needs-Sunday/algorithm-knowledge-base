## 算法原理

**问题模型**：给定一个二进制掩码 $s$（第 $i$ 位为 1 表示元素 $i$ 在集合中），枚举 $s$ 的**所有子集**（包括空集与 $s$ 本身），每个子集恰好访问一次。

**核心递推**：从 $i=s$ 开始，循环执行

$$i \leftarrow (i-1)\ \&\ s$$

直到 $i=0$。这个式子是全部内容——「减一之后与 $s$」恰好跳到**下一个（数值上更小的）子集**。

**为什么恰好降序枚举全部子集（不重不漏）**：把 $i$ 只看作 $s$ 的位模式。

- **不漏**：任意子集 $t\subseteq s$ 都会在某轮被取到。反证：若 $t$ 被跳过，说明存在一步从 $i$ 直接跳到某个 $j<t<i$；但 $(i-1)\&s$ 只"借位"掉 $i$ 中属于 $s$ 的位，跳过的区间里的数在 $s$ 为 0 的位上可能为 1，它们本来就不是 $s$ 的子集——所有真子集按数值递减被逐个命中。
- **不重**：递推严格单调递减（$(i-1)\&s<i$），每个值至多出现一次。
- **终止**：单调递减到 0（空集），循环条件用 `i == 0` 显式 break。

**二进制输出辅助**：`write(n)` 用「从低位往高位剥、逆序输出」的方式打印 $n$ 的二进制形式：`do { ch[idx++] = (n & 1) + '0'; n >>= 1; } while (n)` 逐位取最低位，`while (idx) cout << ch[--idx]` 倒序回放。`do-while` 保证 $n=0$ 时也输出一个 `0`。

**为什么是位运算技巧**：子集枚举是状压 DP、容斥、子集卷积的内层发动机；这个 O(1) 步进的写法比「逐数判断是否为子集」快一整层循环，且天然降序，许多 DP 转移（先算小子集）正好需要这个顺序。

## 核心公式 / 状态定义与转移方程

**状态**：当前子集 $i$（始终满足 $i\ \&\ \sim s=0$，即 $i\subseteq s$）。

**转移**：

$$i_{next}=(i-1)\ \&\ s$$

**初始**：$i_0=s$；**终止**：$i=0$ 后 break。

**子集总数**：$2^{k}$，其中 $k=\text{popcount}(s)$——每个元素（位）独立决定在/不在，$k$ 个 1 位各两种选择。

**手算走读**（$s=1101_2=13$，即集合 $\{0,2,3\}$，$k=3$，应有 $2^3=8$ 个子集，本代码实测与下列完全一致）：

| 轮 | $i$ | 二进制 | 说明 |
|---|---|---|---|
| 0 | $13$ | 1101 | 全集本身 |
| 1 | $(13-1)\&13=12$ | 1100 | 去掉元素 0 |
| 2 | $(12-1)\&13=9$ | 1001 | 跳过 1011/1010（含 $s$ 的 0 位） |
| 3 | $(9-1)\&13=8$ | 1000 | |
| 4 | $(8-1)\&13=5$ | 0101 | 借位落到低段 |
| 5 | $(5-1)\&13=4$ | 0100 | |
| 6 | $(4-1)\&13=1$ | 0001 | |
| 7 | $(1-1)\&13=0$ | 0000 | 空集，break |

对照 $s=0$：$i=0$ 直接输出空集本身后 break（实测输出 `0`）。

## 逐行代码解析

代码拆成 2 个模块，按顺序拼接即完整程序。

### 模块 1 二进制输出函数

```cpp
#include<iostream>
using namespace std;
void write(unsigned int n)
{
	static char ch[40];
    int idx = 0;
    do 
	{
        ch[idx++] = (n & 1) + '0';
        n >>= 1;
    } while (n);
    while (idx) cout << ch[--idx];
}

```

- `static char ch[40]`：静态缓冲，40 字节足够 32 位二进制（最多 32 位 + 空余）；换 64 位掩码要同步扩容。
- `do-while` 而非 `while`：$n=0$ 时也必须输出一个字符 `'0'`（空集有合法表示），这是输出正确性的关键边界。
- `(n & 1) + '0'`：最低位转字符 `'0'/'1'`；`n >>= 1` 剥掉最低位——先低位后高位入栈，最后倒序弹出即正常二进制顺序。
- 索引 `idx` 从 0 递增、回放时 `ch[--idx]` 递减，天然栈式回放，不需要额外数组翻转。

### 模块 2 主函数与子集枚举

```cpp
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr); cout.tie(nullptr);
	unsigned int s;
	cin >> s;
	cout << "此数代表的2进制集合为: ";
	write(s); 
	cout << '\n';
	
	//主要代码 
	cout << "子集为: \n"; 
	for(unsigned int i = s;;i = (i - 1) & s)
	{
		write(i);
		cout << '\n';
		if(i == 0) break;
	}
	return 0;	
}
```

- 读入单个十进制掩码 $s$；先打印 $s$ 本身的二进制（"此数代表的2进制集合"）。
- `for(unsigned int i = s;; i = (i - 1) & s)`：三段式里**省略了循环条件**（等价于恒真），靠循环体内的 `if(i == 0) break` 终止——必须显式 break，否则 $i=0$ 之后 $(0-1)\&s$ 下溢回 $s$ 死循环。
- 每轮先 `write(i)` 输出当前子集，再判终止：所以空集也会被打印一次，输出顺序是 $s$ → 逐层递减 → 0。
- `i` 用 `unsigned int`：递推依赖无符号减法下溢语义（$0-1$ 是 $2^{32}-1$，与 $s$ 后回到某个子集）；用有符号 `int` 在 $i=0$ 处是未定义行为。

## 复杂度分析

- 每个子集恰好一次递推（一次减、一次与，$O(1)$）→ 总时间 $O(2^k)$，$k=\text{popcount}(s)$。
- 空间 $O(1)$（除输出缓冲外无额外数组）；输出本身 $O(2^k\cdot \log s)$ 字符，属演示开销。
- 对比逐数判断法：对 $0..s$ 每个数做 `(x & ~s)==0` 判断是 $O(2^{\text{bitlen}(s)})$，本写法是 $O(2^{\text{popcount}(s)})$——当 $s$ 稀疏（1 少 0 多）时差距指数级。

## 适用场景

**适用**：状压 DP 的「枚举当前集合的所有子集做转移」（如集合划分、斯坦纳树、子集和）；容斥/子集卷积中遍历子集；枚举"删掉哪些元素"的决策。递推天然降序，恰好匹配「先算小子集、再算大集合」的 DP 顺序。

**特别适合**：$k\le20$ 的常规状压（$2^k\le10^6$ 完全可承受）；配合 `__builtin_popcount`、`lowbit` 等位运算内建函数可组合出完整的状态机。

**不适用**：$k$ 接近 30 及以上（$2^k$ 爆炸，输出型演示尤其要卡住 $k$）；需要按特定顺序（如按大小、按格雷码序）枚举时换对应技巧；集合元素超 64 位时换 `bitset` 或数组化枚举。

## 常见陷阱与注意事项

1. **必须显式 break**：`for(;;)` 省略条件后，漏掉 `if(i==0) break` 会在 $i=0$ 后下溢回 $s$ 无限循环。
2. **必须无符号类型**：$i$ 用 `unsigned` 依赖 $0-1$ 的下溢语义；有符号 `int` 在 0 处减法是未定义行为。
3. **输入规模（原代码未写明）**：$s$ 为 32 位 `unsigned`；**全 1 时子集数 $2^{32}\approx43$ 亿**，输出型演示必须限制 $k=\text{popcount}(s)\le25$ 左右，否则程序会"卡死"在输出上。
4. **缓冲容量（原代码未写明）**：`static char ch[40]` 只匹配 32 位；改 64 位掩码（`unsigned long long`）时 `ch` 要同步扩到 64+。
5. **输入格式（原代码未写明）**：单个十进制整数掩码，演示性质；实际使用时通常把子集作为 DP 外层循环，不产生任何输出。
6. **$s=0$ 语义**：空集的子集只有空集；`write(0)` 输出 `0`、循环输出一个 `0` 后 break——两端都要正确，别在"空集"上少打印。
7. **顺序是降序**：若题目要求升序或字典序，本递推不满足，需要换枚举方式；降序对"先小子集后大集合"的 DP 恰是优点。
8. **递推式中漏写 `& s`**：写成 `i = i - 1` 会把"不是子集的数"也算进来（错误枚举 + 数量爆炸）；`& s` 是把借位限制在 $s$ 的 1 位上的核心。
9. **边界的上一轮**：$(i-1)\&s$ 对任何 $i\subseteq s$ 都回到子集，包括从"只剩最低 1 位"到 0 的最后一跳——不要想当然认为 0 不会出现。
10. **混合输出编码**：程序输出含中文提示，本地控制台乱码是编码不匹配而非逻辑问题；搬运时不要改动任何字符串。

## 对比与扩展

**与逐位 DFS**：DFS 枚举子集是 $O(2^k)$ 但带递归/回溯常数，且顺序是"先加后不加"的 DFS 序；本递推是纯循环、常数更小、天然数值降序。两者选谁取决于 DP 需要的访问顺序。

**与格雷码枚举**：格雷码保证相邻子集只差一位（适合增量维护统计量），但实现更绕；本技巧是最常用的"全量遍历"形态。

**与 `opt-bitmask-connectivity`（位掩码连通性判定）**：同一家族的两块拼图——本技巧**枚举**"哪些点在里面"，连通性判定**验证**"里面连不连通"；合起来就是状压 DP 中"枚举子集 + 判连通"的经典组合拳。

**可复用套路**：凡"遍历集合的所有子集"一律用 `for(i=s; ; i=(i-1)&s){ ... if(i==0) break; }` 这个四行骨架；需要排除空集/全集时在循环体内各加一条 `continue` 即可，骨架不变。
