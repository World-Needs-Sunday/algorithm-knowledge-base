## 算法原理

最近公共祖先（Lowest Common Ancestor, LCA）问题：给定一棵有根树，回答 $m$ 个询问，每次查询两个节点 $u$ 和 $v$ 的最近公共祖先——即最深的那个同时是 $u$ 和 $v$ 祖先的节点。倍增法（Binary Lifting）是目前最常用的 LCA 算法之一，通过预处理每个节点的 $2^k$ 级祖先，将单次查询时间降至 $O(\log n)$。

### 核心思想：二进制拆分跳跃

朴素 LCA 做法是先将两个节点调整到同一深度，然后同时向上爬直到相遇。每次向上爬一步需要 $O(n)$ 的最坏时间（比如一条链）。**倍增法**的核心改进是：预处理每个节点的第 $2^0, 2^1, 2^2, \ldots$ 级祖先，从而可以用"二进制拆分"的方式在 $O(\log n)$ 步内跳任意远的距离。

具体来说，若节点 $u$ 要向上跳 $d$ 步（$d$ 的二进制表示为 $b_k b_{k-1} \ldots b_0$），则：
- 从 $k = 0$ 到 $k = \lfloor \log_2 d \rfloor$，若 $d$ 的第 $k$ 位为 1，则从当前位置向上跳 $2^k$ 步
- 总共最多跳 $O(\log d) = O(\log n)$ 次

### 倍增表的递推构造

设 $dp[u][k]$ 表示节点 $u$ 的第 $2^k$ 级祖先，则有递推关系：

$$dp[u][k] = dp[dp[u][k-1]][k-1]$$

即：$u$ 的第 $2^k$ 级祖先 = $u$ 的第 $2^{k-1}$ 级祖先的第 $2^{k-1}$ 级祖先。这就是"倍增"的含义——每次跳的距离翻倍。

### 查询算法（两阶段）

**阶段 1：对齐深度**。假设 $h[u] \ge h[v]$（否则交换），将 $u$ 向上跳 $h[u] - h[v]$ 步，使两者深度相同。

**阶段 2：同步上升**。从最高位 $k$ 到最低位 $0$ 依次检查：若 $dp[u][k] \neq dp[v][k]$，则 $u$ 和 $v$ 都向上跳 $2^k$ 步。这样做的目的是跳到 LCA 的**下一层**——即 $u$ 和 $v$ 成为 LCA 的两个不同子节点。最后返回 $dp[u][0]$ 即为 LCA。

为什么从高位到低位检查？因为我们要尽可能大地跳（贪心），只要跳完之后两个节点还不相等，就说明还没到 LCA，还可以继续跳。跳完所有位后，$u$ 和 $v$ 的父节点就是 LCA。

### 与其他 LCA 算法对比

| 算法 | 预处理时间 | 查询时间 | 空间 | 适用场景 |
|---|---|---|---|---|
| 朴素法（逐步上爬） | $O(n)$ | $O(n)$ | $O(n)$ | 树很矮或查询少 |
| 倍增法 | $O(n \log n)$ | $O(\log n)$ | $O(n \log n)$ | 通用，最常用 |
| Tarjan 离线法 | $O(n + m)$ | $O(\alpha(n))$ | $O(n + m)$ | 批量查询、离线 |
| 欧拉序 + ST 表 | $O(n \log n)$ | $O(1)$ | $O(n \log n)$ | 在线、极快查询 |
| 重链剖分 | $O(n)$ | $O(\log n)$ | $O(n)$ | 树链问题、可扩展 |

## 核心公式/状态定义与转移方程

### 状态定义

$$dp[u][k] = \text{节点 } u \text{ 的第 } 2^k \text{ 级祖先（向上跳 } 2^k \text{ 步到达的节点）}$$

$$h[u] = \text{节点 } u \text{ 的深度（根节点深度为 1）}$$

### 初始化（DFS 阶段）

$$dp[u][0] = \text{father}(u) \quad \text{（每个节点的直接父亲）}$$

$$h[\text{root}] = 1, \qquad h[v] = h[\text{father}(v)] + 1$$

根节点的父节点设为自身：$dp[\text{root}][0] = \text{root}$。

### 倍增表递推

$$dp[u][k] = dp[dp[u][k-1]][k-1] \qquad \text{for } k = 1, 2, \ldots, \lfloor \log_2 n \rfloor$$

$2^k$ 级祖先 = 先跳 $2^{k-1}$ 步，再跳 $2^{k-1}$ 步。

### 最大层数计算

$$\text{max\_level} = \lfloor \log_2(\max\_depth) \rfloor \le \lfloor \log_2 n \rfloor$$

本代码通过 DFS 先求出树的最大深度 `len`，再计算需要的层数。

### 查询：深度对齐

假设 $h[a] \ge h[b]$，令 $d = h[a] - h[b]$，将 $a$ 向上跳 $d$ 步：

$$\text{for } i = 0 \text{ to max\_level}: \quad \text{if } (d \gg i) \& 1 \implies a = dp[a][i]$$

即按 $d$ 的二进制位从低到高，若第 $i$ 位为 1 则跳 $2^i$ 步。

### 查询：同步上升

从最高位到最低位枚举：

$$\text{for } i = \text{max\_level down to } 0: \quad \text{if } dp[a][i] \neq dp[b][i] \implies a = dp[a][i],\; b = dp[b][i]$$

循环结束后，$a$ 和 $b$ 是 LCA 的两个子节点（即 LCA 的下一层）。因此：

$$\text{LCA}(a, b) = dp[a][0] = dp[b][0]$$

**特殊情况**：若深度对齐后 $a == b$，则 $a$ 本身就是 LCA，直接返回。

### 正确性证明（同步上升阶段）

设 LCA 的深度为 $d_{\text{lca}}$，两节点当前深度为 $d$。我们要从深度 $d$ 跳到深度 $d_{\text{lca}} + 1$（LCA 的下一层）。

从高位到低位检查的过程，本质上是在用二进制贪心逼近"需要跳的步数"$d - (d_{\text{lca}} + 1)$。每一步选择能跳的最大的 $2^k$（跳完不相等意味着还没到 LCA），最终恰好跳到 LCA 的下一层。

## 逐行代码解析

### 第 1 段：全局变量与 DFS 求深度和父亲

```cpp
int N, M;
vector<vector<int>> A;           // 多叉树：A[u] 存 u 的所有子节点
vector<vector<int>> dp;           // 倍增表：dp[u][k] = u 的 2^k 级祖先
vector<int> h;                    // 每个节点的深度
int len = 1;                      // 树的最大深度（DFS 中更新）
void dfs(int rt, int t_len, vector<int>& tmp)
{
    if(t_len > len) len = t_len;
    h[rt] = t_len;
    for (int i : A[rt])
    {
        tmp[i] = rt;              // 记录 i 的父亲是 rt
        dfs(i, t_len + 1, tmp);
    }
}
```

- **`A`**：多叉树邻接表，`A[u]` 存储 $u$ 的所有子节点编号。输入格式为每个节点先给子节点数，再给子节点编号。
- **`dp`**：倍增表，`dp[u][k]` 表示 $u$ 的第 $2^k$ 级祖先。
- **`h`**：深度数组，根节点深度为 1。
- **`tmp`**：临时数组存储每个节点的直接父亲，DFS 过程中填充。
- **`len`**：记录树的最大深度，用于后续计算倍增表的最大层数。
- **DFS 顺序**：前序遍历，先处理当前节点（记录深度），再递归所有子节点。多叉树版本用 `for (int i : A[rt])` 遍历所有子节点，比二叉树版本（左右儿子）更通用。

### 第 2 段：初始化倍增表

```cpp
void init(int rt)
{
    vector<int> tmp(N + 1);
    h.resize(N + 1);
    tmp[rt] = rt;              // 根的父亲设为自己
    dfs(rt, 1, tmp);           // DFS 求深度和一级祖先

    int sz = 1;
    while(len >= ((long long)1 << sz)) ++sz;
    len = sz;                  // len 变为需要的倍增层数

    dp.resize(N + 1, vector<int>(len + 1));
    for(int i = 1; i <= N; i++) dp[i][0] = tmp[i];   // 2^0 = 1 级祖先即父亲
    for(int k = 1; k <= len; k++)
    {
        for(int i = 1; i <= N; i++)
        {
            dp[i][k] = dp[dp[i][k - 1]][k - 1];      // 倍增递推
        }
    }
}
```

逐段分析：

- **`tmp[rt] = rt`**：根节点的父亲设为自身。这样根节点再往上跳还是自己，不会越界。
- **`dfs(rt, 1, tmp)`**：根深度为 1，DFS 填充 `h[]` 和 `tmp[]`（直接父亲）。
- **层数计算**：`while(len >= ((long long)1 << sz)) ++sz;` 求出满足 $2^{sz} > \text{max\_depth}$ 的最小 $sz$，即需要的倍增层数。最终 `len` 被赋值为层数（注意这里变量复用，`len` 从"最大深度"变为"最大层数"）。
- **`dp[i][0] = tmp[i]`**：$k=0$ 即 $2^0=1$ 级祖先，就是直接父亲。
- **倍增递推**：外层 $k$ 从 1 到 `len`，内层 $i$ 遍历所有节点。`dp[i][k] = dp[dp[i][k-1]][k-1]` 就是核心的倍增公式。

### 第 3 段：查询函数（核心）

```cpp
int query(int a, int b)
{
    if(h[a] != h[b])
    {
        if(h[b] > h[a])
        {
            int t_h = h[b] - h[a];
            for(int i = 0; i <= len; i++)
            {
                if(t_h & 1) b = dp[b][i];
                t_h >>= 1;
            }
        }
        else
        {
            int t_h = h[a] - h[b];
            for(int i = 0; i <= len; i++)
            {
                if(t_h & 1) a = dp[a][i];
                t_h >>= 1;
            }
        }
    }
    if(a == b) return a;
    for(int i = len; i >= 0; i--)
    {
        if(dp[a][i] != dp[b][i])
        {
            a = dp[a][i];
            b = dp[b][i];
        }
    }
    return dp[a][0];
}
```

**阶段 1：深度对齐**

- 比较 `h[a]` 和 `h[b]`，将较深的节点向上跳到与另一个相同深度。
- `t_h` 是深度差。`for` 循环从低位到高位（$i = 0 \sim len$），检查 `t_h` 的第 $i$ 位是否为 1。若是，则跳 $2^i$ 步。
- 每次循环后 `t_h >>= 1` 右移一位，相当于检查下一位。
- 注意 `t_h & 1` 检查的是最低位，配合 `t_h >>= 1` 实现逐位检查。

**阶段 2：同步上升**

- 先检查 `if(a == b) return a;`：如果对齐后两节点相同，说明一个是另一个的祖先，直接返回。
- 从最高位 `len` 到最低位 `0` 倒序枚举：
  - 若 `dp[a][i] != dp[b][i]`，说明跳 $2^i$ 步后还没到 LCA，可以安全地跳。
  - 若相等，则不能跳（可能跳过了 LCA）。
- 循环结束后，`a` 和 `b` 是 LCA 的两个子节点，`dp[a][0]` 即为 LCA。

### 第 4 段：主函数——建树与找根

```cpp
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    cin >> N >> M;
    vector<bool> vis(N + 1, false);
    A.resize(N + 1);
    for(int i = 1; i <= N; i++)
    {
        int n;
        cin >> n;
        A[i].resize(n);
        for(int j = 0; j < n; j++)
        {
            cin >> A[i][j];
            vis[A[i][j]] = true;     // 标记所有"作为子节点"的节点
        }
    }
    int rt = 1;
    while(vis[rt]) rt++;             // 找根：没被标记为儿子的节点就是根
    init(rt);

    for(int i = 1; i <= M; i++)
    {
        int a, b;
        cin >> a >> b;
        cout << query(a, b) << '\n';
    }
    return 0;
}
```

- **输入格式**：每个节点先输入子节点数 $n$，再输入 $n$ 个子节点编号。与 Tarjan 代码的输入格式一致。
- **找根节点**：用 `vis` 数组标记所有"作为子节点出现"的节点，没被标记的就是根。
- **`while(vis[rt]) rt++`**：从 1 开始找第一个未被标记的节点，即为根。
- **查询循环**：$M$ 个查询，每个调用 `query(a, b)` 输出 LCA。

## 复杂度分析

### 预处理时间

| 步骤 | 复杂度 |
|---|---|
| DFS 求深度 + 一级祖先 | $O(n)$ |
| 计算倍增层数 | $O(\log n)$ |
| 填充倍增表（$n$ 个节点 × $\log n$ 层） | $O(n \log n)$ |
| **总计** | $O(n \log n)$ |

倍增表大小为 $n \times \log_2 n$，每格 $O(1)$ 计算。

### 查询时间

| 步骤 | 复杂度 |
|---|---|
| 深度对齐（最多跳 $\log n$ 次） | $O(\log n)$ |
| 同步上升（最多跳 $\log n$ 次） | $O(\log n)$ |
| **总计** | $O(\log n)$ |

### 空间复杂度

| 数据结构 | 空间 |
|---|---|
| 树存储 `A` | $O(n)$ |
| 倍增表 `dp` | $O(n \log n)$ |
| 深度数组 `h` | $O(n)$ |
| **总计** | $O(n \log n)$ |

空间瓶颈在倍增表。$n = 10^5$ 时，$\log_2 n \approx 17$，空间约 $1.7 \times 10^6$，完全可行。

## 适用场景

### 适合使用倍增法 LCA

- **多次 LCA 查询**：$m$ 个查询，$m$ 较大时 $O(m \log n)$ 远优于朴素法的 $O(mn)$
- **在线查询**：查询一个接一个，无法提前知道全部查询（倍增法是在线算法）
- **树静态不变**：树结构固定，不需要动态加边/删边
- **需要结合其他树上信息**：倍增表可扩展存储更多信息（如路径最大边权、路径和等）
- **竞赛/算法题**：实现简洁，不易写错，常数小

### 不适合使用倍增法

- **树动态变化**：树结构频繁修改时倍增表需要重建，代价高
- **查询量极小**（$m < \log n$）：朴素法更简单，常数更小
- **内存极度受限**：$O(n \log n)$ 空间可能不够（可用 Tarjan 离线法的 $O(n + m)$ 空间）

### 扩展：倍增表存储更多信息

倍增表不仅可以存"祖先是谁"，还可以存路径上的各种信息：

- **路径最大边权**：`maxw[u][k]` = $u$ 到 $2^k$ 级祖先路径上的最大边权
  - 递推：`maxw[u][k] = max(maxw[u][k-1], maxw[dp[u][k-1]][k-1])`
- **路径边权和**：`sumw[u][k]` = $u$ 到 $2^k$ 级祖先路径上的边权和
  - 递推：`sumw[u][k] = sumw[u][k-1] + sumw[dp[u][k-1]][k-1]`
- **路径最小值、路径与/或/异或**等满足结合律的运算都可倍增维护

## 常见陷阱与注意事项

1. **根节点的父亲设为自身**
   - `tmp[rt] = rt` 必须设置，否则根节点向上跳会越界（访问未定义的 `dp[0]` 或数组越界）。
   - 根的 $2^k$ 级祖先始终是根本身，不会出错。

2. **倍增层数计算**
   - 本代码先 DFS 求最大深度，再计算所需层数。也可直接用常量（如 `20`，对应 $2^{20} > 10^6$，足够大多数情况）。
   - 若层数设少了（不够跳），会导致查询错误。宁多勿少。
   - `(long long)1 << sz` 强制转 `long long` 防止 `1 << sz` 在 `sz >= 31` 时溢出 `int`。

3. **深度对齐方向**
   - 代码分了 `h[b] > h[a]` 和 `h[a] > h[b]` 两种情况，分别跳较深的那个。
   - 也可以写得更简洁：统一让 $a$ 为较深的节点，若不是则 `swap(a, b)`。

4. **同步上升的"不等"判断**
   - 条件是 `dp[a][i] != dp[b][i]` 才跳，而不是 `dp[a][i] == dp[b][i]`。
   - 原因：我们要跳到 LCA 的**下一层**，而不是跳到 LCA 本身。如果跳完相等，可能跳过了或刚好到了，无法确定。
   - 跳完所有位后，LCA 就是 `dp[a][0]`。

5. **对齐后直接相等的情况**
   - `if(a == b) return a;` 不能省略。若省略，进入同步上升循环时 `dp[a][i] == dp[b][i]` 恒成立（因为 $a=b$），不会跳任何步，最后返回 `dp[a][0]` 也是正确的……但这是巧合，显式判断更清晰且避免意外。

6. **DFS 栈溢出风险**
   - 本代码用递归 DFS。若树是一条链（$n$ 很大，如 $10^5$），递归深度可达 $10^5$，会栈溢出。
   - 解决方法：改用**迭代 DFS** 或 **BFS** 求深度和父亲。

7. **多叉树 vs 二叉树**
   - 本代码使用 `vector<vector<int>> A` 邻接表存储多叉树，`for (int i : A[rt])` 遍历所有子节点。
   - 这比二叉树版本（`pair<int,int>` 存左右儿子）更通用，支持任意度数的树。

8. **节点编号从 1 开始**
   - 代码中节点编号 $1 \sim N$。若节点从 0 开始，需调整数组大小和循环范围。

## 对比与扩展

### 各种 LCA 算法对比

| 算法 | 预处理 | 查询 | 空间 | 在线/离线 | 实现难度 | 特点 |
|---|---|---|---|---|---|---|
| 朴素上爬 | $O(n)$ | $O(n)$ | $O(n)$ | 在线 | 极低 | 简单但慢，仅适合小树 |
| 倍增法 | $O(n \log n)$ | $O(\log n)$ | $O(n \log n)$ | 在线 | 中 | 最常用，通用，易扩展 |
| Tarjan 并查集 | $O(n + m)$ | $O(\alpha(n))$ | $O(n + m)$ | 离线 | 中 | 查询极快，但需离线 |
| 欧拉序 + ST 表 | $O(n \log n)$ | $O(1)$ | $O(n \log n)$ | 在线 | 较高 | 查询最快，常数稍大 |
| 重链剖分 | $O(n)$ | $O(\log n)$ | $O(n)$ | 在线 | 高 | 可维护树链信息，功能强 |

### 扩展：树上路径距离

利用 LCA 可以求树上任意两点 $u, v$ 的距离：

$$\text{dist}(u, v) = h[u] + h[v] - 2 \times h[\text{LCA}(u, v)]$$

原理：$u$ 到 LCA 的距离 + $v$ 到 LCA 的距离 = $u$ 到根 + $v$ 到根 - 2 × LCA 到根。

### 扩展：树上第 k 个祖先

倍增表天然支持"求节点 $u$ 的第 $k$ 个祖先"，将 $k$ 二进制拆分后逐位跳即可：

```cpp
int kth_ancestor(int u, int k) {
    for(int i = 0; i <= len; i++) {
        if(k & (1 << i)) u = dp[u][i];
    }
    return u;
}
```

### 扩展：无根树的处理

本代码假设树以"每个节点的子节点列表"形式给出（有根树）。若题目给出无根树（边集形式），需要：

1. 建无向邻接表
2. 任选一个节点作为根（如节点 1）
3. DFS 时传入父节点参数，跳过父节点方向

```cpp
vector<vector<int>> adj;  // 无向邻接表
void dfs(int u, int fa, int depth) {
    dp[u][0] = fa;
    h[u] = depth;
    for(int v : adj[u]) {
        if(v != fa) dfs(v, u, depth + 1);
    }
}
```

### 扩展：树上差分

LCA 是树上差分的基础。对于路径 $u \to v$ 上所有节点加 $w$，可以用差分数组：

$$\text{diff}[u] \mathrel{+}= w, \quad \text{diff}[v] \mathrel{+}= w, \quad \text{diff}[\text{lca}] \mathrel{-}= w, \quad \text{diff}[\text{fa}(\text{lca})] \mathrel{-}= w$$

最后 DFS 求子树和即为每个节点的最终值。
