## 算法原理

Manacher 算法用于求解**最长回文子串**：给定一个字符串 $s$，求它的最长连续回文子串。

回文串分为两类：**奇数长度**（中心是单个字符，如 `aba`）和**偶数长度**（中心在两个字符之间，如 `abba`）。为了统一处理，先在字符串每两个字符之间以及两端插入分隔符 `#`，例如 `abba` 变为 `#a#b#b#a#`。这样每个对称中心都会对应到一个具体的字符位置，所有回文都被转化为奇数长度，便于统一扩展。

朴素做法是枚举每个可能的中心，向两侧逐位扩展直到失配，复杂度为 $O(n^2)$。其低效之处在于：**每个中心都从头开始扩展，大量已计算过的回文信息被重复利用**，例如 `aaaaa` 每个中心都要完整扩展一遍，总扩展次数达到 $O(n^2)$。

Manacher 的优化核心是：**利用已经找到的回文串的对称性，避免重复扩展**。维护"右端点最靠右"的已知回文串，在处理新中心时先通过对称关系"继承"一部分回文半径，再只对可能扩展的部分暴力扩展，从而把总复杂度降到线性。

## 核心公式 / 状态定义与转移方程

定义 $p[i]$ 为：**以位置 $i$ 为中心的最长回文串的半径（不含中心本身）**。对展开后的串 `#a#b#b#a#`：

| $i$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 字符 | `#` | `a` | `#` | `b` | `#` | `b` | `#` | `a` | `#` |
| $p[i]$ | 0 | 1 | 0 | 1 | 4 | 1 | 0 | 1 | 0 |

以 $i=4$ 为中心，回文串是整个 `#a#b#b#a#`，半径 $p[4]=4$。

**关键转化**：在带 `#` 的展开串中，以 $i$ 为中心的最长回文半径 $p[i]$ 恰好等于**原串中对应的最长回文子串长度**。因此原串最长回文子串的长度等于 $\max_i p[i]$。

**镜像继承**：维护两个变量

- $C$：当前已知回文串中**右端点最靠右**的那个回文串的中心；
- $R$：该回文串的右端点，即 $R = C + p[C]$。

处理位置 $i$ 时，若 $i < R$，则 $i$ 落在当前最右回文串的覆盖范围内，其关于 $C$ 的对称点为 $i' = 2C - i$。由回文串的对称性，$p[i]$ 至少可以继承 $p[i']$ 的一部分：

$$
p[i] \ge \min(p[i'],\ R - i)
$$

由于 $p[i']$ 可能超出当前回文串的右边界，超出部分无法保证对称，故取 $\min$。于是 Manacher 的流程为：

1. 若 $i < R$，令 $p[i] = \min(p[2C-i],\ R-i)$；否则 $p[i] = 0$。
2. **暴力扩展**：从 $p[i]+1$ 开始向两侧扩展，直到两侧字符不相等或越界。
3. 更新 $C$、$R$：若 $i + p[i] > R$，令 $C = i$、$R = i + p[i]$。
4. 用 $p[i]$ 更新答案的最大值。

### 模块二：读入与插入分隔符

```cpp
    string s;
    cin >> s;
    int n = s.size();

    // 插入分隔符
    string t = "#";
    for (char c : s) {
        t += c;
        t += '#';
    }
    int m = t.size();

    vector<int> p(m, 0);
    int C = 0, R = 0;
    int ans = 0;
```

- 读入原串 $s$，`n` 为原串长度（展开后的长度用 `m` 表示，二者满足 $m = 2n+1$）。
- 在每个字符两侧插入 `#`，把奇偶回文统一成奇数长度；`t` 从单个 `#` 起步，每读一个字符就追加 `字符 + #`。
- `p` 数组长度与展开串一致、初值全 0；`C`、`R` 分别记录"最右回文串的中心与右端点"，`ans` 记录全局最长回文长度。

### 模块三：主循环——镜像继承与暴力扩展

```cpp
    for (int i = 0; i < m; i++) {
        // 镜像继承
        if (i < R) p[i] = min(p[2 * C - i], R - i);

        // 暴力扩展
        while (i - p[i] - 1 >= 0 && i + p[i] + 1 < m && t[i - p[i] - 1] == t[i + p[i] + 1])
            p[i]++;

        // 更新最右回文串
        if (i + p[i] > R) {
            C = i;
            R = i + p[i];
        }

        ans = max(ans, p[i]);
    }
```

- `if (i < R)`：只有当 $i$ 落在当前最右回文串内部时才可继承；对称点为 `2 * C - i`，并受 `R - i` 上限约束。
- `while` 从 $p[i]+1$ 处向两侧暴力扩展：同时检查左右不越界、两侧字符相等才令 `p[i]++`。
- 扩展结束后若 `i + p[i] > R`，说明回文右端点突破了当前最右边界，更新 `C = i`、`R = i + p[i]`。
- `ans = max(ans, p[i])` 实时维护全局最大半径（即原串最长回文子串长度）。

### 模块四：输出答案

```cpp
    cout << ans << '\n';
    return 0;
}
```

- 输出全局最大半径 `ans`，即原串最长回文子串的长度。
- `return 0` 表示程序正常结束。

## 复杂度分析

时间复杂度：主循环中虽然存在 `while` 暴力扩展，但每次扩展都会把 $R$ 向右推进至少一位，而 $R$ 单调不减、最多从 0 推到 $m-1$（展开串长度 $m = 2n+1$），因此所有 `while` 扩展的**总次数**为 $O(m) = O(n)$。整体时间复杂度为 $O(n)$。

空间复杂度：需要存储展开串 $t$（$O(n)$）与半径数组 $p$（$O(n)$），总空间复杂度为 $O(n)$。

## 适用场景

1. **最长回文子串**：直接取 $\max_i p[i]$，是 Manacher 最经典的应用。
2. **回文子串个数**：以每个中心 $i$ 为对称轴的回文子串个数为 $\lceil p[i]/2 \rceil$，求和 $\sum \lceil p[i]/2 \rceil$ 即可。
3. **回文串判定**：结合哈希可在 $O(1)$ 内判断任意子串是否回文，但求全局最长回文时 Manacher 更合适。
4. **双倍回文（P4555）**：在 Manacher 的基础上增加预处理，求两个相邻回文串拼接而成的最长"双倍回文"。

## 常见陷阱与注意事项

1. **分隔符不能与输入字符冲突**：本实现用 `#` 作分隔符，隐含假设输入串不含 `#`（如输入限定为小写字母）。若输入可能出现 `#`，需改用其他不冲突的哨兵字符。
2. **$p[i]$ 的含义**：它是"不含中心"的半径，且恰好等于原串对应回文子串的长度，直接取 $\max$ 即为答案，不要再做 $(2p[i]+1)/2$ 这类换算。
3. **镜像继承必须带 $R-i$ 上限**：继承量是 $\min(p[2C-i], R-i)$，漏掉 `R - i` 会把"超出当前最右回文串范围"的部分误判为已知回文。
4. **暴力扩展的边界**：`while` 条件必须同时检查 `i - p[i] - 1 >= 0` 与 `i + p[i] + 1 < m`，否则首尾越界。
5. **展开串下标与长度**：展开后长度 $m = 2n+1$，`p` 数组也要开成 $m$ 大小；循环遍历范围是 `i < m` 而非 `i < n`。
6. **`ans` 的更新**：输出的是最大半径 $p[i]$（即原回文长度），而非展开串的回文长度 $2p[i]+1$。

## 对比与扩展

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|---|---|---|---|
| 朴素中心扩展 | $O(n^2)$ | $O(1)$ | 实现最简单，但中心重复扩展，无法处理大数据 |
| **Manacher（本算法）** | $O(n)$ | $O(n)$ | 线性时间，代码细节较多、易写挂 |
| 字符串哈希 + 二分 | $O(n \log n)$ | $O(n)$ | 实现更简单通用，能顺便回答"任意子串是否回文" |
