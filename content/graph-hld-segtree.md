## 算法原理

树链剖分（Heavy-Light Decomposition, HLD）是一种将**树拆分为若干条不相交链**的技术，使得树上任意一条路径最多跨越 $O(\log n)$ 条链。配合线段树，可以实现 $O(\log^2 n)$ 的**路径修改/查询**和 $O(\log n)$ 的**子树修改/查询**。

### 核心思想

将树边分为**重边**和**轻边**：
- **重儿子**：节点 $u$ 的所有儿子中，子树最大的那个
- **轻儿子**：除了重儿子以外的其他儿子
- **重链**：沿着重边走到底形成的链

关键性质：从任意节点到根的路径上，最多经过 $O(\log n)$ 条轻边，因此也最多跨越 $O(\log n)$ 条重链。

### 两次 DFS 预处理

| DFS | 作用 | 维护的数组 |
|-----|------|-----------|
| dfs1 | 求每个节点的父节点、深度、子树大小、重儿子 | `fa`, `h`, `sz`, `w_son` |
| dfs2 | 按重链优先的顺序重新编号，使每条重链上的 DFS 序连续 | `id`, `top` |

dfs2 的关键策略：**先递归重儿子，再递归轻儿子**。这样同一条重链上的节点在 DFS 序中是连续的区间，可以直接用线段树做区间操作。

## 核心操作详解

### 数组定义

| 数组 | 含义 |
|------|------|
| `fa[u]` | $u$ 的父节点 |
| `h[u]` | $u$ 的深度 |
| `sz[u]` | $u$ 的子树大小 |
| `w_son[u]` | $u$ 的重儿子编号（0 表示无） |
| `id[u]` | $u$ 在 DFS 序中的新编号 |
| `top[u]` | $u$ 所在重链的链顶节点 |

### 路径操作：split 函数

路径 $(u, v)$ 被拆分为 $O(\log n)$ 段连续区间：

1. 若 $u$ 和 $v$ 不在同一条重链上，将**链顶更深**的一方整条链切下来（区间 $[\text{id}[\text{top}[u]], \text{id}[u]]$），然后跳到该链链顶的父节点
2. 重复直到 $u$ 和 $v$ 在同一条重链上
3. 此时 $u$ 和 $v$ 在同一段连续区间内，切下最后一段

### 子树操作

由于 dfs2 是优先重儿子的先序遍历，子树 $u$ 的 DFS 序区间为 $[\text{id}[u], \text{id}[u] + \text{sz}[u] - 1]$，是一个连续区间，直接在线段树上做区间操作即可。

## 逐行代码解析

### dfs1：求大小、深度、重儿子

```cpp
void dfs1(int rt)
{
    int son_id = 0, nmax = 0;
    for (int i : edges[rt])
    {
        if (i == fa[rt]) continue;
        fa[i] = rt;       // 记录父节点
        h[i] = h[rt] + 1; // 记录深度
        dfs1(i);
        sz[rt] += sz[i];  // 累加子树大小
        if (sz[i] > nmax) // 更新重儿子
        {
            son_id = i;
            nmax = sz[i];
        }
    }
    w_son[rt] = son_id;
}
```

### dfs2：重链优先编号

```cpp
void dfs2(int rt, int tp)
{
    id[rt] = ++cnt;   // 分配新编号
    top[rt] = tp;     // 记录链顶
    if (w_son[rt]) dfs2(w_son[rt], tp); // 先递归重儿子（保持重链连续）
    for (int i : edges[rt])
    {
        if (i == fa[rt] || i == w_son[rt]) continue;
        dfs2(i, i);  // 轻儿子是新链的链顶
    }
}
```

### split：路径拆分为区间

```cpp
vector<pair<int,int>> split(int u, int v)
{
    vector<pair<int, int>> sp;
    while (top[u] != top[v])         // 不在同一条重链
    {
        if (h[top[u]] < h[top[v]]) swap(u, v); // 选链顶更深的
        sp.emplace_back(id[top[u]], id[u]);    // 切下这条链
        u = fa[top[u]];                       // 跳到链顶的父亲
    }
    if (h[u] > h[v]) swap(u, v);
    sp.emplace_back(id[u], id[v]);            // 同一条链上的最后一段
    return sp;
}
```

### 线段树：区间加 + 区间求和

线段树部分是标准实现，支持懒标记下推的区间加法和区间求和。初始化时将原始点权按 `id` 重排到线段树中：

```cpp
for (int i = 1; i <= n; i++) A[id[i]] = arr[i]; // 按DFS序重排
```

### 四种操作

| 操作 | 函数 | 说明 |
|------|------|------|
| 路径加 $k$ | `mset(u, v, k)` | 拆分路径为区间，对每段区间做线段树区间加 |
| 路径求和 | `mget(u, v)` | 拆分路径为区间，对每段区间做线段树区间求和 |
| 子树加 $k$ | `subtree_set(x, k)` | 区间 $[\text{id}[x], \text{id}[x] + \text{sz}[x] - 1]$ 做线段树区间加 |
| 子树求和 | `subtree_get(x)` | 同上区间做线段树区间求和 |

## 复杂度分析

- **预处理**（两次 DFS）：$O(n)$
- **线段树建树**：$O(n)$
- **路径操作**：$O(\log^2 n)$，路径拆分为 $O(\log n)$ 段，每段线段树操作 $O(\log n)$
- **子树操作**：$O(\log n)$，单次线段树区间操作
- **空间**：$O(n)$

## 适用场景

1. **树上路径修改/查询**：路径加、路径求和、路径求最值
2. **子树修改/查询**：子树加、子树求和
3. **树上 LCA**：`split` 过程中最后一次同链时深度较小的节点即为 LCA
4. **树上差分的替代方案**：当需要在线查询而非离线处理时，树链剖分比差分更灵活

## 常见陷阱与注意事项

1. **dfs2 的递归顺序**：必须先递归重儿子，否则重链上的节点在 DFS 序中不连续，线段树区间操作会出错
2. **重儿子为 0 的情况**：叶子节点的 `w_son` 为 0，dfs2 中 `if (w_son[rt])` 的判断不能省
3. **根节点的父节点**：`fa[rt] = rt`（自指向），防止 dfs1 中误判
4. **链顶深度比较**：split 中比较的是 `h[top[u]]`（链顶深度）而非 `h[u]`（节点深度）
5. **数据类型**：路径求和可能超出 `int` 范围，需用 `long long`
6. **子树大小初始化**：`sz` 数组初始化为 1（包含自身），dfs1 中累加子树大小

## 对比与扩展

| 方法 | 路径修改 | 路径查询 | 子树修改 | 在线性 | 复杂度 |
|------|---------|---------|---------|--------|--------|
| 树上差分 | $O(1)$ | $O(n)$ 重建前缀和 | $O(1)$ | 离线 | $O(n)$ |
| 树链剖分+线段树 | $O(\log^2 n)$ | $O(\log^2 n)$ | $O(\log n)$ | 在线 | $O(n)$ |
| 树链剖分+树状数组 | $O(\log^2 n)$ | $O(\log^2 n)$ | $O(\log n)$ | 在线 | $O(n)$ |
| Link-Cut Tree | $O(\log n)$ 均摊 | $O(\log n)$ 均摊 | 不直接支持 | 在线动态 | $O(n)$ |

树链剖分在**静态树**上是最实用的选择，代码量适中且常数较小。如果树的结构动态变化（加边/删边），则需要 LCT。
