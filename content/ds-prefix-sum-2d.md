## 算法原理

二维前缀和是一维前缀和的扩展：给定一个 $n \times m$ 的矩阵 $a$，预处理出前缀和矩阵 $S$，使得 $S[i][j]$ 表示以 $(1,1)$ 为左上角、$(i,j)$ 为右下角的子矩阵中所有元素之和。预处理后，可以在 $O(1)$ 时间内回答任意子矩阵的和。

### 核心公式

前缀和矩阵定义：

$$S[i][j] = \sum_{x=1}^{i} \sum_{y=1}^{j} a[x][y]$$

### 递推构造（容斥原理）

$$S[i][j] = a[i][j] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]$$

**容斥解释**：
- $a[i][j]$：当前格的值
- $+ S[i-1][j]$：加上上方矩形的和
- $+ S[i][j-1]$：加上左方矩形的和
- $- S[i-1][j-1]$：左上角重叠部分被加了两次，减去一次

### 子矩阵和查询

求以 $(x_1, y_1)$ 为左上角、$(x_2, y_2)$ 为右下角的子矩阵和：

$$\text{sum}(x_1, y_1, x_2, y_2) = S[x_2][y_2] - S[x_1-1][y_2] - S[x_2][y_1-1] + S[x_1-1][y_1-1]$$

**容斥解释**：
- $S[x_2][y_2]$：从 $(1,1)$ 到 $(x_2,y_2)$ 的大矩形
- $- S[x_1-1][y_2]$：减去上半部分（$x_1-1$ 行及以上）
- $- S[x_2][y_1-1]$：减去左半部分（$y_1-1$ 列及以左）
- $+ S[x_1-1][y_1-1]$：左上角被减了两次，加回来一次

### 复杂度

| 操作 | 时间 |
|---|---|
| 构造前缀和矩阵 | $O(nm)$ |
| 单次子矩阵和查询 | $O(1)$ |
| 空间 | $O(nm)$ |

## 数据结构图示

### 构造过程示意（容斥原理）

以 $3 \times 3$ 矩阵为例，演示 $S[2][2]$ 的计算：

```
原始矩阵 a:             前缀和矩阵 S:
   j=0  1  2  3            j=0  1  2  3
i=0  0  0  0  0          i=0  0  0  0  0
i=1  0  1  2  3          i=1  0  ?  ?  ?
i=2  0  4  5  6          i=2  0  ?  ?  ?
i=3  0  7  8  9          i=3  0  ?  ?  ?
```

逐步计算，按行优先顺序：

```
计算 S[1][1]:
  S[1][1] = a[1][1] + S[0][1] + S[1][0] - S[0][0]
          = 1 + 0 + 0 - 0 = 1

  S[1][1] 就是左上角 1×1 区域的和 = 1 ✓
  ┌─────┐
  │ 1   │
  └─────┘

计算 S[1][2]:
  S[1][2] = a[1][2] + S[0][2] + S[1][1] - S[0][1]
          = 2 + 0 + 1 - 0 = 3

  S[1][2] 是第 1 行前 2 列的和 = 1+2 = 3 ✓
  ┌──────────┐
  │ 1   2    │
  └──────────┘
   a[1][2]=2  +  S[1][1]=1  =  3

计算 S[2][1]:
  S[2][1] = a[2][1] + S[1][1] + S[2][0] - S[1][0]
          = 4 + 1 + 0 - 0 = 5

  S[2][1] 是第 1 列前 2 行的和 = 1+4 = 5 ✓
  ┌─────┐
  │ 1   │
  │ 4   │
  └─────┘

计算 S[2][2]:
  S[2][2] = a[2][2] + S[1][2] + S[2][1] - S[1][1]
          = 5 + 3 + 5 - 1 = 12

  验证: 1+2+4+5 = 12 ✓
```

**容斥图解 S[2][2]**：

```
        上矩形 S[1][2] = 3
        ┌─────────────┐
        │ 1     2     │
  左矩形 ├─────┬───────┤
S[2][1]=5│ 1   │  5    │  ← a[2][2] = 5
        │ 4   │       │
        └─────┴───────┘
          重叠 S[1][1]=1
          （被加了两次）

S[2][2] = a[2][2] + S[1][2] + S[2][1] - S[1][1]
        =    5    +    3    +    5    -    1   = 12
```

上方矩形 + 左方矩形 = 包含了左上重叠区域两次，所以要减去一次。

### 子矩阵和查询示意

查询以 $(2, 2)$ 为左上角、$(3, 3)$ 为右下角的子矩阵和：

```
S 矩阵:
     j=0   1    2    3
i=0  0    0    0    0
i=1  0    1    3    6
i=2  0    5   12   21
i=3  0   12   27   45

查询 (x1=2, y1=2) → (x2=3, y2=3):

  S[x2][y2] = S[3][3] = 45
    ┌─────────────────┐
    │ 1    2     3    │
    │ 4    5     6    │
    │ 7    8     9    │
    └─────────────────┘

  - S[x1-1][y2] = S[1][3] = 6
    ┌─────────────────┐
    │ 1    2     3    │  ← 减去这一行
    │ ─ ─ ─ ─ ─ ─ ─ │
    │ 4    5     6    │
    │ 7    8     9    │
    └─────────────────┘

  - S[x2][y1-1] = S[3][1] = 12
    ┌──┬──────────────┐
    │1 │  2     3     │
    │4 │  5     6     │  ← 减去这一列
    │7 │  8     9     │
    └──┴──────────────┘

  + S[x1-1][y1-1] = S[1][1] = 1
    ┌──┬──────────────┐
    │1 │  2     3     │
    ├──┼──────────────┤  ← 加回这个角（被减了两次）
    │4 │  5     6     │
    │7 │  8     9     │
    └──┴──────────────┘

结果: 45 - 6 - 12 + 1 = 28
验证: 5+6+8+9 = 28 ✓
```

公式记忆口诀：**大四角减上矩形、减左矩形、加回左上角**。

### 最终前缀和矩阵完整示例

```
原矩阵 a(3×3):          前缀和 S(3×3):
   1  2  3                 1   3   6
   4  5  6        →        5  12  21
   7  8  9                12  27  45

每个 S[i][j] 是左上 i×j 矩形的总和。
S[3][3] = 1+2+3+4+5+6+7+8+9 = 45 ✓
```

## 逐行代码解析

```cpp
#include<bits/stdc++.h>
using namespace std;
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    int N, M, T;
    cin >> N >> M >> T;
    vector<vector<long long>> A(N + 1, vector<long long>(M + 1));
    for(int i = 1; i <= N; i++)
    {
        for(int j = 1; j <= M; j++)
        {
            cin >> A[i][j];
        }
    }
    for(int i = 1; i <= N; i++)
    {
        for(int j = 1; j <= M; j++)
        {
            A[i][j] = A[i][j] + A[i - 1][j] + A[i][j - 1] - A[i - 1][j - 1];
        }
    }

    for(int i = 1; i <= T; i++)
    {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        cout << A[x2][y2] - A[x1 - 1][y2] - A[x2][y1 - 1] + A[x1 - 1][y1 - 1] << '\n';
    }
    return 0;
}
```

逐段分析：

- **`vector<vector<long long>> A(N + 1, vector<long long>(M + 1))`**：开 $(N+1) \times (M+1)$ 的二维数组，第 0 行和第 0 列均为 0（`vector` 默认初始化）。这样当 $x_1=1$ 或 $y_1=1$ 时，$S[x_1-1][\cdot]$ 或 $S[\cdot][y_1-1]$ 自动为 0，无需特判。
- **读入矩阵**：$A[1][1] \sim A[N][M]$ 存入原始值。
- **构造前缀和**：双重循环，按行优先顺序。每个位置 $A[i][j]$ 由上方、左方、左上方三个值推出。$O(nm)$ 时间。
  - 注意：由于是按行优先遍历，计算 $A[i][j]$ 时 $A[i-1][j]$（上一行同列）和 $A[i][j-1]$（同行前一列）都已经是前缀和值了，正确。
- **查询子矩阵和**：容斥公式，$O(1)$。

### 遍历顺序的正确性

构造二维前缀和时，计算 $(i,j)$ 需要：
- $S[i-1][j]$（上方）→ 上一行已经算完，正确
- $S[i][j-1]$（左方）→ 同行前一列已经算完，正确
- $S[i-1][j-1]$（左上方）→ 上一行前一列已经算完，正确

因此按行优先或列优先遍历均正确。

## 常见陷阱与注意事项

1. **下标从 1 开始**
   - 与一维前缀和同理，二维前缀和也从 $(1,1)$ 开始，第 0 行和第 0 列为 0。
   - 好处：边界查询（如 $x_1=1$ 或 $y_1=1$）无需特判。

2. **容斥公式别记错**
   - 构造：$+$ 上方 $+$ 左方 $-$ 左上
   - 查询：$-$ 上矩形 $-$ 左矩形 $+$ 左上矩形
   - 记忆技巧：两次加了重叠区域就减，两次减了重叠区域就加。

3. **数据类型**
   - 二维前缀和数值更大：$n = 10^3, m = 10^3$，每个元素 $10^9$，总和可达 $10^{15}$，必须用 `long long`。

4. **原地修改**
   - 本代码原地修改矩阵，原始值丢失。若需保留原始矩阵，应开两个二维数组。

5. **不支持动态修改**
   - 修改一个元素需要更新其后所有前缀和，$O(nm)$ 时间。
   - 动态修改 + 子矩阵查询应使用二维树状数组或二维线段树。

6. **坐标约定**
   - $(x_1, y_1)$ 是左上角，$(x_2, y_2)$ 是右下角，保证 $x_1 \le x_2, y_1 \le y_2$。
   - 若输入不保证顺序，需先 `swap` 调整。

## 扩展应用

### 二维差分

二维前缀和的逆操作是二维差分。子矩阵 $(x_1, y_1) \sim (x_2, y_2)$ 加 $w$：

$$d[x_1][y_1] \mathrel{+}= w, \quad d[x_1][y_2+1] \mathrel{-}= w, \quad d[x_2+1][y_1] \mathrel{-}= w, \quad d[x_2+1][y_2+1] \mathrel{+}= w$$

还原时先做行前缀和，再做列前缀和（或先列后行）。

### 更高维前缀和

前缀和可扩展到三维甚至更高维，容斥项数量为 $2^k$（$k$ 为维度）。三维前缀和构造有 8 项（加 3 个面、减 3 条棱、加 1 个角）。

### 前缀和优化 DP

二维前缀和常用于二维 DP 中快速求子矩阵和，将转移从 $O(nm)$ 优化为 $O(1)$。
