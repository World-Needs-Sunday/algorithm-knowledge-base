## 算法原理

树是图论中最特殊、也最重要的一类图。它不仅在算法竞赛中频繁出现，而且很多复杂图论问题（如网络流、树链剖分）的解题起点，就是先把图转化成树来处理。可以说，掌握了树，就掌握了图论的大半。

### 树的定义与性质

**定义**：树是一个**连通且无环**的无向图。这意味着树上任意两个顶点之间有且仅有一条简单路径；若一棵树有 $n$ 个顶点，那么它恰好有 $n-1$ 条边。

由「连通性」和「无环性」可以推出许多重要性质：

- 树是**边数最少的连通图**：再少一条边就不连通了。
- 树是**边数最多的无环图**：再多一条边就会出现环。
- 任意两个顶点之间有且仅有一条简单路径（这是树最核心的性质）。
- 删去一条边会把树分成两个连通块；加一条边会产生唯一一个环。

**有根树与无根树**：若给树指定一个特殊顶点作为「根」，就得到有根树。根的存在引入了父子关系、子树、深度等概念，树形 DP 等大量算法都建立在有根树上。

### 树为什么重要

树本质上是一种特殊的图，因此图上的 DFS、BFS 都能直接用于树上，而且树的结构会让搜索更简单、更高效：

1. 树上 DFS 不会「重复访问」（因为无环），因此不必维护 visited 数组，只需在递归时传入父节点防止往回走。
2. 树的深度优先遍历天然具有「先处理子树、再回溯」的结构，与树形 DP 的「自底向上」过程完美契合。
3. 树上的 BFS 可以快速求出每个节点到根的距离（深度），这也是求边权为 1 时最短路的简单方式。

## 核心公式 / 状态定义与转移方程

### 树的边数与路径

- **边数**：$n$ 个顶点的树恰有 $n-1$ 条边。
- **路径唯一性**：任意两点 $u,v$ 之间存在且仅存在一条简单路径。

### 树的直径

直径是树上最长的简单路径。经典求法是**两次 DFS**：任选一点 $s$ 找最远点 $u$，再从 $u$ 出发找最远点 $v$，则 $u$ 到 $v$ 即为一条直径，长度为 $\text{dist}(u,v)$。第一次找到的点 $u$ 一定是某条直径的端点，该性质只对树成立。

直径的中点称为树的**中心**，它位于直径的正中间（直径长度为奇数时中心是一条边），是所有点中「到最远点距离最小」的平衡点。

### 树的重心

重心是删除后使剩余各连通块中**最大块大小最小**的节点。删去节点 $u$ 后，最大的连通块大小为

$$
\max\Bigl(\max_{v \in \text{child}(u)} sz[v],\ n - sz[u]\Bigr)
$$

使该值取最小的节点即为重心。树最多有两个重心，且若有两个，它们相邻。

### 最近公共祖先（LCA）的树上距离

若记 $\text{dep}[x]$ 为节点 $x$ 的深度（无权树），则

$$
\text{dist}(u,v) = \text{dep}[u] + \text{dep}[v] - 2\,\text{dep}[\text{LCA}(u,v)]
$$

若边带权，只需把 $\text{dep}$ 换成「根到该点的路径总权值」即可。这是处理树上路径问题的核心工具。

### 倍增法递推式

设 $f[u][k]$ 表示节点 $u$ 向上跳 $2^k$ 步到达的祖先，则

$$
f[u][0] = \text{parent}[u],\qquad f[u][k] = f\bigl[f[u][k-1]\bigr][k-1]\quad(k \ge 1)
$$

## 逐行代码解析

以下均为**思想步骤伪代码**，用于说明做法流程，不必与具体实现逐字对应。

### 树的 DFS 遍历

```cpp
void dfs(int u, int fa) {
    dep[u] = dep[fa] + 1;      // 记录深度
    sz[u]  = 1;                // 子树大小初始为 1
    for (int v : G[u]) {
        if (v == fa) continue; // 无环，只需防止走回父节点
        dfs(v, u);             // 递归处理子树
        sz[u] += sz[v];        // 回溯时累计子树大小
    }
}
```

- 由于树无环，不需要 visited 数组；`fa` 用于避免沿来路返回。
- 进入时先处理当前点，回溯时再汇总子树信息，正好对应「自底向上」。

### 求树的直径（两次 DFS）

```cpp
// 第一次：从任意点 s 出发找最远点 u
u = farthest(s);
// 第二次：从 u 出发找最远点 v
v = farthest(u);
// 直径长度 = dist(u, v)
```

- 第一次找到的 $u$ 必是某条直径的一个端点，因此第二次从 $u$ 出发即可得到直径。
- `farthest` 就是一次 DFS/BFS，顺带记录每个点的最远距离与来源。

### 求树的重心

```cpp
void dfs(int u, int fa) {
    sz[u] = 1;
    int big = 0;                    // 删去 u 后最大连通块的大小
    for (int v : G[u]) {
        if (v == fa) continue;
        dfs(v, u);
        sz[u] += sz[v];
        big = max(big, sz[v]);      // 各子树块
    }
    big = max(big, n - sz[u]);      // 上方那一整块
    if (big < ans) {                // ans 为当前最小"最大块"
        ans = big;
        centroid = {u};
    } else if (big == ans) {
        centroid.push_back(u);      // 重心最多两个且相邻
    }
}
```

### LCA 倍增法

```cpp
// 预处理：每个节点向上 2^k 步的祖先
void dfs(int u, int fa) {
    dep[u] = dep[fa] + 1;
    f[u][0] = fa;
    for (int k = 1; k <= LOG; k++)
        f[u][k] = f[f[u][k-1]][k-1];
    for (int v : G[u]) if (v != fa) dfs(v, u);
}

// 查询
int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    for (int k = LOG; k >= 0; k--)       // 第一步：深度对齐
        if (dep[f[u][k]] >= dep[v]) u = f[u][k];
    if (u == v) return u;                // v 恰是 u 的祖先
    for (int k = LOG; k >= 0; k--)       // 第二步：同步上跳
        if (f[u][k] != f[v][k]) u = f[u][k], v = f[v][k];
    return f[u][0];                      // 停在 LCA 的直接子节点上
}
```

## 复杂度分析

树本身是概念，不绑定单一实现；各算法的复杂度如下：

| 操作 / 算法 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 树的遍历 / 求直径 / 求重心 | $O(n)$ | $O(n)$ |
| LCA 倍增法 | 预处理 $O(n\log n)$，查询 $O(\log n)$ | $O(n\log n)$ |
| LCA Tarjan 离线 | 总 $O(n + q\,\alpha(n))$ | $O(n+q)$ |
| LCA 欧拉序 + ST 表 | 预处理 $O(n\log n)$，查询 $O(1)$ | $O(n\log n)$ |

其中 $n$ 为节点数，$q$ 为询问数，$\alpha$ 为反阿克曼函数（实际可视为常数）。总体上，树的常见基础操作多为 $O(n)$ 或 $O(n\log n)$ 级别。

## 适用场景

- **树形 DP**：树的「先处理子树、再回溯」结构与自底向上 DP 天然契合，广泛用于树上选点、树上背包等问题。
- **路径查询与统计**：借助 LCA 可 $O(\log n)$（或更优）回答树上距离、路径权值和等询问。
- **树上差分**：对路径批量加值后通过子树和还原，需要用 LCA 标记路径端点。
- **点分治 / 树分治**：重心保证每次删点后最大连通块不超过一半，使分治深度为 $O(\log n)$。
- **特殊形态转换**：链可以转成序列用线段树、前缀和处理；满二叉树等平衡形态适合分治与剪枝。
- **判断祖先关系**：$\text{LCA}(u,v)=u$ 当且仅当 $u$ 是 $v$ 的祖先。

## 常见陷阱与注意事项

- **DFS 忘记传父节点**：树虽无环，但若不加 `fa` 判断，会沿来路反复递归导致死循环或重复计数。
- **无根树必须先指定根**：涉及深度、子树大小等概念时，需先任选一个根转化为有根树。
- **两次 DFS 求直径只对树成立**：它依赖「最远点必是直径端点」这一树特有性质，不能直接套用到一般图或带负权图上。
- **重心的两个细节**：重心最多两个且相邻；判断条件可用「删去后各连通块大小均 $\le n/2$」，与「最大块最小」等价。
- **LCA 倍增要先对齐深度**：必须先把较深的节点上跳到同一深度，再同步上跳，顺序不能颠倒。
- **Tarjan 只能离线**：它需要一次性读入所有询问，无法应对动态增加的询问。
- **欧拉序长度为 $2n-1$**：每个节点「进入」「离开」各记录一次，共 $2n-1$ 个位置，不是 $n$。
- **区分重心与中心**：重心最小化「删点后最大连通块」，中心最小化「到所有点的最远距离」，两者含义不同。

## 对比与扩展

### LCA 三种求法对比

| 求法 | 预处理 | 单次查询 | 在线 | 特点 |
|---|---|---|---|---|
| 倍增法 | $O(n\log n)$ | $O(\log n)$ | 是 | 最常用、稳定，可顺带维护路径信息 |
| Tarjan 离线 | $O(n+q\,\alpha(n))$ | 均摊 $O(\alpha(n))$ | 否 | 总时间接近线性，适合询问极多的场景 |
| 欧拉序 + ST 表 | $O(n\log n)$ | $O(1)$ | 是 | 查询最快，但不支持修改 |

### 树的特殊形态对比

| 形态 | 特征 | 典型处理 |
|---|---|---|
| 链 | 每个节点度数最多为 2 | 转为序列问题，用前缀和、线段树处理 |
| 菊花图 | 一个中心节点连接其余所有点 | 贪心、DP 往往有简化性质 |
| 二叉树 | 每个节点最多两个子节点 | 用左右儿子设计状态，降低转移复杂度 |
| 满 / 完全二叉树 | 高度 $O(\log n)$ | 适合分治与搜索剪枝 |

### 树与一般图

树是一般无向图的特例（连通且无环），因此树上算法比一般图更简单、更高效；反过来，很多一般图问题的第一步是**把图转化为树**（如缩点、最小生成树、树链剖分），再在树上求解。

### 可延伸的方向

- **树链剖分**：把树拆成若干重链，配合线段树实现路径与子树的批量修改/查询。
- **点分治 / 边分治**：利用重心递归分治处理树上路径统计。
- **虚树**：在关键点极少时压缩原树，降低 DP 规模。
- **树上差分 / 树上启发式合并（DSU on Tree）**：进一步优化树上路径与子树统计。
