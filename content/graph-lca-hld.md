## 算法原理

重链剖分（Heavy-Light Decomposition, HLD）是一种将树分解为若干条链的技巧，使得树上任意一条路径最多跨越 $O(\log n)$ 条链。虽然本代码仅用于求 LCA，但重链剖分的能力远不止此——它还能支持树链上的区间修改/查询（配合线段树）、子树修改/查询等操作，是最通用的树问题工具之一。

### 核心思想：重儿子 + 链顶继承

树中每个节点 $u$ 的子树大小不同。设 $u$ 的子节点中子树最大的那个为**重儿子**（heavy son），其余为**轻儿子**（light son）。关键性质：

> **从任意节点沿轻边向上跳，每跳一次子树大小至少减半。**

因为重儿子的子树最大，若轻儿子的子树 $\ge \frac{\text{sz}(u)}{2}$，则重儿子的子树也 $\ge \frac{\text{sz}(u)}{2}$，两者之和超过 $\text{sz}(u)$，矛盾。因此轻儿子的子树 $< \frac{\text{sz}(u)}{2}$，沿轻边上跳最多 $O(\log n)$ 次。

**重链**：从一个节点沿重儿子一路向下延伸形成的链。同一条重链上的节点共享同一个**链顶**（top）。重链的链顶总是某个节点的轻儿子（或根节点）。

### 两次 DFS 预处理

**DFS 1（自底向上）**：求每个节点的深度 $h$、父节点 $fa$、子树大小 $sz$、重儿子 $z\_son$。

**DFS 2（自顶向下）**：分配链顶。重儿子继承父节点的链顶（同属一条重链），轻儿子自己作为新链顶（开新链）。

### LCA 查询

查询 $\text{LCA}(a, b)$ 时，若 $a$ 和 $b$ 在同一条重链上（`top[a] == top[b]`），则深度较浅的就是 LCA。若不在同一条重链上，则将**链顶较深**的那个节点跳到其链顶的父节点（跨过一条重链），重复直到在同一条链上。

每次跳跃跨越一条重链且至少经过一条轻边，由于沿轻边上跳最多 $O(\log n)$ 次，总跳跃次数 $O(\log n)$。

### 与倍增法、Tarjan 的对比

| 算法 | 预处理 | 查询 | 空间 | 在线/离线 | 可扩展性 |
|---|---|---|---|---|---|
| 倍增法 | $O(n \log n)$ | $O(\log n)$ | $O(n \log n)$ | 在线 | 可扩展路径信息 |
| Tarjan | $O(n + m)$ | $O(\alpha(n))$ | $O(n + m)$ | 离线 | 仅 LCA |
| 重链剖分 | $O(n)$ | $O(\log n)$ | $O(n)$ | 在线 | **极强**：树链区间操作、子树操作 |
| 欧拉序+ST表 | $O(n \log n)$ | $O(1)$ | $O(n \log n)$ | 在线 | 仅 LCA |

重链剖分预处理 $O(n)$、空间 $O(n)$ 均优于倍增法，查询同阶 $O(\log n)$，且可扩展性最强。

## 核心公式/状态定义与转移方程

### 状态定义

$$\text{fa}[u] = \text{节点 } u \text{ 的父节点}$$

$$h[u] = \text{节点 } u \text{ 的深度（根节点深度为 1）}$$

$$\text{sz}[u] = \text{以 } u \text{ 为根的子树大小}$$

$$z\_son[u] = \text{节点 } u \text{ 的重儿子（子树最大的子节点，若存在）}$$

$$\text{top}[u] = \text{节点 } u \text{ 所在重链的链顶}$$

### DFS 1 递推（自底向上）

子树大小：

$$\text{sz}[u] = 1 + \sum_{v \in \text{children}(u)} \text{sz}[v]$$

重儿子选择：

$$z\_son[u] = \arg\max_{v \in \text{children}(u)} \text{sz}[v]$$

本代码不显式存储 `sz`，而是通过返回值传递（`dfs1` 返回子树大小），仅保留重儿子 `z_son`。

### DFS 2 递推（自顶向下）

链顶分配：

$$\text{top}[v] = \begin{cases} \text{top}[u] & \text{若 } v = z\_son[u] \text{（重儿子继承父链顶）} \\ v & \text{若 } v \neq z\_son[u] \text{（轻儿子开新链）} \end{cases}$$

### LCA 查询

```
while top[a] != top[b]:
    if h[top[a]] >= h[top[b]]:
        a = fa[top[a]]       // 跳过 a 所在重链的链顶，到链顶的父节点
    else:
        b = fa[top[b]]       // 跳过 b 所在重链的链顶，到链顶的父节点
return h[a] < h[b] ? a : b   // 同链上深度浅的就是 LCA
```

### 复杂度

$$T_{\text{预处理}} = O(n), \quad T_{\text{查询}} = O(\log n), \quad S = O(n)$$

### 正确性证明

当 `top[a] != top[b]` 时，$a$ 和 $b$ 在不同重链上。将链顶较深的节点跳到其链顶的父节点，相当于跨过一条重链 + 一条轻边。LCA 必然在两条路径的分叉点，不会在已被跳过的链上（因为被跳过的链顶比另一条链浅，LCA 不可能在其下方）。最终同链时，深度浅的就是 LCA。

## 逐行代码解析

### 第 1 段：全局变量

```cpp
int N, M;
vector<int> fa, vis, h, z_son, top;
vector<vector<int>> A;
```

- **`fa`**：父节点数组。
- **`vis`**：复用两次——先用于找根（标记"是某节点子节点"），后未重置但不再使用。
- **`h`**：深度数组，根深度为 1。
- **`z_son`**：重儿子编号，无子节点时为 0（`vector` 默认初始化为 0，根初始化为 -1）。
- **`top`**：重链链顶编号。
- **`A`**：多叉树邻接表。

### 第 2 段：DFS 1——求深度、父节点、重儿子

```cpp
int dfs1(int rt, int t_h)
{
    int sz = 1, nmax = 0, tz_son = 0;
    h[rt] = t_h;
    for (int i : A[rt])
    {
        fa[i] = rt;
        int t_s = dfs1(i, t_h + 1);
        sz += t_s;
        if (t_s > nmax) tz_son = i, nmax = t_s;
    }
    z_son[rt] = tz_son;
    return sz;
}
```

- **`sz`**：当前子树大小，初始为 1（自身），加上所有子树的 `t_s`。
- **`nmax`**：记录最大子树大小，用于选重儿子。
- **`tz_son`**：临时记录重儿子编号。
- **`for (int i : A[rt])`**：遍历所有子节点，递归求子树大小，更新重儿子。
- **`z_son[rt] = tz_son`**：若无子节点，`tz_son = 0`（即不存在重儿子）。
- **返回值**：返回子树大小 `sz`，供父节点累加。

### 第 3 段：DFS 2——分配链顶

```cpp
void dfs2(int rt, int z_rt)
{
    for (int i : A[rt])
    {
        if (i == z_son[rt])
        {
            top[i] = z_rt;    // 重儿子继承父链顶
            dfs2(i, z_rt);
        }
        else
        {
            top[i] = i;        // 轻儿子自开新链
            dfs2(i, i);
        }
    }
}
```

- **参数 `z_rt`**：当前链顶编号。
- **重儿子**：`top[i] = z_rt`，继承父节点的链顶，继续沿重链向下延伸。
- **轻儿子**：`top[i] = i`，自己作为新链的链顶。
- **DFS 顺序**：先处理重儿子（优先级高），再处理轻儿子。虽然对本 LCA 代码无影响，但在配合线段树时需要按 DFS 序分配位置，先重后轻保证重链上节点 DFS 序连续。

### 第 4 段：LCA 查询

```cpp
int find(int a, int b)
{
    while (top[a] != top[b])
    {
        if (h[top[a]] >= h[top[b]]) a = fa[top[a]];
        else b = fa[top[b]];
    }
    return h[a] < h[b] ? a : b;
}
```

- **`while (top[a] != top[b])`**：$a$ 和 $b$ 不在同一条重链上时循环。
- **`h[top[a]] >= h[top[b]]`**：比较两条链顶的深度，将链顶较深的那个跳上去。
  - `a = fa[top[a]]`：从 $a$ 所在重链的链顶跳到其父节点，跨过一整条重链。
- **`return h[a] < h[b] ? a : b`**：同链后，深度浅的就是 LCA。

**关键细节**：比较的是 `h[top[a]]` 和 `h[top[b]]`（链顶深度），而不是 `h[a]` 和 `h[b]`（节点深度）。因为我们要将较深的链整体跳过去，而不是逐节点跳。

### 第 5 段：主函数——建树、找根、两次 DFS、查询

```cpp
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    cin >> N >> M;
    A.resize(N + 1);
    vis.resize(N + 1, false);
    for (int i = 1; i <= N; i++)
    {
        int n;
        cin >> n;
        A[i].resize(n);
        for (int j = 0; j < n; j++)
        {
            cin >> A[i][j];
            vis[A[i][j]] = true;
        }
    }
    int rt = 1;
    while (vis[rt]) rt++;

    fa.resize(N + 1);
    fa[rt] = rt;
    h.resize(N + 1);
    z_son.resize(N + 1, -1);
    dfs1(rt, 1);

    top.resize(N + 1);
    top[rt] = rt;
    dfs2(rt, rt);

    for (int i = 1; i <= M; i++)
    {
        int a, b;
        cin >> a >> b;
        cout << find(a, b) << '\n';
    }
    return 0;
}
```

- **建树**：输入每个节点的子节点数和子节点编号。
- **找根**：用 `vis` 标记所有"作为子节点"的节点，未被标记的是根。
- **`fa[rt] = rt`**：根的父节点设为自身，防止查询时越界。
- **`z_son.resize(N + 1, -1)`**：初始化为 -1 表示无重儿子。注意 `dfs1` 中若子树大小相等（`t_s > nmax` 严格大于），第一个遇到的较大子树会被选为重儿子，但若所有子树大小为 0（叶节点），`z_son` 保持 0（`vector` 默认值）。
- **`top[rt] = rt`**：根节点所在重链的链顶是根本身。
- **`dfs2(rt, rt)`**：从根开始分配链顶，根继承自身。

## 复杂度分析

### 预处理时间

| 步骤 | 复杂度 |
|---|---|
| 建树 + 找根 | $O(n)$ |
| DFS 1（每个节点访问一次） | $O(n)$ |
| DFS 2（每个节点访问一次） | $O(n)$ |
| **总计** | $O(n)$ |

### 查询时间

每次 `while` 循环至少跨过一条轻边，沿轻边上跳最多 $O(\log n)$ 次：

| 步骤 | 复杂度 |
|---|---|
| 跳链（最多 $O(\log n)$ 条重链） | $O(\log n)$ |
| 同链比较 | $O(1)$ |
| **总计** | $O(\log n)$ |

### 空间复杂度

| 数据结构 | 空间 |
|---|---|
| 树存储 `A` | $O(n)$ |
| `fa`, `h`, `z_son`, `top` | $O(n)$ |
| **总计** | $O(n)$ |

重链剖分只需 $O(n)$ 空间，优于倍增法的 $O(n \log n)$。

## 适用场景

### 适合使用重链剖分

- **树链区间操作**：路径修改/查询（如"将 $u \to v$ 路径上所有点权 $+w$"或"查询路径最大值"），配合线段树实现 $O(\log^2 n)$
- **子树区间操作**：子树修改/查询，利用 DFS 序将子树映射到连续区间
- **在线 LCA 查询**：$O(\log n)$ 查询，无需预处理 $O(n \log n)$
- **需要综合多种树操作**：LCA + 路径修改 + 子树查询，重链剖分是唯一能同时支持这些操作的算法
- **空间受限**：$O(n)$ 空间优于倍增法

### 不适合使用重链剖分

- **仅需 LCA 且查询量大**：Tarjan 离线法 $O(\alpha(n))$ 更快
- **仅需 LCA 且需要 $O(1)$ 查询**：欧拉序 + ST 表更合适
- **树动态变化**：加边/删边需要重新剖分

## 常见陷阱与注意事项

1. **重儿子的选择标准**
   - 本代码用 `t_s > nmax`（严格大于）选重儿子。若两个子节点子树大小相等，先遇到的被选为重儿子。
   - 选择标准不影响正确性，只影响重链的划分方式。任何划分方式都保证 $O(\log n)$ 跳跃次数。

2. **`z_son` 的初始化**
   - `z_son.resize(N + 1, -1)` 初始化为 -1。但 `dfs1` 中若无子节点，`tz_son = 0`（初始值），叶节点的 `z_son` 会被设为 0。
   - 注意 0 不是有效节点编号（节点从 1 开始），`dfs2` 中 `i == z_son[rt]` 比较时不会误匹配。

3. **根节点的父节点设为自身**
   - `fa[rt] = rt` 必须设置。查询中 `a = fa[top[a]]` 可能使 `a` 跳到根的链顶，再跳就是 `fa[rt] = rt`，不会越界。

4. **比较链顶深度而非节点深度**
   - `h[top[a]] >= h[top[b]]` 而非 `h[a] >= h[b]`。这是重链剖分 LCA 最容易写错的地方。
   - 我们要将整条重链跳过去，因此比较链顶深度。若比较节点深度，可能反复在同一条链内跳，死循环。

5. **DFS 2 的顺序**
   - 本代码先处理重儿子再处理轻儿子。对于纯 LCA 查询，顺序不影响正确性。
   - 但若配合线段树做树链操作，必须先重后轻，保证重链上节点的 DFS 序连续。

6. **`z_son` 为 0 的处理**
   - `vector` 默认初始化为 0。叶节点无子节点，`dfs1` 中 `for` 循环不执行，`z_son[叶] = 0`。
   - `dfs2` 中 `if (i == z_son[rt])` 判断，0 不会匹配任何有效子节点（编号从 1 开始），因此叶节点不会误判。

7. **多叉树输入格式**
   - 本代码输入格式为：每个节点先给子节点数，再给子节点编号。与倍增法、Tarjan 版本一致。

## 对比与扩展

### 四种 LCA 算法综合对比

| 算法 | 预处理 | 查询 | 空间 | 在线/离线 | 可扩展性 | 实现难度 |
|---|---|---|---|---|---|---|
| 倍增法 | $O(n \log n)$ | $O(\log n)$ | $O(n \log n)$ | 在线 | 可扩展路径信息 | 中 |
| Tarjan | $O(n + m)$ | $O(\alpha(n))$ | $O(n + m)$ | 离线 | 仅 LCA | 中 |
| 重链剖分 | $O(n)$ | $O(\log n)$ | $O(n)$ | 在线 | **极强** | 中 |
| 欧拉序+ST表 | $O(n \log n)$ | $O(1)$ | $O(n \log n)$ | 在线 | 仅 LCA | 较高 |

### 扩展：树链操作（路径修改 + 查询）

重链剖分最强大的扩展是支持树链操作。将每条重链映射到线段树的一个连续区间，路径操作转化为 $O(\log n)$ 次区间操作：

```cpp
// 路径 u → v 上所有点权 +w
void update_path(int u, int v, int w) {
    while (top[u] != top[v]) {
        if (h[top[u]] < h[top[v]]) swap(u, v);
        // 更新 [dfn[top[u]], dfn[u]] 区间
        seg_update(dfn[top[u]], dfn[u], w);
        u = fa[top[u]];
    }
    if (h[u] > h[v]) swap(u, v);
    // 更新 [dfn[u], dfn[v]] 区间
    seg_update(dfn[u], dfn[v], w);
}
```

总复杂度 $O(\log^2 n)$（$O(\log n)$ 次线段树操作，每次 $O(\log n)$）。

### 扩展：子树操作

DFS 序的性质：一棵子树在 DFS 序中对应一个连续区间 $[\text{dfn}[u],\; \text{dfn}[u] + \text{sz}[u] - 1]$。因此子树修改/查询只需一次线段树区间操作，$O(\log n)$。

### 扩展：无根树处理

本代码以有根树（子节点列表）形式输入。若题目给出无根树（边集），需建无向邻接表，DFS 时跳过父节点：

```cpp
void dfs1(int u, int fa_node, int depth) {
    fa[u] = fa_node;
    h[u] = depth;
    int sz = 1, nmax = 0, heavy = 0;
    for (int v : adj[u]) {
        if (v == fa_node) continue;
        int t = dfs1(v, u, depth + 1);
        sz += t;
        if (t > nmax) nmax = t, heavy = v;
    }
    z_son[u] = heavy;
    return sz;
}
```

### 扩展：长链剖分

与重链剖分类似，但选择子树**深度**最大的子节点为"长儿子"（而非子树大小最大的）。长链剖分的特点：

- 任意节点向上跳 $O(\sqrt{n})$ 条轻边
- 可用于 $O(1)$ 求树上 $k$ 级祖先（配合预处理）
- 适合维护与深度相关的信息（如子树中各深度的权值）
