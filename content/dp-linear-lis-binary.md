## 算法原理

最长上升子序列（LIS）问题求数组 $A$ 中最长的严格递增子序列的长度。朴素DP的时间复杂度为 $O(n^2)$，二分优化将其降到 $O(n \log n)$，是LIS的最优解法。

核心思想是维护一个数组 $B$，其中 $B[k]$ 表示长度为 $k$ 的上升子序列的最小末尾元素。这个定义是关键：对于每个长度 $k$，我们只关心所有长度为 $k$ 的上升子序列中末尾最小的那个，因为末尾越小越有利于后续元素延长子序列。

对每个新元素 $A[i]$，分两种情况处理：若 $A[i]$ 大于 $B$ 的末尾元素（即 $A[i] > B[\text{back}]$），说明 $A[i]$ 可以延长当前最长的上升子序列，直接将 $A[i]$ 追加到 $B$ 末尾。若 $A[i]$ 不大于 $B$ 的末尾元素，则在 $B$ 中用二分查找找到第一个大于等于 $A[i]$ 的位置，将其替换为 $A[i]$——这不会增加子序列长度，但会使该长度的末尾更小，为后续延长创造更有利条件。

替换操作的正确性在于：用更小的 $A[i]$ 替换 $B$ 中某位置的值，不会影响之前已经形成的更长子序列（因为只替换了第一个 $\geq A[i]$ 的位置，且 $A[i]$ 比该位置的旧值更小）。最终 $B$ 的长度（减去哨兵）即为LIS长度。

需要注意的是，$B$ 数组本身不一定构成真实的LIS（因为替换操作打乱了原始顺序），但其大小正确反映了LIS的长度。

## 状态定义与转移方程

状态定义：

$$B[k] = \text{所有长度为 } k \text{ 的上升子序列中，末尾元素的最小值}$$

转移规则：

$$\text{若 } A[i] > B[\text{back}]: \quad B.\text{push\_back}(A[i])$$

$$\text{否则}: \quad B\big[\text{lower\_bound}(A[i])\big] = A[i]$$

其中 `lower_bound` 返回 $B$ 中第一个 $\geq A[i]$ 的位置索引。

最终答案：

$$\text{ans} = |B| - 1$$

（减去哨兵元素 $0$）

## 逐行代码解析

```cpp
#include<bits/stdc++.h>
using namespace std;
int n;
vector<int> A;
vector<int> B;
int find(int x)
{
	int l = 0,r = B.size() - 1;
	while(l < r)
	{
		int mid = (l + r) / 2;
		if(x >= B[mid]) r = mid;
		else l = mid + 1;
	}
	return l;
}
int main()
{
	cin >> n;
	A.resize(n + 1,0);
	B.emplace_back(0);
	for(int i = 1;i <= n;i++) cin >> A[i];
	for(int i = 1;i <= n;i++)
	{
		if(A[i] > B.back()) B.emplace_back(A[i]);
		else B[find(A[i])] = A[i];
	}
	cout << B.size() - 1;
	return 0;	
} 
```

- **`A` 数组**：存储输入序列，下标从 $1$ 开始，大小 $n+1$。
- **`B` 数组**：维护的辅助数组，`B[k]` 表示长度为 $k$ 的上升子序列的最小末尾。初始化放入哨兵 $0$（假设元素均为正数，$0$ 作为虚拟的长度为 $0$ 的子序列末尾）。
- **`find` 函数**：手写二分查找，返回 $B$ 中第一个 $\geq x$ 的位置索引。使用 $l < r$ 的二分模板，当 $x \geq B[mid]$ 时收缩右边界，否则左边界右移。
- **主循环**：对每个 $A[i]$，若大于 `B.back()` 则追加（延长子序列），否则调用 `find` 找到替换位置并替换。
- **输出**：`B.size() - 1` 即为LIS长度（减去哨兵 $0$）。

## 复杂度分析

- **时间复杂度**：$O(n \log n)$。对每个元素 $A[i]$，要么 $O(1)$ 追加到 $B$ 末尾，要么 $O(\log n)$ 的二分查找替换位置。共 $n$ 个元素，总时间 $O(n \log n)$。
- **空间复杂度**：$O(n)$。`A` 和 `B` 数组各 $O(n)$。`B` 数组的大小不会超过 $n$（每个元素最多追加一次）。

## 适用场景

适用于求LIS长度且数据量较大（$n > 10^4$）的场景，是LIS的最优算法。广泛用于序列分析、调度问题、嵌套结构检测等。当 $n$ 较小（$< 10^3$）时朴素 $O(n^2)$ DP也可接受。

## 常见陷阱与注意事项

- **哨兵值的选取**：`B` 初始化放入 $0$ 作为哨兵，假设输入元素均为正数。若元素可能为 $0$ 或负数，哨兵应设为 $-\infty$ 或调整 `find` 函数跳过哨兵。
- **`find` 函数的正确性**：本代码的 `find` 使用 `x >= B[mid]` 作为收缩条件，找到的是第一个 $\geq x$ 的位置。若需严格递增（不允许相等），应改为 `x >= B[mid]`（替换第一个 $\geq x$ 的）；若需非递减（允许相等），应改为 `x > B[mid]`（替换第一个 $> x$ 的）。
- **`B` 不构成真实LIS**：`B` 数组中的值经过替换操作后可能不满足原始顺序，不能直接作为LIS输出。其大小正确反映LIS长度。
- **严格递增 vs 非递减**：若求最长非递减子序列（允许相等），`find` 的条件需调整为查找第一个 $> x$ 的位置。
- **`B` 数组的大小**：最终 `B.size() - 1` 才是LIS长度，需减去哨兵。

## 对比与扩展

与朴素 $O(n^2)$ DP相比，二分优化利用了 $B$ 数组"长度对应最小末尾"的单调性，将内层线性查找变为二分查找。若需输出具体LIS序列，需在二分优化的同时额外维护一个前驱数组（记录每个元素在LIS中的前驱），最后回溯输出。可扩展为二维LIS（如俄罗斯套娃问题）、带权LIS（求最大权值上升子序列）等变种。
