## 算法原理

Floyd-Warshall 算法（简称 Floyd）解决**全源最短路**（All-Pairs Shortest Path, APSP）问题：给定 $n$ 个节点、$m$ 条边的带权图，求所有节点对 $(i, j)$ 之间的最短距离。与 Johnson 算法不同，Floyd 的核心思想是**动态规划**——通过逐步允许更多节点作为中转点，迭代更新所有节点对的最短路径。

### 核心思想：逐步放宽中转节点

定义 $A^{(k)}[i][j]$ 为从 $i$ 到 $j$，**仅以 $\{1, 2, \ldots, k\}$ 中的节点作为中转点**时的最短距离。则：

- $A^{(0)}[i][j]$：不经过任何中转点，即直接边权 $w(i, j)$（若无边则为 $+\infty$）
- $A^{(k)}[i][j]$：在 $A^{(k-1)}$ 的基础上，考虑是否经过新中转点 $k$

关键洞察：从 $i$ 到 $j$ 的最短路径（只允许 $1..k$ 中转），要么**不经过** $k$（此时就是 $A^{(k-1)}[i][j]$），要么**经过** $k$（此时路径拆成 $i \to k$ 和 $k \to j$ 两段，各自只允许 $1..k-1$ 中转）。由此得到状态转移方程。

### 与其他全源最短路算法的关系

| 特性 | Floyd | Johnson | $n$ 次 Dijkstra |
|---|---|---|---|
| 核心方法 | 动态规划 | 重赋权 + Dijkstra | 逐源 Dijkstra |
| 时间复杂度 | $O(n^3)$ | $O(nm \log n)$ | $O(nm \log n)$ |
| 空间复杂度 | $O(n^2)$ | $O(n^2 + m)$ | $O(n^2 + m)$ |
| 负权边 | 支持 | 支持 | 不支持 |
| 负环检测 | 支持（对角线） | 支持（Bellman-Ford） | 不适用 |
| 适用图密度 | 稠密图 | 稀疏图 | 稀疏图且无负权 |
| 实现难度 | 极简 | 较复杂 | 简单 |

**选择原则**：当 $n$ 较小（$n \le 500$）或图为稠密图（$m$ 接近 $n^2$）时，Floyd 是最优选择；当 $n$ 较大且图为稀疏图时，Johnson 更优。

## 核心公式/状态定义与转移方程

### 状态定义

$$A^{(k)}[i][j] = \text{从 } i \text{ 到 } j \text{ 仅经过 } \{1, 2, \ldots, k\} \text{ 中转的最短距离}$$

### 初始化

$$A^{(0)}[i][j] = \begin{cases} 0 & \text{若 } i = j \\ w(i, j) & \text{若存在边 } (i, j) \\ +\infty & \text{否则} \end{cases}$$

### 状态转移方程

$$A^{(k)}[i][j] = \min\Big(A^{(k-1)}[i][j],\; A^{(k-1)}[i][k] + A^{(k-1)}[k][j]\Big)$$

含义：允许 $k$ 作为中转后，$i \to j$ 的最短距离 = $\min$（不经过 $k$，经过 $k$）。

### 空间优化

注意到 $A^{(k)}$ 只依赖 $A^{(k-1)}$，可以去掉第一维，用**滚动数组**直接在原矩阵上原地更新：

$$A[i][j] = \min\Big(A[i][j],\; A[i][k] + A[k][j]\Big)$$

原地更新之所以正确：更新时 $A[i][k]$ 和 $A[k][j]$ 的值要么是 $A^{(k-1)}$ 的值（本轮还没被更新过），要么是 $A^{(k)}$ 的值（本轮已经更新过）。但 $A^{(k)}[i][k] = A^{(k-1)}[i][k]$（经过 $k$ 再回到 $k$ 不会更短，否则存在负环），因此两者相等，原地更新不影响正确性。

### 最终结果

$$d(i, j) = A^{(n)}[i][j]$$

即允许所有 $n$ 个节点作为中转时的最短距离。

### 负环检测

若存在负环，则负环上的节点 $i$ 满足 $A^{(n)}[i][i] < 0$。因此算法结束后，检查对角线是否有负值即可判断是否存在负环。

## 逐行代码解析

### 第 1 段：输入与邻接矩阵初始化

```cpp
long long INF = 1e17;
int main()
{
    int n, m;
    cin >> n >> m;
    vector<vector<long long>> A(n + 1, vector<long long>(n + 1, INF));
    for (int i = 1; i <= n; i++) A[i][i] = 0;
```

- **`INF = 1e17`**：使用 `long long` 防止加法溢出。$10^{17}$ 远小于 `LLONG_MAX`（约 $9.2 \times 10^{18}$），保证 $A[i][k] + A[k][j]$ 两个 INF 相加不会溢出。
- **邻接矩阵 `A`**：$(n+1) \times (n+1)$，初始化全为 INF。
- **对角线置 0**：$A[i][i] = 0$，表示节点到自身距离为 0。

### 第 2 段：读入边（处理重边与无向图）

```cpp
    for (int i = 1; i <= m; i++)
    {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        if (A[u][v] > w)
        {
            A[u][v] = w;
            A[v][u] = w;
        }
    }
```

- **重边处理**：`if (A[u][v] > w)` 取最小边权。同一对节点间可能有多条边，只保留最短的。
- **无向图**：`A[u][v] = w; A[v][u] = w;` 双向建边。若为有向图，只需 `A[u][v] = w;`。
- **注意**：判断条件 `A[u][v] > w` 而非 `A[u][v] >= w`，这意味着遇到相同权值的多条边时不会重复赋值，但效果一样。

### 第 3 段：Floyd 三重循环（核心）

```cpp
    for (int k = 1; k <= n; k++)
    {
        for (int i = 1; i <= n; i++)
        {
            for (int j = 1; j <= n; j++)
            {
                A[i][j] = min(A[i][j], A[i][k] + A[k][j]);
            }
        }
    }
```

- **外层 `k` 必须在最外**：这保证状态转移的正确性——每一轮 $k$ 都是在"允许 $\{1..k\}$ 中转"的基础上更新。若 $k$ 在内层，会导致路径使用尚未更新完毕的中间结果，得到错误答案。
- **`A[i][j] = min(A[i][j], A[i][k] + A[k][j])`**：状态转移方程的直接实现。
- **原地更新**：直接在 $A$ 上修改，不需要额外矩阵。正确性依赖于 $A^{(k)}[i][k] = A^{(k-1)}[i][k]$ 这一性质（若不存在负环，经过 $k$ 再回到 $k$ 不会更短）。

### 第 4 段：输出结果

```cpp
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            cout << A[i][j] << ' ';
        }
        cout << '\n';
    }
    return 0;
}
```

- 输出 $n \times n$ 的最短距离矩阵，第 $i$ 行第 $j$ 列即 $d(i, j)$。
- 若 $A[i][j] = \text{INF}$，输出 $10^{17}$（可根据题目要求改为输出 `-1` 或 `NO`）。
- 若 $A[i][i] < 0$，说明存在经过 $i$ 的负环（本代码未显式检测，但可根据需要添加）。

## 复杂度分析

### 时间复杂度

三重循环，每层 $n$ 次，内部为 $O(1)$ 的 `min` 和加法运算：

$$T(n) = n \times n \times n \times O(1) = O(n^3)$$

与边数 $m$ 无关——无论图是稠密还是稀疏，Floyd 都执行固定 $n^3$ 次操作。

### 空间复杂度

邻接矩阵 $A$ 占用 $O(n^2)$ 空间。无额外数据结构，空间复杂度为 $O(n^2)$。

### 实际性能参考

| $n$ | 操作次数 | 耗时（约） |
|---|---|---|
| 100 | $10^6$ | $< 1$ ms |
| 200 | $8 \times 10^6$ | $\sim 10$ ms |
| 500 | $1.25 \times 10^8$ | $\sim 200$ ms |
| 1000 | $10^9$ | $\sim 2$ s（接近超时边界） |

一般竞赛中 Floyd 适合 $n \le 500$ 的场景。

## 适用场景

### 适合使用 Floyd

- **全源最短路**：需要所有节点对之间的最短距离（而非单源）
- **稠密图**：$m$ 接近 $n^2$，Floyd 的 $O(n^3)$ 不逊于 Johnson 的 $O(nm \log n) = O(n^3 \log n)$
- **$n$ 较小**：$n \le 500$ 时 $O(n^3)$ 可接受
- **存在负权边**：Floyd 天然支持负权边（无负环时）
- **需要检测负环**：结束后检查对角线即可
- **需要传递闭包**：将 `min`/`+` 替换为 `|`/`&`，Floyd 即可计算图的传递闭包（可达性矩阵）

### 不适合使用 Floyd

- **$n$ 很大**（$n > 1000$）：$O(n^3)$ 超时，应选 Johnson 或 $n$ 次 Dijkstra
- **只需单源最短路**：用 Dijkstra/Bellman-Ford 即可，$O(n^3)$ 浪费
- **存在负环且需报告路径**：Floyd 可检测负环但不便于还原具体环
- **稀疏图且 $n$ 中等**：Johnson 的 $O(nm \log n)$ 更优

## 常见陷阱与注意事项

1. **循环顺序：$k$ 必须在最外层**
   - 错误写法：$i \to j \to k$ 或 $j \to i \to k$，会导致某些路径在中间节点尚未充分松弛时就被使用
   - 正确写法：$k \to i \to j$，保证每一轮 $k$ 都是基于"允许 $\{1..k\}$ 中转"的完整更新

2. **INF 大小与溢出**
   - `INF` 不能取 `LLONG_MAX`，否则 `A[i][k] + A[k][j]` 两个 INF 相加溢出
   - 推荐 `INF = 1e17`，既足够大表示"不可达"，又保证两个 INF 相加不溢出 `long long`
   - 若用 `int`，推荐 `INF = 1e9`（$10^9$，两个相加 $2 \times 10^9$ 不超过 `INT_MAX` 约 $2.1 \times 10^9$，但很危险，建议用 `long long`）

3. **无向图 vs 有向图**
   - 本代码处理无向图：`A[u][v] = A[v][u] = w`
   - 若为有向图，删除 `A[v][u] = w;` 即可

4. **重边处理**
   - 输入可能有 $u$ 到 $v$ 的多条边，代码用 `if (A[u][v] > w)` 取最小值
   - 若不处理重边，后读入的边可能覆盖更短的边

5. **自环处理**
   - 初始化 `A[i][i] = 0` 已经处理了自环
   - 若输入包含负自环（$u = v, w < 0$），会被 `if (A[u][v] > w)` 覆盖，导致 $A[i][i] < 0$，这表示负环

6. **负环检测**
   - Floyd 结束后，若 $\exists i: A[i][i] < 0$，则存在负环
   - 本代码未显式检测，可根据题目要求在输出前添加检查

7. **路径还原**
   - Floyd 不直接支持路径还原。若需还原路径，需额外维护一个 `nxt[i][j]` 数组记录中转点
   - 更新时：`if (A[i][k] + A[k][j] < A[i][j]) { A[i][j] = A[i][k] + A[k][j]; nxt[i][j] = k; }`
   - 递归还原路径：$i \to \text{nxt}[i][j] \to j$，对 $i \to \text{nxt}$ 和 $\text{nxt} \to j$ 递归

## 对比与扩展

### Floyd vs Johnson vs Dijkstra×n

| 对比维度 | Floyd | Johnson | Dijkstra $\times n$ |
|---|---|---|---|
| 算法范式 | 动态规划 | 贪心 + 重赋权 | 贪心 |
| 时间复杂度 | $O(n^3)$ | $O(nm \log n)$ | $O(nm \log n)$ |
| 稠密图 ($m \approx n^2$) | $O(n^3)$ ✅ | $O(n^3 \log n)$ | $O(n^3 \log n)$ |
| 稀疏图 ($m \approx n$) | $O(n^3)$ | $O(n^2 \log n)$ ✅ | $O(n^2 \log n)$ ✅ |
| 负权边 | ✅ 支持 | ✅ 支持 | ❌ 不支持 |
| 负环检测 | ✅ 对角线 | ✅ Bellman-Ford | ❌ |
| 实现复杂度 | 极低（4 行核心） | 中等 | 低 |
| 路径还原 | 需额外数组 | Dijkstra 前驱数组 | Dijkstra 前驱数组 |
| 图的存储 | 邻接矩阵 | 邻接表 | 邻接表 |

### 扩展：传递闭包

将 Floyd 的 `min`/`+` 替换为 `|`/`&`，可计算图的**传递闭包**（Transitive Closure）——判断任意两点是否可达：

$$T^{(k)}[i][j] = T^{(k-1)}[i][j] \;\lor\; \big(T^{(k-1)}[i][k] \;\land\; T^{(k-1)}[k][j]\big)$$

代码只需将 `A[i][j] = min(A[i][j], A[i][k] + A[k][j])` 改为 `T[i][j] = T[i][j] | (T[i][k] & T[k][j])`。可用 `bitset` 优化到 $O(n^3 / w)$，其中 $w$ 为字长。

### 扩展：最小环

Floyd 可用于求图中**最小环**（边权和最小的环）。在处理中转点 $k$ 时，对于所有 $i < k$ 和 $j < k$，检查 $A[i][k] + A[k][j] + G[i][j]$（其中 $G$ 是原始边权）是否构成更小的环。时间复杂度仍为 $O(n^3)$。
