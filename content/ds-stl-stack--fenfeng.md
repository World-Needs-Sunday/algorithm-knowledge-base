## 算法原理

栈（stack）是一种**后进先出**（LIFO，Last In First Out）的线性数据结构：最后入栈的元素最先出栈。可以把栈想象成一摞盘子——每次只能从顶部放入或取出，无法直接操作中间或底部的元素。

在 C++ 中，标准库提供 `std::stack`（头文件 `<stack>`）。它并不是一个独立的容器，而是一个**容器适配器**：默认基于 `std::deque`（双端队列）实现，只对外暴露栈这一侧的接口，屏蔽了底层容器的细节。

栈只允许在**栈顶**这一个位置进行操作，因此接口非常简洁：

- `push(x)`：将元素 $x$ 压入栈顶
- `pop()`：弹出栈顶元素（不返回该元素）
- `top()`：返回栈顶元素的引用（不移除）
- `empty()`：判断栈是否为空
- `size()`：返回栈内元素个数

## 核心公式 / 状态定义与转移方程

设栈内元素自栈底到栈顶为序列 $S = (a_1, a_2, \ldots, a_n)$，其中 $a_1$ 为栈底、$a_n$ 为栈顶。三种基本操作的状态转移如下：

- 入栈：`push(x)` 后 $S = (a_1, \ldots, a_n, x)$，新栈顶为 $x$，长度变为 $n+1$
- 出栈：`pop()` 后 $S = (a_1, \ldots, a_{n-1})$，移除原栈顶 $a_n$，长度变为 $n-1$（要求 $n \ge 1$）
- 取栈顶：$\text{top}(S) = a_n$，栈状态不变

核心不变量是**后进先出**：元素出栈的顺序与入栈顺序恰好相反。若依次入栈 $x_1, x_2, \ldots, x_n$，则第一个出栈的元素必为 $x_n$，最后一个出栈的必为 $x_1$。

## 逐行代码解析

以 `std::stack` 的基本用法为例：

```cpp
#include <stack>       // 引入栈
using namespace std;

stack<int> st;         // 声明一个存放 int 的栈，默认基于 deque

st.push(1);            // 入栈 1，栈: [1]
st.push(2);            // 入栈 2，栈: [1, 2]，2 为栈顶
int x = st.top();      // 取栈顶，x = 2，栈不变
st.pop();              // 弹出栈顶，栈: [1]
bool b = st.empty();   // 判空，b = false
int n = st.size();     // 元素个数，n = 1
```

- `stack<int> st;` 声明时模板参数是元素类型；第二个模板参数可指定底层容器（默认 `std::deque`），如 `stack<int, vector<int>>`
- `top()` 只返回栈顶元素的**引用**，不删除；想要移除必须再调用 `pop()`
- `pop()` 无返回值，这是新手最容易写错的地方：不能写 `int x = st.pop();`
- 对空栈调用 `top()` 或 `pop()` 是未定义行为，操作前应先 `empty()` 判空

## 复杂度分析

`std::stack` 的所有成员操作都直接转调底层容器，均为常数时间：

| 操作 | 时间复杂度 | 说明 |
|---|---|---|
| `push(x)` | $O(1)$ | 在栈顶插入一个元素 |
| `pop()` | $O(1)$ | 删除栈顶元素 |
| `top()` | $O(1)$ | 返回栈顶引用 |
| `empty()` / `size()` | $O(1)$ | 查询状态与大小 |

空间复杂度取决于底层容器与元素数量，为 $O(n)$（$n$ 为栈内元素个数）。由于底层默认是 `deque`，`push` 可能触发动态扩容，但均摊后仍是 $O(1)$。

## 适用场景

- **括号匹配**：遇到左括号入栈、右括号与栈顶配对后出栈，遍历结束后栈为空即匹配成功
- **表达式求值与后缀表达式**：操作数入栈，运算符弹出栈顶若干操作数计算后把结果压回
- **模拟递归（DFS）**：把递归调用栈显式化，可避免递归层数过深导致的栈溢出
- **撤销 / 回退**：编辑器撤销、浏览器后退等历史记录，天然是后进先出
- **单调栈**：以栈为底层并维护栈内元素单调性，解决「下一个更大/更小元素」等问题
- **图的非递归遍历**：用显式栈替代系统调用栈做深度优先遍历

## 常见陷阱与注意事项

1. **`pop()` 不返回元素**：必须先 `top()` 取值、再 `pop()` 移除，否则会丢失数据
2. **对空栈操作是未定义行为**：调用 `top()` 或 `pop()` 前务必 `empty()` 判空
3. **栈不能随机访问**：`std::stack` 不提供 `operator[]`、迭代器与随机访问，只能操作栈顶；需要随机访问时应改用 `vector` 或 `deque`
4. **递归深度过大会爆栈**：系统调用栈空间有限，深层递归（如 $n$ 达 $10^5$ 以上）可能栈溢出，可改用显式 `std::stack` 模拟递归或增大栈空间
5. **底层容器默认是 `deque`**：若对内存布局有特殊要求，可指定 `std::vector` 作为底层容器，但要理解两者的分配差异

## 对比与扩展

| 对比维度 | `std::stack` | `std::queue` | `std::vector` | 单调栈 |
|---|---|---|---|---|
| 访问规则 | 后进先出（LIFO） | 先进先出（FIFO） | 随机访问 | 后进先出 + 单调性 |
| 插入 / 删除位置 | 栈顶 | 队尾入 / 队头出 | 任意位置 | 栈顶 |
| 随机访问 | 否 | 否 | 是 | 否 |
| 典型用途 | 括号匹配、递归模拟 | 层序遍历、BFS | 顺序存储 | 下一个更大元素 |

**扩展**：

- **手写数组栈**：用数组 `stk[]` 加指针 `top` 模拟栈，常数更小、空间可控，适合竞赛中频繁操作
- **双栈实现队列**：用两个栈 `in`、`out` 分别负责入队和出队，可 $O(1)$ 均摊实现队列
- **单调栈**：在普通栈基础上维护单调性，解决区间最值相关的一类问题
- **栈与递归**：函数调用本身依赖系统栈，理解栈有助于调试递归与爆栈问题
