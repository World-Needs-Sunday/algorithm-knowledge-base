## 算法原理

对于**有向无环图（DAG）**，求单源最短路可以通过**拓扑排序**在 $O(n+m)$ 时间内完成，比 Dijkstra 的 $O(m \log n)$ 更快，且能处理**负权边**（只要图中没有环）。

### 核心思想

在 DAG 中，所有路径都沿着拓扑序单向延伸。当处理节点 $u$ 时，所有能到达 $u$ 的前驱节点都已经被处理完毕，因此 $u$ 的最短距离已经确定，可以直接用它去松弛后继节点。

换句话说：**按拓扑序依次松弛每条边，每个节点入队时其最短路值就已经是最终答案**。

### 为什么正确

- DAG 中没有环，所以存在拓扑序
- 对于任意边 $u \to v$，在拓扑序中 $u$ 一定出现在 $v$ 之前
- 当处理 $u$ 时，$dis[u]$ 已经是从源点到 $u$ 的最短距离（所有到达 $u$ 的路径都已被考虑）
- 用 $dis[u]$ 松弛 $v$，即考虑了经过 $u$ 到达 $v$ 的路径
- 当 $v$ 的入度减为 0 时，所有能到达 $v$ 的前驱都已处理完毕，$dis[v]$ 就是最终最短路

## 算法步骤

以 Kahn 拓扑排序为基础，在出队时松弛邻边：

1. **建图**：读入 $n$ 个点、$m$ 条有向边，建邻接表并记录入度
2. **找源点**：入度为 0 的节点即为 DAG 入口（本题假设唯一）
3. **初始化距离**：源点距离为 0，其余为无穷大
4. **拓扑排序 + 松弛**：
   - 入度为 0 的节点入队
   - 取出队首节点 $u$，遍历所有出边 $u \to v$，权值 $w$
   - 松弛：$dis[v] = \min(dis[v], dis[u] + w)$
   - $v$ 的入度减 1，若入度变为 0 则入队
5. **输出结果**：遍历所有节点，输出最短距离

## 逐行代码解析

### 找入口节点

```cpp
int idx = 1;
while (in[idx]) idx++;  // 找到第一个入度为 0 的节点
```

DAG 中入度为 0 的节点是起点。本题假设入口唯一，若有多个源点需全部入队。

### 拓扑排序 + 松弛

```cpp
vector<int> que(n + 5);
vector<long long> dis(n + 1, 1e18);
dis[idx] = 0;
int l = 0, r = 0;
que[r++] = idx;
while (l != r)
{
    int top = que[l++];
    for (pair<int, long long> i : edges[top])
    {
        dis[i.first] = min(dis[top] + i.second, dis[i.first]); // 松弛
        if (!(--in[i.first])) que[r++] = i.first;              // 入度为0则入队
    }
}
```

注意：松弛操作在入度减 1 之前进行，**无论入度是否为 0 都要松弛**。入度减为 0 只是判断该节点是否可以入队（即其所有前驱都已处理完毕）。

## 复杂度分析

- **时间复杂度**：$O(n+m)$
  - 每个节点入队一次、出队一次：$O(n)$
  - 每条边被松弛一次：$O(m)$
  - 比 Dijkstra（$O(m \log n)$）更快，且无需堆
- **空间复杂度**：$O(n+m)$
  - 邻接表：$O(m)$
  - 入度数组、距离数组、队列：$O(n)$

## 适用场景

1. **DAG 上的最短路/最长路**：可以处理负权边（DAG 中无负环）
2. **DAG 上的 DP**：很多 DAG DP 本质上就是拓扑排序上的递推
3. **关键路径**：DAG 最长路的经典应用
4. **有多个源点的情况**：只需将所有入度为 0 的节点初始距离设为 0 并全部入队

## 与其他最短路算法对比

| 算法 | 适用图 | 时间复杂度 | 负权边 | 实现难度 |
|------|--------|-----------|--------|---------|
| Dijkstra（堆优化） | 非负权图 | $O(m \log n)$ | ❌ | 中等 |
| Bellman-Ford | 任意图（无负环） | $O(nm)$ | ✅ | 简单 |
| SPFA | 稀疏图（无负环） | $O(km)$ 平均 | ✅ | 中等 |
| Floyd-Warshall | 任意图（无负环） | $O(n^3)$ | ✅ | 简单 |
| **DAG 拓扑排序** | **DAG** | **$O(n+m)$** | **✅** | **简单** |

DAG 上的最短路是所有最短路算法中**时间复杂度最优**的，前提是图必须是 DAG。

## 常见陷阱与注意事项

1. **必须是 DAG**：有环的图不能用此方法，拓扑排序无法完成
2. **松弛时机**：每条出边都要松弛，不管后继节点入度是否为 0；入度为 0 只是入队条件
3. **多个源点**：如果 DAG 有多个入度为 0 的节点，要全部初始化为距离 0 并入队
4. **数据类型**：路径可能很长，距离数组用 `long long`，无穷大设为 `1e18` 或 `LLONG_MAX`
5. **最长路变体**：把 `min` 改成 `max`、初始值改成 `-INF`，就是 DAG 最长路（关键路径）
6. **不可达节点**：距离仍为无穷大的节点表示从源点不可达，输出 -1

## 扩展：DAG 最长路（关键路径）

只需要改三处即可求 DAG 最长路：
- 距离数组初始化为 $-\infty$
- 源点距离为 $0$
- 松弛条件从 `min` 改为 `max`

```cpp
dis[v] = max(dis[v], dis[u] + w);  // 最长路松弛
```

关键路径问题（项目调度中各活动的最早完成时间）就是 DAG 最长路的典型应用。
