## 算法原理

字符串 $S$ 的循环同构串是将 $S$ 在某个位置断开并重新拼接得到的串。例如 $S = \text{"bcad"}$ 的循环同构串有 "bcad"、"cadb"、"adbc"、"dbca" 共 4 种。最小表示法的目标是找出所有循环同构串中字典序最小的那一个。朴素做法是枚举 $n$ 个起点逐字符比较，时间复杂度为 $O(n^2)$，在 $n$ 较大时不可接受。

最小表示法采用双指针 $i$、$j$ 分别表示两个候选起点，维护一个匹配长度 $k$。每轮比较从 $i$ 和 $j$ 出发的同构串的第 $k$ 个字符：若 $S[i+k] \ne S[j+k]$，则字典序较大那一侧的起点及其后的 $k$ 个位置都不可能成为最优起点，可直接跳过。具体地，若 $S[i+k] > S[j+k]$，则起点 $i, i+1, \ldots, i+k$ 均被排除，令 $i = i + k + 1$；反之令 $j = j + k + 1$。这种"批量跳过"策略是算法达到 $O(n)$ 的核心。

跳跃正确性的关键在于：若从起点 $i$ 出发的串在第 $k$ 位劣于从 $j$ 出发的串，那么对于任意 $i' \in [i, i+k]$，从 $i'$ 出发的串在第 $(i+k-i')$ 位恰好对应原 $S[i+k]$ 的字符（循环同构性质），因此 $i'$ 也一定劣于从 $j + (i'-i)$ 出发的串，无需再比较。为保证 $i \ne j$，当跳跃后两者相等时将其中一个加一错开。当 $k$ 达到 $n$ 时说明两个候选起点出发的串完全相同（整串存在周期 $|i-j|$），此时任一候选都是最小表示，直接跳出循环并返回 $\min(i,j)$。

## 核心公式

循环同构串定义（在位置 $i$ 断开）：
$$T_i = S[i..n] + S[1..i-1]$$

最小表示的目标：
$$\text{ans} = \arg\min_{0 \le i < n} T_i$$

双指针比较与跳跃规则（设 $k$ 为已匹配长度）：
$$\text{if } S[i+k] > S[j+k] \text{ then } i \leftarrow i+k+1, \quad \text{else } j \leftarrow j+k+1$$

跳跃排除的不等式（$S[i+k] > S[j+k]$ 时对任意 $d \in [0, k]$）：
$$T_{i+d} > T_{j+d}$$

最终结果取较小指针：
$$\text{ans} = \min(i, j)$$

## 逐行代码解析

### 模块 1：头文件与命名空间

```cpp
#include<bits/stdc++.h>
using namespace std;
```

- `#include<bits/stdc++.h>` 是竞赛常用的万能头文件，一次性引入标准库与 STL。
- `using namespace std;` 引入标准命名空间，省去每次书写 `std::` 前缀。

### 模块 2：fn 函数 —— 初始化、空串判断与拼接

```cpp
int fn(string str)
{
	int n = str.size();
	if (n == 0) return 0;            // 空串直接返回起点 0，避免后续越界

	str += str;                       // 拼接自身，把循环比较转为线性比较
	int i = 0;
	int j = 1;
```

- `str` 按值传入，函数内的 `str += str` 拼接的是副本，不影响 `main` 里的原串。
- `n = str.size()` 在拼接前记录原串长度；`if (n == 0) return 0` 显式处理空串，直接返回起点 $0$，避免空串进入双指针循环。
- `str += str` 把循环比较转为线性比较，之后从任意起点取 $n$ 个字符都无需取模回绕。
- `i = 0`、`j = 1` 是两个候选起点。

### 模块 3：fn 函数 —— 核心双指针匹配

```cpp
	while (i < n && j < n)
	{
		int k = 0;
		while (k < n && str[i + k] == str[j + k]) k++;  // 先判 k < n，短路避免越界

		if (k == n) break;            // 两串完全相同，跳出循环
```

- 外层 `while(i < n && j < n)`：两个候选起点都必须在原串范围内，其中一个越过 $n$ 即结束，此时另一个就是答案。
- 内层 `while` 逐字符比较两个候选同构串，`k` 是已匹配长度；`k < n` 放在 `&&` 前面先判断，当 $k$ 达到 $n$ 时短路停止，避免越界访问。
- `k == n` 说明两个不同起点的串完全相同（整串存在周期 $|i-j|$），此时任一候选都是最小表示，`break` 跳出循环后由 `return min(i,j)` 给出答案。

### 模块 4：fn 函数 —— 跳跃与收尾

```cpp
		if (str[i + k] < str[j + k])   // j 侧较大，跳过 j..j+k
		{
			j = j + k + 1;
			if (j == i) j++;           // 保证 i != j
		}
		else                          // i 侧较大，跳过 i..i+k
		{
			i = i + k + 1;
			if (i == j) i++;           // 保证 i != j
		}
	}
	return min(i, j);                  // 较小者为最小表示起点
}
```

- `str[i + k] < str[j + k]` 表示 i 侧更优，则跳过 j 侧 `j..j+k`；否则跳过 i 侧。
- `+ k + 1` 一次跳过 $k+1$ 个起点，是批量排除、把复杂度从 $O(n^2)$ 降到 $O(n)$ 的关键。
- `if(j == i) j++` / `if(i == j) i++` 防止两指针重合，避免自比死循环。
- 循环结束（无论正常退出还是 `k == n` 的 `break`）统一返回 `min(i, j)`，即最小表示的起点。

### 模块 5：main 函数 —— 读入与输出

```cpp
int main()
{
	string str;
	cin >> str;
	int idx = fn(str);
	int n = str.size();
	for (int i = 0; i < n; i++) cout << str[(i + idx) % n];   // 从最小起点输出 n 个字符
	return 0;
}
```

- 读入原串后调用 `fn(str)`，用 `idx` 接收最小起点。
- `n = str.size()` 记录原串长度，输出循环据此执行 $n$ 次。
- `(i + idx) % n` 利用取模从最小起点回绕输出 $n$ 个字符；`idx` 由 `fn` 保证落在 $[0, n-1]$ 内，下标合法。

## 复杂度分析

虽然外层 `while` 循环和内层 `k` 的比较看起来像嵌套循环，但关键在于指针 $i$ 和 $j$ 每次跳跃至少前进 $k+1$ 位，且 $k$ 是本轮新匹配的字符数。在整个算法执行过程中，$i$、$j$ 均不超过 $n$，而 $k$ 的累计增加值（即总比较次数）受 $i + j$ 的总移动量约束，最多为 $2n$。因此总比较次数为 $O(n)$，算法整体时间复杂度为 $O(n)$。拼接字符串额外使用 $O(n)$ 空间。

## 适用场景

环状字符串的判同构与归一化（如项链排列、环形序列的最小化表示）、字符串循环匹配、需要将循环同构串统一为唯一标准形式以便去重或比较的场景。

## 常见陷阱与注意事项

1. **内层比较的短路顺序**：`str += str` 后字符串长度为 $2n$，`i + k` 和 `j + k` 最大可达 $2n - 1$。内层条件必须写成 `k < n && str[i + k] == str[j + k]`（`k < n` 在前）：当 $k$ 达到 $n$ 时短路停止，不再访问 `str[i+k]`，既避免误读拼接后的第二份拷贝，也规避了顺序颠倒时可能的下标越界。
2. **`i == j` 未处理**：跳跃后两指针可能重合，若不错开则进入无限自比循环。代码中 `if(j == i) j++` 和 `if(i == j) i++` 必不可少。
3. **`k == n` 的含义**：当 $k$ 达到 $n$ 时并非找到了最小表示，而是说明两个不同起点的串完全相同，即整串存在周期 $|i-j|$（如 "abab" 这类周期串，而不仅是 "aaaa"）。此时直接 `break` 跳出循环，返回 `min(i,j)`，无需再作特殊标记。
4. **空串处理**：函数开头 `if (n == 0) return 0` 显式处理空串，直接返回起点 $0$，避免空串进入双指针循环引发越界；`main` 中 $n = 0$ 时输出循环自然不执行。
5. **指针越界上限**：外层条件为 `i < n && j < n`，当其中一个指针达到或超过 $n$ 时停止，此时另一个即为答案。注意是 `< n` 而非 `< 2n`，因为只需在原串范围内寻找起点。

## 对比与扩展

与朴素 $O(n^2)$ 枚举相比，最小表示法通过跳跃将复杂度降至线性，是处理循环同构问题的标准方法。与后缀数组方法（将拼接串建后缀数组取最小后缀）相比，最小表示法常数更小、实现更简洁。扩展方向包括：利用最小表示进行循环串判等（两个串的最小表示相同则循环同构）、与 KMP 结合解决循环匹配问题、以及推广到多串的最小公共循环表示等。
