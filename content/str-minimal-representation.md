## 算法原理

字符串 $S$ 的循环同构串是将 $S$ 在某个位置断开并重新拼接得到的串。例如 $S = \text{"bcad"}$ 的循环同构串有 "bcad"、"cadb"、"adbc"、"dbca" 共 4 种。最小表示法的目标是找出所有循环同构串中字典序最小的那一个。朴素做法是枚举 $n$ 个起点逐字符比较，时间复杂度为 $O(n^2)$，在 $n$ 较大时不可接受。

最小表示法采用双指针 $i$、$j$ 分别表示两个候选起点，维护一个匹配长度 $k$。每轮比较从 $i$ 和 $j$ 出发的同构串的第 $k$ 个字符：若 $S[i+k] \ne S[j+k]$，则字典序较大那一侧的起点及其后的 $k$ 个位置都不可能成为最优起点，可直接跳过。具体地，若 $S[i+k] > S[j+k]$，则起点 $i, i+1, \ldots, i+k$ 均被排除，令 $i = i + k + 1$；反之令 $j = j + k + 1$。这种"批量跳过"策略是算法达到 $O(n)$ 的核心。

跳跃正确性的关键在于：若从起点 $i$ 出发的串在第 $k$ 位劣于从 $j$ 出发的串，那么对于任意 $i' \in [i, i+k]$，从 $i'$ 出发的串在第 $(i+k-i')$ 位恰好对应原 $S[i+k]$ 的字符（循环同构性质），因此 $i'$ 也一定劣于从 $j + (i'-i)$ 出发的串，无需再比较。为保证 $i \ne j$，当跳跃后两者相等时将其中一个加一错开。当 $k$ 达到 $n$ 时说明整串由同一字符重复构成，返回特殊标记。

## 核心公式

循环同构串定义（在位置 $i$ 断开）：
$$T_i = S[i..n] + S[1..i-1]$$

最小表示的目标：
$$\text{ans} = \arg\min_{0 \le i < n} T_i$$

双指针比较与跳跃规则（设 $k$ 为已匹配长度）：
$$\text{if } S[i+k] > S[j+k] \text{ then } i \leftarrow i+k+1, \quad \text{else } j \leftarrow j+k+1$$

跳跃排除的不等式（$S[i+k] > S[j+k]$ 时对任意 $d \in [0, k]$）：
$$T_{i+d} > T_{j+d}$$

最终结果取较小指针：
$$\text{ans} = \min(i, j)$$

## 逐行代码解析

```cpp
#include<bits/stdc++.h>
using namespace std;

int fn(string str)
{
	int i = 0;
	int j = 1;
	int n = str.size();
	str += str;                       // 拼接自身，把循环比较转为线性比较
	while(i < n && j < n)
	{
		int k = 0;
		while(str[i + k] == str[j + k] && k < n) k++;  // 逐字符匹配
		if(k == n) return -1;         // 整串相同，全由同一字符重复
		if(str[i + k] < str[j + k])   // j 侧较大，跳过 j..j+k
		{
			j = j + k + 1;
			if(j == i) j++;           // 保证 i != j
		}
		else                          // i 侧较大，跳过 i..i+k
		{
			i = i + k + 1;
			if(i == j) i++;           // 保证 i != j
		}
	}
	return min(i,j);                  // 较小者为最小表示起点
}

int main()
{
	string str;
	cin >> str;
	int idx = fn(str);
	if(idx == -1)
	{
		cout << "有重复" <<endl;
		return -1;
	}
	for(int i = 0;i < str.size();i++)
		cout << str[(i + idx) % str.size()];   // 从最小起点输出 n 个字符
	return 0;
}
```

**关键解析：**

- `str += str`：将原串拼接为两倍长度，使得从任意起点 $i$ 出发取 $n$ 个字符时无需取模回绕，将循环问题转化为线性连续比较。
- `while(str[i + k] == str[j + k] && k < n) k++`：逐字符比较两个候选起点的同构串，`k` 记录已匹配长度。若 `k == n` 说明两串完全相同，意味着整串由单一字符重复构成，所有循环同构串相同。
- `j = j + k + 1`（或 `i = i + k + 1`）：跳跃操作。被跳过的 $k+1$ 个起点根据循环同构性质可以证明一定不是最优解，因此批量排除，这是将复杂度从 $O(n^2)$ 降至 $O(n)$ 的关键。
- `if(j == i) j++`：跳跃后若两指针重合则错开一位，保证每轮比较的两个起点不同，避免自比。
- `(i + idx) % str.size()`：最终从最小起点 `idx` 开始，利用取模回绕输出原串长度的字符，即得到最小表示。

## 复杂度分析

虽然外层 `while` 循环和内层 `k` 的比较看起来像嵌套循环，但关键在于指针 $i$ 和 $j$ 每次跳跃至少前进 $k+1$ 位，且 $k$ 是本轮新匹配的字符数。在整个算法执行过程中，$i$、$j$ 均不超过 $n$，而 $k$ 的累计增加值（即总比较次数）受 $i + j$ 的总移动量约束，最多为 $2n$。因此总比较次数为 $O(n)$，算法整体时间复杂度为 $O(n)$。拼接字符串额外使用 $O(n)$ 空间。

## 适用场景

环状字符串的判同构与归一化（如项链排列、环形序列的最小化表示）、字符串循环匹配、需要将循环同构串统一为唯一标准形式以便去重或比较的场景。

## 常见陷阱与注意事项

1. **拼接后下标越界**：`str += str` 后字符串长度为 $2n$，`i + k` 和 `j + k` 最大可达 $2n - 1$。若未拼接而直接用取模访问原串，内层 `k` 循环的取模运算会引入额外常数且容易出错。
2. **`i == j` 未处理**：跳跃后两指针可能重合，若不错开则进入无限自比循环。代码中 `if(j == i) j++` 和 `if(i == j) i++` 必不可少。
3. **`k == n` 的含义**：当 $k$ 达到 $n$ 时并非找到了最小表示，而是说明两个不同起点的串完全相同，即整串由同一字符重复。此时返回 $-1$ 表示特殊情况，需在调用处单独处理。
4. **空串处理**：当输入为空字符串时 `n = 0`，`i = 0, j = 1` 直接跳出循环返回 `min(0,1) = 0`，但后续输出循环不会执行，需确保边界安全。
5. **指针越界上限**：外层条件为 `i < n && j < n`，当其中一个指针达到或超过 $n$ 时停止，此时另一个即为答案。注意是 `< n` 而非 `< 2n`，因为只需在原串范围内寻找起点。

## 对比与扩展

与朴素 $O(n^2)$ 枚举相比，最小表示法通过跳跃将复杂度降至线性，是处理循环同构问题的标准方法。与后缀数组方法（将拼接串建后缀数组取最小后缀）相比，最小表示法常数更小、实现更简洁。扩展方向包括：利用最小表示进行循环串判等（两个串的最小表示相同则循环同构）、与 KMP 结合解决循环匹配问题、以及推广到多串的最小公共循环表示等。
