## 算法原理

Kosaraju 算法用于求出有向图中所有的**强连通分量（Strongly Connected Components, SCC）**。它的核心是进行**两次 DFS**，因此思路非常直观。

### 什么是强连通分量

对于一个有向图 $G$，一个点集 $S$ 称为强连通分量，当且仅当 $S$ 中任意两个节点互相可以到达（默认节点可以到达自身）。当一个强连通分量无法在保持强连通性质的同时再扩张时，称其为**极大强连通分量**，通常简称为 SCC。

极大 SCC 有两个关键性质：

- 每一个点只属于一个 SCC，即不同的极大 SCC **没有交集**。
- 将所有极大 SCC 缩成一个点后，所得的图是 **DAG**（有向无环图）。

这两条性质是「缩点」类题目成立的基础，也是 Kosaraju 正确性的关键。

### 两次 DFS 的基本流程

1. **第一次 DFS**：在原图 $G$ 上 DFS，记录每个点的**完成时间**（即该点的所有邻点都递归处理完毕的时刻）。DFS 完成后，将点按完成时间从小到大（或从大到小）保存，得到出栈序。
2. **第二次 DFS**：在**反图** $G^T$（把每条有向边的方向反转得到的图）上，按照第一次 DFS 完成时间的**逆序**依次进行 DFS。

### 为什么这样做正确

设原图缩点后形成 DAG。第一次 DFS 得到的完成时间能够保证：从某个 SCC 出发时，其完成时间顺序具有**拓扑意义**——即「出边方向的分量，完成时间更晚」。第二次在反图中按照完成时间逆序 DFS，由于反图把跨分量的边方向反转，恰好能把搜索**限制在同一个 SCC 内**，不会跨到别的分量。

因此，每次从一个尚未访问的点开始，在反图上能够访问到的所有点，恰好构成一个 SCC。

## 核心公式 / 状态定义与转移方程

Kosaraju 没有数值型的递推方程，它的「状态」体现在第一次 DFS 记录的时间戳与出栈序上，核心结论可以用一条引理表达。

### 反图定义

对每条有向边 $u \to v$，反图 $G^T$ 中有一条反向边 $v \to u$。原图与反图的边数相同，反图把「$u$ 能到达 $v$」变为「$v$ 能到达 $u$」。两个点 $u,v$ 强连通，当且仅当它们在原图和反图中都互相可达。

### 完成时间与出栈序

第一次 DFS 中，节点 $u$ 的所有邻点都递归处理完毕的时刻记为完成时间 $f[u]$。把节点按 $f[u]$ 递增的顺序压入序列 `order`，则 `order` 的末尾就是完成时间最晚的节点；从后往前遍历 `order`，等价于按完成时间**递减**的顺序处理。

### 关键引理

设缩点后的 DAG 中存在一条边 $C \to C'$（原图中分量 $C$ 有边指向分量 $C'$），则：

$$
\max_{u \in C} f[u] > \max_{v \in C'} f[v]
$$

即「出边方向的分量，其最大完成时间一定更晚」。于是按 $f$ 递减遍历时，$C$ 会先于 $C'$ 被处理；在反图中边的方向反转，从 $C$ 出发能到达的未分配节点恰好都还在 $C$ 内部（被它指向的分量都已更早处理并标记），从而每次 DFS 恰好圈出一个 SCC。

## 逐行代码解析

> 本节以**算法流程伪代码**说明 Kosaraju 的两个 DFS 步骤，不要求与某个完整程序逐字对应。

### 模块一：建图与反图

```cpp
vector<vector<int>> g, rg;              // 原图 / 反图 的邻接表
// 对每条有向边 u -> v：
g[u].push_back(v);
rg[v].push_back(u);                     // 反图：边方向反转
```

- 原图用于第一次 DFS，反图用于第二次 DFS，两者都要存。
- 反图的建法是在读入边 $u \to v$ 时，同时向 `rg[v]` 压入 $u$。
- 原图与反图各占 $O(n+m)$ 空间，这是 Kosaraju 相比 Tarjan 多出来的开销。

### 模块二：第一次 DFS——记录完成时间

```cpp
vector<int> order;                      // 出栈序，完成时间从早到晚排列
vector<bool> vis(n + 1, false);

void dfs1(int u) {
    vis[u] = true;
    for (int v : g[u])
        if (!vis[v]) dfs1(v);
    order.push_back(u);                 // 邻点全部处理完才压入（完成时间）
}
```

- 递归返回（所有邻点都访问完）时才把 $u$ 压入 `order`，压入的时机就是「完成时间」。
- `order` 的末尾是完成时间最晚的节点，逆序遍历即可得到「完成时间递减」的顺序。
- 对每个未访问节点都要调用 `dfs1`，保证不连通图也能被完整处理。

### 模块三：第二次 DFS——反图按逆序染色

```cpp
vector<int> comp(n + 1, 0);             // comp[u]：u 所属 SCC 编号，0 表示未访问
int cnt = 0;                            // SCC 计数

void dfs2(int u) {
    comp[u] = cnt;                      // 染色为当前分量
    for (int v : rg[u])
        if (!comp[v]) dfs2(v);
}
```

- 第二次 DFS 在反图 `rg` 上进行，而不是原图。
- `comp[u]` 记录 $u$ 所属的分量编号，同时兼作 `vis`（值为 0 表示未访问）。
- 从某个起点出发，在反图上能到达的所有节点都会被染成同一个 `cnt`。

### 模块四：主流程——串起两次 DFS

```cpp
// 第一次 DFS：处理每个未访问点（不连通图）
for (int u = 1; u <= n; u++)
    if (!vis[u]) dfs1(u);

// 第二次 DFS：按 order 逆序（完成时间从晚到早）遍历
for (int i = n - 1; i >= 0; i--) {
    int u = order[i];
    if (!comp[u]) { cnt++; dfs2(u); }
}
```

- 第一次 DFS 结束后 `order` 有 $n$ 个节点，从下标 $n-1$ 到 $0$ 就是完成时间的逆序。
- 第二次 DFS 每次从一个尚未染色的节点出发，得到一个新的 SCC，`cnt` 自增。
- 循环结束后 `cnt` 就是 SCC 的总数，`comp[u]` 给出了每个点所属的分量编号，可直接用于缩点。

## 复杂度分析

| 步骤 | 时间复杂度 |
|---|---|
| 第一次 DFS（原图） | $O(n+m)$ |
| 第二次 DFS（反图） | $O(n+m)$ |
| **总计** | $O(n+m)$ |

- **时间复杂度**：$O(n+m)$。两次 DFS 中，每个节点、每条边（原图与反图各一次）都恰好被访问一次，总代价线性。
- **空间复杂度**：$O(n+m)$。需要同时存储原图与反图两个邻接表，各 $O(n+m)$；此外 `order`、`vis`、`comp` 各 $O(n)$，整体仍为线性。

## 适用场景

1. **强连通分量检测**：求出有向图中所有 SCC，分析图的结构。
2. **缩点**：将每个 SCC 缩成一个点，把一般有向图转化为 DAG，然后做拓扑排序、最长路、DP 等。
3. **2-SAT 问题**：根据每个变量的两个状态是否落在同一 SCC 中判断可行性（可用 Kosaraju 替代 Tarjan 求 SCC）。
4. **有向图连通性判断**：判断两个节点是否互相可达，或统计入度为零的缩点个数。

与 Tarjan 相比，Kosaraju 多一次 DFS 且需要额外存反图，竞赛中通常首选 Tarjan；但当图以「边集」形式给出、且需要频繁从某分量出发做可达性分析时，Kosaraju「两次 DFS + 反图」的思路更直观，也便于在纸上复现。

## 常见陷阱与注意事项

1. **完成时间的记录时机**：必须在「所有邻点递归处理完」之后才把当前点压入 `order`。若在进入节点时就压入，得到的是「发现时间」而非「完成时间」，整个算法会失效。
2. **第二次 DFS 必须在反图上进行**：在原图上按出栈序逆序 DFS 得到的是错误的划分，务必使用 `rg`。
3. **遍历顺序是「完成时间的逆序」**：从 `order` 的末尾向开头遍历，而不是正向；顺序反了会跨分量错误染色。
4. **不连通图要遍历所有节点**：第一次 DFS 的外层循环要覆盖 $1$ 到 $n$ 的所有点，不能只从一个起点出发。
5. **`comp` 兼作访问标记**：第二次 DFS 用 `comp[u] == 0` 判断是否访问过；若另行维护 `vis`，要保证与 `comp` 同步，避免重复染色。
6. **反图建边方向别搞反**：读入 $u \to v$ 时，反图应写 `rg[v].push_back(u)`，方向反转才能让「反图上可达」等价于「原图上可互相到达」。
7. **缩点后是 DAG**：利用缩点图做拓扑 DP 前，要认识到缩点图无环，不能再按原图上的环去做。

## 对比与扩展

### 与 Tarjan 算法的对比

| 算法 | 思路 | DFS 次数 | 常数 | 直观程度 |
|------|------|---------|------|---------|
| Kosaraju | 正向 DFS 求出栈序 + 反图 DFS | 2 次 | 稍大 | 直观易理解 |
| Tarjan | 一次 DFS + 栈 + `dfn`/`low` | 1 次 | 小 | 较难理解 |

两者时间复杂度相同，都是 $O(n+m)$。Tarjan 只需一次 DFS，常数更小、代码也更短，竞赛中更常用；Kosaraju 需要额外存反图、多跑一遍 DFS，但思路更清晰，适合作为理解 SCC 的入门算法。相关内容见「Tarjan 强连通分量」。

### 缩点：SCC 的典型应用

求出 `comp` 后，可以构建**缩点图**：每个 SCC 是一个新节点，原图中跨 SCC 的边变成缩点图中的边。缩点图一定是 DAG。

```cpp
// 伪代码：构建缩点图
vector<vector<int>> new_edges(cnt + 1);
for (int u = 1; u <= n; u++)
    for (int v : g[u])
        if (comp[u] != comp[v])
            new_edges[comp[u]].push_back(comp[v]);
```

缩点后可以做：拓扑排序上的 DP（如求经过节点权值最大的路径）、求 DAG 上的最长路/最短路、统计入度为 0 的缩点个数（至少需要多少个起点才能走遍全图）等。

### 延伸阅读

- 掌握 SCC 后，可进一步学习**边双连通分量（E-DCC）**：它对应无向图中的「桥」结构，同样用 Tarjan 思想求解。
- 2-SAT 是 SCC 的经典应用，可用 Kosaraju 或 Tarjan 求出分量后判定可行性。
- Kosaraju 的「两次 DFS + 反图」思想也启发了很多「正向处理 + 反向处理」的图论套路，例如在某些可达性/支配性分析中先正后反各扫一遍。
