## 算法原理

**一句话结论**：bitset 把「一行布尔值」打包成若干个 64 位整数，把「一行对一行逐元素做布尔或」变成一次按机器字并行的整块或运算，常数缩小约 64 倍。用在 Floyd 传递闭包上，就是 $O(n^3)$ 的常数层面降到 $O(n^3/64)$。

**解决的问题**：传递闭包。以洛谷 P2881 [USACO07MAR] Ranking the Cows G 为例：有 $n$ 头奶牛、$m$ 条已知大小关系 $x < y$，关系具有传递性（$a<b,\ b<c \Rightarrow a<c$）。把牛看成点、$x<y$ 看成有向边 $x \to y$，则点对 $(i,j)$ 的关系已知，当且仅当 $i$ 能到达 $j$ 或 $j$ 能到达 $i$；答案 = 总点对数 $\dfrac{n(n-1)}{2}$ 减去关系已知的点对数。这就是传递闭包问题。

**朴素做法的瓶颈**：用 `bool reach[n][n]` 表示可达性，Floyd 三层循环：

```text
for k: for i: for j: if (reach[i][k] && reach[k][j]) reach[i][j] = true;
```

复杂度 $O(n^3)$，$n=1000$ 时约 $10^9$ 次判断，很容易超时。

**核心思想怎么来的**：固定 $k$ 和 $i$，若 `reach[i][k]` 为真，内层 $j$ 循环做的其实是：对每个 $j$，`reach[i][j] |= reach[k][j]`——等价于「第 $i$ 行整体或上第 $k$ 行」。逐元素的布尔或，可以改写成整行的按位或；而一行 0/1 如果打包成整数串，一次操作就能并行处理很多个 $j$。这正是 bitset 的切入点。

**bitset 是什么**：`std::bitset<N>` 是 C++ 标准库的定长二进制串，两个关键特点：每个元素只占 1 位（不是 1 字节）；`&` `|` `^` `~` `<<` `>>`、`count()` 等对整排位一次性运算，底层按 64 位机器字并行。本题把每个 `vis[i]`（点 $i$ 能到达哪些点）压成一整个 bitset：第 $j$ 位为 1 表示 $i$ 能到达 $j$。

**为什么这样做是对的**：对每个 $k$，当第 $k$ 轮处理完所有 $i$ 后，「只允许以编号 $\le k$ 的点作中间点」的可达关系全部算对（归纳：$k-1$ 轮成立，第 $k$ 轮把所有经过 $k$ 的路径补上）。`vis[i] |= vis[k]` 与朴素的内层 $j$ 循环在全部 $j$ 上的计算结果完全相同，只改变了计算方式，所以正确性与朴素 Floyd 传递闭包一致。

## 核心公式 / 状态定义与转移方程

**状态定义**：`vis[i]` 是长度为 `nmax` 的 bitset，`vis[i][j] = 1` 表示点 $i$ 能到达点 $j$（含 $j = i$）。下标从 0 开始，`vis[i][0]` 是最低位。

**初始化**：

- 对每条已知边 $x < y$：`vis[x][y] = 1`。
- 自反：`vis[i][i] = 1`，让转移形式统一（`vis[i][k]` 为真时整行并入不会漏掉 $k$ 自身）；代价是统计时多出 $n$ 个自环。

**转移方程**：

```text
if (vis[i][k]) vis[i] |= vis[k];
```

含义：若 $i$ 能到达 $k$，则 $k$ 能到达的所有点 $i$ 也都能到达，把 $k$ 的可达集合整行并入 $i$。$k$ 必须放最外层（与朴素 Floyd 相同），保证每一步用的都是已更新过的中间点信息。

**答案公式**：令 $sum = \sum_{i=1}^{n} vis[i].count()$（可达对数，含 $n$ 个自环），已知关系数（不含自反）为 $sum - n$，答案：

$$ans = \dfrac{n(n-1)}{2} - (sum - n) = \dfrac{n(n-1)}{2} - sum + n$$

**底层字映射**：bitset 内部用 64 位字数组存位：第 $j$ 位落在 `word = j >> 6`（即 $j/64$）号字、`bit = j & 63`（即 $j \bmod 64$）位。长度为 $N$ 的整行或只需约 $N/64$ 次字运算。

**手算示例**：$n=5$，已知关系 $1<2$、$2<3$、$4<5$。

初始（只列出用到的位，第 $j$ 列对应 vis 的第 $j$ 位）：

```text
vis[1]: 0 1 0 0 0     （1 能到 2）
vis[2]: 0 0 1 0 0     （2 能到 3）
vis[3]: 0 0 0 0 0
vis[4]: 0 0 0 0 1     （4 能到 5）
vis[5]: 0 0 0 0 0
```

自反后每个 `vis[i][i]` 置 1。$k=1$ 轮无变化；$k=2$ 轮：`vis[1][2]` 为真，`vis[1] |= vis[2]`，第 3 位变 1；$k=3$ 轮：`vis[1][3]` 为真，并入 `vis[3]` 无新增；$k=4$、$k=5$ 轮同理无新增。最终：

```text
vis[1]: 1 1 1 0 0     （count = 3）
vis[2]: 0 1 1 0 0     （count = 2）
vis[3]: 0 0 1 0 0     （count = 1）
vis[4]: 0 0 0 1 1     （count = 2）
vis[5]: 0 0 0 0 1     （count = 1）
```

$sum = 9$，答案 $= \dfrac{5 \times 4}{2} - 9 + 5 = 6$。已知关系 4 对（(1,2)、(1,3)、(2,3)、(4,5)），确实还差 6 对。

## 逐行代码解析

代码拆成 5 个模块，按顺序拼接即完整程序。

### 模块 1 头文件与全局数组

```cpp
#include<bits/stdc++.h>
using namespace std;
const int nmax = 1005;
bitset<nmax> vis[nmax];
```

- `vis[i]` 是第 $i$ 行，即点 $i$ 的可达集合，第 $j$ 位为 1 表示 $i$ 能到达 $j$。
- `nmax` 取 1005 覆盖 $n \le 1000$；bitset 的模板参数必须是编译期常量，否则编译不过。
- 全局数组默认全 0，不需要手动清零。

### 模块 2 main 与读入

```cpp
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr); cout.tie(nullptr);
	int n, m;
	cin >> n >> m;
	for (int i = 1; i <= m; i++)
	{
		int x, y;
		cin >> x >> y;
		vis[x][y] = true;
	}

```

- 关闭同步加速输入输出，$m$ 较大时读入也要快。
- 每条已知关系只置 `vis[x][y] = 1`（一条有向边）；反向位不能预先置，留给传递闭包自己推出来。

### 模块 3 自反初始化

```cpp
	for (int i = 1; i <= n; i++) vis[i][i] = true;

```

- 每个点自己可达自己，保证 `vis[i][k]` 为真时把 `vis[k]` 整行并入不会漏掉 $k$ 自身。
- 不初始化自反位会漏转移：部分可达对只能靠「终点自身」这一跳补齐。
- 代价是统计时多了 $n$ 个自环，答案公式里要相应补偿。

### 模块 4 Floyd 传递闭包

```cpp
	for (int k = 1; k <= n; k++)
	{
		for (int i = 1; i <= n; i++)
		{
			if (vis[i][k]) vis[i] |= vis[k];
		}
	}

```

- `k` 必须最外层：传递闭包要用已经更新过的中间点继续向外扩展；顺序颠倒会漏掉经多个中间点串联的可达对。
- `if (vis[i][k])` 是守卫：只有 $i$ 能到 $k$ 时才并入 $k$ 的行，省掉会错误继承无关可达关系。
- `vis[i] |= vis[k]` 一次处理整行约 1005 位（约 16 个 64 位字），替代朴素的内层 $j$ 循环。

### 模块 5 统计与输出

```cpp
	long long sum = 0;
	for (int i = 1; i <= n; i++) sum += vis[i].count();
	cout << (long long)n * (n - 1) / 2 - sum + n;
	return 0;
}
```

- `count()` 用 popcount 指令数每行的 1，$sum$ 是可达对数（含 $n$ 个自环）。
- `(long long)n * (n - 1) / 2`：先转 `long long` 再乘，防止 $n$ 较大时 int 溢出。
- 答案 = 总点对数 − 已知关系数（不含自反），即 $\dfrac{n(n-1)}{2} - sum + n$。

## 复杂度分析

- **时间**：Floyd 部分有 $n \times n$ 个 (k, i) 组合，每次整行或需约 $n/64$ 次字运算（bitset 长度按 $n$ 计），合计 $O(n^3/64)$；统计部分 $n$ 次 `count()` 共 $O(n^2/64)$。渐近意义下与朴素做法同阶（64 是常数），但实际快约 64 倍，$n=1000$ 时从约 $10^9$ 次判断降到约 $1.6 \times 10^7$ 次字运算。
- **空间**：$n$ 个长度为 $n$ 的 bitset 共 $n^2/8$ 字节，$n=1000$ 时约 128 KB；同样规模 `bool` 二维数组约 1 MB。按 64 位字计为 $O(n^2/64)$。

## 适用场景

- **传递闭包 / 可达性**：$n$ 在 500~2000 量级、朴素 $O(n^3)$ 常数吃紧时，把行压成 bitset 直接提速（P2881 就是典型）。
- **DAG 可达性统计**：按拓扑序逆序做 `bit[u] |= bit[v]`（$u \to v$），配合 `count()` 统计每个点能到达的点数（AcWing 164 可达性统计）。
- **0-1 可行性 DP**：子集和 / 0-1 背包可行性可用 `dp |= dp << w` 表示加入重量 $w$。
- **不要用**：长度必须由运行时输入决定且远超预留上限时——`bitset<N>` 的 $N$ 是编译期常量，应改手写 `vector<uint64_t>`；只做少量单点读写、不涉及整行运算时，`bool` 数组即可，bitset 没有收益。

## 常见陷阱与注意事项

1. **忘记 `vis[i][i] = 1`**：自反位缺失会让依赖「终点自身」的可达对漏推；但加上自反后统计必须减 $n$，两处要配套改。
2. **`if (vis[i][k])` 守卫省掉**：会把所有行无条件并入，多算大量不存在的可达关系，答案偏小。
3. **`k` 不在最外层**：颠倒成 $i$ 外层会漏掉经多个中间点串联的可达对；小随机样例往往测不出来，要用链状数据验证。
4. **答案公式符号**：是 $\dfrac{n(n-1)}{2} - sum + n$（等价于减去 $sum - n$），错写成 $- sum - n$ 会多减。
5. **int 溢出**：$n(n-1)$ 先乘再除可能溢出，写 `1LL * n * (n - 1) / 2`。
6. **bitset 长度用了变量**：`int n; cin >> n; bitset<n> ...` 编译不过；动态长度要手写 `vector<uint64_t>` 位集。
7. **`operator[]` 不检查越界**：`vis[i][j]` 的 $j$ 超过模板长度是未定义行为，开数组时长度必须 ≥ 数据上限。
8. **`count()` 返回 `size_t`**：是无符号类型，与负数、减法混合运算时小心无符号转换。
9. **下标从 0 开始**：`vis[i][0]` 是最低位，位下标与从 1 开始的图论点编号是两套下标，混用容易错位（本题 `vis[0]` 整行闲置）。

## 对比与扩展

**bool 二维数组 vs bitset 行压缩**：

| 操作 | bool 二维数组 | bitset 行压缩 |
|---|---|---|
| 单点读写 | O(1) | O(1)（多几次位运算） |
| 整行或 / count | O(N) | O(N/64)（按机器字并行） |
| 空间 | 1 字节/元素 | 1 bit/元素 |
| 越界检查 | 无 | 无 |

严格说 64 是常数，渐近复杂度不变；差距体现在常数的几十倍，对卡时限的传递闭包题就是「过」与「不过」的区别。

**与手写动态位集对比**：长度必须运行时决定时，手写 `vector<uint64_t>` 存位并封装 `|=` 和 `count()`（内部 popcount），思想与 `std::bitset` 完全一致，只是位定位要自己算 `word = j >> 6`、`bit = j & 63`。

**与 bitmask DP 的区别**：bitmask DP（如状压哈密顿路）以「二进制位编码集合状态」为核心，改变的是状态定义；bitset 优化以「整行布尔运算并行化」为核心，只改变运算方式，状态仍是普通布尔矩阵。

**延伸练习**（同一套路的迁移）：

- 洛谷 P4306 [JSOI2010] 连通数：传递闭包后求所有点能到达点数之和，代码结构几乎相同。
- AcWing 164 可达性统计：DAG 上按拓扑逆序做整行或。
- 子集和 / 0-1 背包可行性：`dp |= dp << w`，体会移位用法。
