## 〇、地基：补码（看懂一切负数位运算的钥匙）

初赛爱直接考"写出某负数的补码"，先把地基打牢。

**核心三条：**

- `-x = ~x + 1`（取反加一）
- `~x = -x - 1`
- `~0 = -1`（-1 的二进制是全 1；`~1 = -2`）

**手算负数补码（例：8 位表示 -12）：**

```
12      = 0000 1100
按位取反 = 1111 0011
加一     = 1111 0100    ← 这就是 -12 的补码
```

**反向读补码**：最高位权值取负，直接算数值：

```
1111 0100 = -128 + 64 + 32 + 16 + 4 = -12 ✓
```

**范围**：$n$ 位补码范围 $[-2^{n-1},\; 2^{n-1}-1]$，int 是 $[-2^{31},\; 2^{31}-1]$。

> ⚠️ **坑**：`-INT_MIN` 溢出（INT_MIN 的相反数还是它自己），`abs(INT_MIN)` 同理，判断题常设陷阱。

## 一、三大恒等式（逐位证明）

**原理**：二进制每一位独立分析。单看某一位：

每一位都满足：

```
a位 + b位 = (a|b位) + (a&b位)
a位 + b位 = (a^b位) + 2×(a&b位)    （1&1 时异或丢掉的 1 变成进位 ×2）
```

按位加权求和，得到全局恒等式：

```
a | b = a + b - (a & b)
a ^ b = (a | b) - (a & b)
a + b = (a ^ b) + 2 * (a & b)
```

**验证**：`a=6(110)`，`b=3(011)` → `a&b=2`，`a|b=7`，`a^b=5`，`a+b=9`

```
9 = 5 + 2×2 ✓    7 = 9−2 ✓    5 = 7−2 ✓
```

**记忆钩子：**

- 异或 = 无进位加法
- `a&b` = 同时为 1 的位（这些位相加会进位，所以 ×2）
- `a|b` = a+b 去掉重复的部分

> **考场用法**：题目给 `a&b` 和 `a|b`，直接 `a+b = (a|b) + (a&b)`，不用求出 a 和 b。

## 二、异或 ^（初赛出题率最高）

### 性质

```
x ^ x = 0            （自己消自己）
x ^ 0 = x            （0 是单位元）
交换律、结合律成立
x ^ x ^ x = x        （奇数次保持，偶数次抵消）
x ^ (~x) = 全1 = -1
x ^ (-1) = ~x        （异或全1 = 取反）
x ^ y = 0  ⟺  x = y
```

**为什么 `a^b=c` 能推出 `a=b^c`？** 两边同时异或 b：

```
a^b^b = c^b → a^0 = b^c → a = b^c
```

（靠的就是结合律 + `x^x=0` + `x^0=x`）

### 应用一：找只出现一次的数

其余数都出现偶数次，全部异或后成对抵消为 0，剩下那个单独的数。

```cpp
ans = 0;
for (每个数 x) ans ^= x;
```

### 应用二：1^2^3^…^n 的公式（超高频！）

设 $f(n) = 1 \oplus 2 \oplus \dots \oplus n$，只看 $n \bmod 4$：

| $n \bmod 4$ | $f(n)$ |
|---|---|
| 0 | $n$ |
| 1 | $1$ |
| 2 | $n + 1$ |
| 3 | $0$ |

**原理**：任意连续 4 个数异或为 0（如 `4^5^6^7=0`），周期为 4。

自测：$f(1)=1$，$f(2)=3$，$f(3)=0$，$f(4)=4$，$f(5)=1$ ✓

### 应用三：无临时变量交换（含大坑）

```cpp
a ^= b;
b ^= a;
a ^= b;
```

> ⚠️ **坑**：若 a、b 是同一块内存（如 `swap(a[i], a[j])` 且 `i==j`），第一步就变 0。判断题陷阱。

### 应用四：Nim 博弈（与博弈论结合的选择题）

$n$ 堆石子，每次任选一堆取任意多个。先手必胜 $\iff$ 所有堆大小的异或和 $\neq 0$；异或和 $= 0$ 则先手必败。

## 三、与 &、或 |、非 ~ 的代数定律

**幂等律：**

```
x & x = x        x | x = x
```

**零元 / 单位元：**

```
x & 0 = 0        x | 0 = x          （0 是 | 的单位元）
x & ~0 = x       x | ~0 = ~0        （全1 是 & 的单位元）
```

**互补：**

```
x & ~x = 0       x | ~x = ~0(全1)
```

**还原律：**

```
~~x = x
```

**分配律（双向！这和普通算术不同，两边都能展开）：**

```
a & (b | c) = (a & b) | (a & c)
a | (b & c) = (a | b) & (a | c)
```

**吸收律（补充，选择题用来化简）：**

```
a & (a | b) = a
a | (a & b) = a
```

**德摩根律（补充）：**

```
~(a & b) = ~a | ~b
~(a | b) = ~a & ~b
```

**结合律**：`&`、`|`、`^` 都满足；不满足消去律：`a&b = a&c` 推不出 `b=c`（但 `a|b = a|c` 且 `a&b = a&c` 可以推出 `b=c`）。

## 四、移位 << >>

### 左移

`x << k` = $x \times 2^k$（不溢出的前提下！），低位补 0。

> ⚠️ **坑**：
> - int 溢出后不再等于乘 $2^k$，`1 << 31` 对 32 位 int 是移入符号位（UB/结果常为 INT_MIN）。要表示 $2^{31}$ 就写 `1LL << 31` 或 `1u << 31`。
> - 移位数 ≥ 类型位宽也是 UB：`x << 32` ≠ `x << 0`，读程序题挖过坑。

### 右移

- 无符号数 / 非负数：`x >> k` = $\lfloor x / 2^k \rfloor$，高位补 0（逻辑右移）
- 有符号负数：高位补 1（算术右移）

> ⚠️ **超级考点——负数右移 ≠ C++ 除法**：
> - `-7 >> 1 = -4`（算术右移 = 向下取整，数学意义 $\lfloor -3.5 \rfloor$）
> - `-7 / 2 = -3`（C++ 除法 = 向零截断）
>
> 另外：`-1 >> k = -1`（全1右移还是全1）。

### 移位取模（补充）

非负 $x \bmod 2^k = $ `x & ((1 << k) - 1)`

例：`x & 0xF` = x 的低 4 位

> ⚠️ 负数时 `&` 给的是数学模（结果非负），`%` 给的是截断（可为负），如 `-7 & 3 = 1` 而 `-7 % 3 = -1`。

## 五、两大神器：x&(x-1) 和 x&(-x)

### x & (x-1)：清除最低位的 1

**原理**：设 `x = …A 1 00…0`（最低的 1 后面跟 k 个 0）

```
减 1 借位 → x-1 = …A 0 11…1 （最低的 1 变 0，后面的 0 全变 1）
相与     → …A 00…0          （那个 1 消失，高位原封不动）
```

例：`x=10100`, `x-1=10011`, `x&(x-1)=10000`

**两大衍生：**

**判断 2 的幂**：

```cpp
x > 0 && (x & (x-1)) == 0
```

（2 的幂二进制只有一个 1，消掉就变 0）

**数 1 的个数**：每次至少消一个 1，循环几次就有几个 1（比逐位判快）

```cpp
int cnt = 0;
while (x) { x &= x-1; cnt++; }
```

（GCC 内建：`__builtin_popcount(x)`）

### x & (-x)：取出最低位的 1

**原理**：`-x = ~x + 1`。设 `x = …B 1 00…0`

```
~x = …~B 0 11…1
加 1 的进位链恰好停在原最低 1 的位置，把它重新置 1：
-x = …~B 1 00…0
x 与 -x 相与：高位 B & ~B = 0，低位全 0，只剩那个 1。
```

例：`x = 10100`，`-x = …11101100`，`x & -x = 00100` ✓

> 📌 **澄清一个常见误解**：它对任意整数（含正数）都有效，前提是"负数用补码表示"——C++ 恰好就是补码，所以放心用。它也叫 **lowbit**，是树状数组（复赛）的核心操作。

### 姊妹公式（补充，判断题会考）

```
x & (x+1) == 0   ⟺  x 是 2^k - 1（二进制全1，如 0,1,3,7,15,255）
~x & (x+1)        ：取出最低位的 0
```

## 六、位操作四件套 + 状压集合（复赛也常用）

**单个位的操作**（i 从 0 开始，最低位是第 0 位）：

| 操作 | 代码 |
|---|---|
| 取第 i 位 | `(x >> i) & 1` → 0 或 1 |
| 第 i 位置 1 | `x \| (1 << i)` |
| 第 i 位清 0 | `x & ~(1 << i)` |
| 第 i 位翻转 | `x ^ (1 << i)` |

**状压 DP / 集合运算**（把集合塞进一个 int）：

```
全集 = (1 << n) - 1        空集 = 0
加入元素 i：s | (1 << i)
删除元素 i：s & ~(1 << i)
判断 i ∈ s：(s >> i) & 1 → 非 0
A ⊆ B：(A & B) == A
```

**枚举 s 的所有非空子集：**

```cpp
for (int t = s; t; t = (t - 1) & s) { /* ... */ }
```

**格雷码**（偶尔考概念）：`gray(x) = x ^ (x >> 1)`

## 七、运算符优先级——初赛第一大坑！

从高到低完整链条：

```
~（一元） >  * / %  >  + -  >  << >>  >  < <= > >=  >  == !=  >  &  >  ^  >  |  >  &&  >  ||  >  赋值
```

**关键结论**：`&`、`^`、`|` 的优先级比 `==` 还低！由此产生两大经典陷阱：

**陷阱 1**：

```cpp
if (x & 1 == 0)        // 实际是 if (x & (1 == 0)) = if (x & 0) = 恒假！
if ((x & 1) == 0)      // 正确
```

**陷阱 2**：

```cpp
1 << 2 + 3             // 实际是 1 << (2+3) = 1 << 5 = 32（加减高于移位）
```

> ⚠️ **附加坑**：`&&` 有短路求值，`&` 没有——`if (p != NULL & p->x)` 可能崩，`&&` 不会。

**口诀**：位运算表达式一律手动加括号，永不失手。

## 八、有符号 / 无符号坑

混比 / 混算时有符号自动转无符号：

- `-1 < 1u` 结果是 `false`（-1 变成 4294967295）。
- `unsigned` 永远 ≥ 0：`for (unsigned i = 5; i >= 0; i--)` 死循环。
- `v.size()` 返回 unsigned：`for (int i = 0; i < v.size() - 1; i++)` 在 v 为空时，`size()-1` 变成巨大数——读程序题常客。

## 九、大小关系不等式链（选择题排除神器）

对非负整数 $a$、$b$：

$$a \mathbin{\&} b \;\leq\; \min(a,b) \;\leq\; \max(a,b) \;\leq\; a \mathbin{|} b \;\leq\; a + b$$

$$且 \quad a \oplus b \;\leq\; a \mathbin{|} b$$

**原理**：`a&b` 每一位 ≤ a 对应位；`a|b = a+b−(a&b)` ≤ a+b。

**验证**：`a=6`, `b=3`：$2 \leq 3 \leq 6 \leq 7 \leq 9$，$5 \leq 7$ ✓

**配套判断：**

- `a + b == a | b` $\iff$ `a & b == 0`（无公共 1，加法无进位）
- `a ^ b == a | b` $\iff$ `a & b == 0`（同一个条件）
- `a ^ b == a + b` $\iff$ 同上

## 十、必背常数 + 进制转换基本功

**2 的幂表：**

| 幂次 | 值 | 幂次 | 值 |
|---|---|---|---|
| $2^0$ | 1 | $2^6$ | 64 |
| $2^1$ | 2 | $2^7$ | 128 |
| $2^2$ | 4 | $2^8$ | 256 |
| $2^3$ | 8 | $2^{10}$ | 1024 |
| $2^4$ | 16 | $2^{16}$ | 65536 |
| $2^5$ | 32 | $2^{20}$ | $\approx 10^6$ |

| 常数 | 值 |
|---|---|
| $2^{30}$ | $\approx 10^9$ |
| $2^{31}$ | 2147483648 |
| INT_MAX ($2^{31}-1$) | 2147483647 |
| INT_MIN ($-2^{31}$) | -2147483648 |
| UINT_MAX ($2^{32}-1$) | 4294967295 |

**估算口诀**：$2^{10} \approx 10^3$，$2^k \approx 10^{0.3k}$

**常用十六进制：**

```
0xFF = 255
0x7FFFFFFF = INT_MAX
0xFFFFFFFF = -1(int) = 4294967295(unsigned)
0x3F3F3F3F ≈ 1.06×10^9（memset 设"无穷大"，两倍不爆 int）
```

**进制转换**（初赛第一大题就是它）：

- 十→二：除 2 取余，逆序写；小数部分乘 2 取整
- 二→十六：从右往左 4 位一组；二→八：3 位一组
- $2^k$ 的二进制 = 1 后 k 个 0；$2^k - 1$ = k 个 1

## 十一、终极速记卡（考场默写版）

**【补码】** `~x+1`、`~x = -x-1`、`~0 = -1`（全1）

**【三大恒等式】**

```
a | b = a + b - (a & b)
a ^ b = (a | b) - (a & b)
a + b = (a ^ b) + 2*(a & b)      （异或=无进位加法）
```

**【异或】** `x^x=0`、`x^0=x`、`a^b=c ⟹ a=b^c`

$1 \oplus \dots \oplus n$：$n \bmod 4 = 0 \to n$，$1 \to 1$，$2 \to n+1$，$3 \to 0$

找单独数 / Nim（异或和 0 必败）

**【定律】** 分配（双向）、吸收 `a&(a|b)=a`、德摩根 `~(a&b)=~a|~b`

**【移位】** `x<<k` = $x \times 2^k$（防溢出写 `1LL<<k`）

负数右移是 floor，C++ 除法是向零截断：`-7>>1=-4` ≠ `-7/2=-3`

$x \bmod 2^k =$ `x & (2^k - 1)`

**【神器】** `x&(x-1)` 去掉最低位 1（判 2 幂 / 数 1 个数）

`x&(-x)` 取出最低位 1（lowbit，树状数组）

`x&(x+1)==0` $\iff$ x 是 $2^k - 1$

**【四件套】** 取：`>>i & 1`　置：`| 1<<i`　清：`& ~(1<<i)`　翻：`^ 1<<i`

**【大小链】** `a&b ≤ min ≤ max ≤ a|b ≤ a+b`；`a^b ≤ a|b`

**【优先级】** `~ > */% > +- > <<>> > 关系 > == > & > ^ > | > &&`

大坑：`x & 1 == 0` 实为 `x & (1==0)` 恒假；`1<<2+3 = 32`

铁律：位运算一律加括号！

**【无符号坑】** `-1 < 1u` 为假；`unsigned i≥0` 恒真；空容器 `size()-1` 爆炸

**【常数】** $2^{31}=2147483648$　INT_MAX $= 2147483647$　$2^{10} \approx 10^3$

> **使用建议**：每天默写一遍速记卡；做题时优先用"逐位分析"和"大小关系链"两条思路排除选项；遇到负数、unsigned、优先级三类题先警觉三分——初赛的坑 90% 藏在这三处。
