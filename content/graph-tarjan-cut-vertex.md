# Tarjan 求割点

## 一、问题定义

**割点（关节点）**：在无向图中，如果删掉某个点（以及它连的所有边）之后，图的连通分量数增加了，这个点就称为割点。

暴力做法是枚举每个点，删掉它后用 BFS/DFS 检查连通性，时间复杂度 $O(n(n+m))$，在大规模数据下会超时。

Tarjan 算法的精髓在于：**只做一次 DFS，就能同时判断所有点是不是割点**，复杂度 $O(n+m)$。

## 二、核心思想

删掉点 $u$ 之后图会不会断，关键看 $u$ 的"下方"（DFS 树中 $u$ 的子树）能不能不经过 $u$，绕回到 $u$ 的"上方"（$u$ 的祖先）。

- 如果能绕回去 → $u$ 的子树和其余部分除了 $u$ 还有别的通道，删 $u$ 不断
- 如果绕不回去 → $u$ 是子树通向外界的唯一通道，删 $u$ 后子树被孤立，$u$ 是割点

## 三、基础概念

### 1. DFS 生成树

对图做 DFS，第一次走到某个点所经过的边称为**树边**，所有树边构成一棵生成树。其余边称为**非树边**。

**重要性质**：无向图的 DFS 中，非树边一定是"连向祖先"的**返祖边**，不存在横叉边（连向完全另一棵子树的边）。这个性质是 Tarjan 正确性的基石。

### 2. dfn[u] —— 时间戳

`dfn[u]` 表示 $u$ 是第几个被访问到的点。它有两个作用：
- 作为"访问顺序"的编号，数值越小代表越靠近 DFS 的源头（越像"祖先"）
- 同时充当访问标记（0 = 未访问）

### 3. low[u] —— 能追溯到的最早时间戳

**定义**：$u$ 及其子树中的所有点，通过最多一条返祖边，能够到达的时间戳最小的点的时间戳。

直观理解：`low[u]` 回答的问题是——"$u$ 这一片区域，最远能'回头'摸到多早的祖先？"

- `low[u]` 越小 → 子树有强大的返祖通道，能绕过很多层祖先
- `low[u] >= dfn[u]` → 整个子树被 $u$ 封死了，任何回头路最多回到 $u$ 自己

**low 的维护规则**：

| 情况 | 更新方式 | 代码 |
|------|---------|------|
| 初始化 | `low[u] = dfn[u]`（至少能摸到自己） | `dfn[nd] = low[nd] = ++tim` |
| 走树边进入孩子 to | 孩子的回头能力可以继承给我 | `low[nd] = min(low[nd], low[to])` |
| 遇到返祖边连向已访问的 to | 直接一步跳到 to，能摸到 dfn[to] | `low[nd] = min(low[nd], dfn[to])` |

## 四、两个判定定理

### 定理 1：非根节点 u 是割点

**条件**：存在一个孩子 $v$，满足 $\text{low}[v] \geq \text{dfn}[u]$

**证明思路**：
- 如果 $v$ 的子树中所有返祖边最远只能回到 $u$ 或 $u$ 的后代（$\text{low}[v] \geq \text{dfn}[u]$），那么 $v$ 的子树与"$u$ 的祖先部分"之间，$u$ 是唯一通道。删掉 $u$，$v$ 的子树必然和上面断开。
- 反过来，如果每个孩子的子树都能绕到 $u$ 的严格祖先（$\text{low}[v] < \text{dfn}[u]$），删掉 $u$ 后各子树借返祖边跳到上方再互通，图仍然连通。

### 定理 2：根节点是割点

**条件**：它在 DFS 树中有 $\geq 2$ 个孩子

**为什么根不能用定理 1？** 因为根的时间戳最小（`dfn = 1`），`low[v] >= dfn[root]` 对任何孩子都恒成立，直接套用会得出"根永远是割点"的错误结论。根本身就是最高点，"绕不到根上面"对根没有意义。

**正确角度**：由"无向图 DFS 无横叉边"的性质，根的不同 DFS 子树之间一定没有边相连。所以：
- 孩子数 $\geq 2$ → 子树之间完全隔离 → 删根必断 → 根是割点
- 孩子数 $= 1$ → 整张图都在一棵子树里 → 根不是割点

> 注意：这里的"孩子"指 DFS 树中的孩子，不是图中的度数。比如星形图从叶子开始 DFS，中心节点有多个孩子（判为割点 ✓），叶子只有一个孩子（非割点 ✓）。用度数会误判。

## 五、代码逐行解析

### 变量定义

```cpp
int n, m, tim, cnt;
vector<vector<int>> edges;
vector<int> dfn, low;
vector<bool> is_cut;
```

| 变量 | 含义 |
|------|------|
| `n, m` | 点数、边数 |
| `tim` | 时间戳计数器 |
| `cnt` | 割点总数 |
| `edges` | 邻接表 |
| `dfn` | 每个点的时间戳，0 表示未访问 |
| `low` | 每个点子树能追溯到的最早时间戳 |
| `is_cut` | 标记每个点是否为割点 |

### 初始化函数

```cpp
void init()
{
    tim = 0;
    cnt = 0;
    dfn.assign(n + 1, 0);
    low.assign(n + 1, 0);
    is_cut.assign(n + 1, false);
}
```

重置所有数组和计数器，时间戳从 1 开始（0 表示未访问）。

### Tarjan 主函数

```cpp
void tarjan(int nd, int fa)
{
    int child_cnt = 0;
    dfn[nd] = low[nd] = ++tim;
```

- `nd`：当前节点；`fa`：父节点，根传 -1
- `child_cnt`：记录 DFS 树中的孩子数量
- 打时间戳，low 初始化为自己（"最差也能摸到自己"）

```cpp
    for (int to : edges[nd])
    {
        if (to == fa) continue;
```

枚举所有邻居，**跳过父亲边**。无向边在邻接表里存了两份，从孩子往回枚举时一定会碰到父亲，如果不跳过，就会把"来时的树边"误认成"返祖边"，导致所有点都判不出割点。

```cpp
        if (!dfn[to])                // 情况 1: to 未访问 → 树边
        {
            ++child_cnt;
            tarjan(to, nd);
            low[nd] = min(low[nd], low[to]);
            if (fa != -1 && low[to] >= dfn[nd] && !is_cut[nd])
                is_cut[nd] = true, cnt++;
        }
```

**情况 1：树边**
1. 孩子数 +1
2. 递归处理孩子（先递归，出来时 `low[to]` 才是最终值）
3. 继承孩子的回头能力：`low[nd] = min(low[nd], low[to])`
4. 定理 1 判定非根割点：`low[to] >= dfn[nd]` 且非根
   - `!is_cut[nd]` 去重：多个孩子都满足条件时只计数一次

```cpp
        else                         // 情况 2: to 已访问 → 返祖边
            low[nd] = min(low[nd], dfn[to]);
    }
```

**情况 2：返祖边**
- 用 `dfn[to]` 更新，不是 `low[to]`！
- 语义：返祖边是"我直接一步就能到达 to"，一步可达能摸到的最早值就是 `dfn[to]`
- 割点场景下误用 low[to] 恰好不出错，但割边（桥）会出 bug，养成用 `dfn[to]` 的正确习惯

```cpp
    if (fa == -1 && child_cnt >= 2)
        is_cut[nd] = true, cnt++;
}
```

**定理 2：根的特判**
- 必须等所有邻居枚举完（所有孩子都统计完）才能下结论
- 放在循环外、函数末尾

### 驱动函数

```cpp
void fn()
{
    init();
    for (int i = 1; i <= n; i++)
    {
        if (!dfn[i]) tarjan(i, -1);
    }
}
```

图可能不连通，对每个未访问的点都启动一次 DFS。每个连通块的第一个被访问点自动成为该块的 DFS 根，享受"孩子数 ≥ 2"的正确判定；孤立点孩子数为 0，不会被误判。

### 主函数

```cpp
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr); cout.tie(nullptr);
    cin >> n >> m;
    edges.assign(n + 1, {});
    for (int i = 1; i <= m; i++)
    {
        int u, v;
        cin >> u >> v;
        edges[u].emplace_back(v);
        edges[v].emplace_back(u);   // 无向图，双向加边
    }
    fn();
    cout << cnt << '\n';
    for (int i = 1; i <= n; i++)
    {
        if (is_cut[i]) cout << i << ' ';
    }
    return 0;
}
```

## 六、手动模拟示例

**图结构**：

```
1 — 2 — 3
    |
    4 — 5
```

边：1-2, 2-3, 2-4, 4-5

从 1 开始 DFS，路径 1→2→3→(回)→2→4→5：

| 步骤 | 动作 | 结果 |
|------|------|------|
| 1 | 进入 1 | `dfn[1]=low[1]=1` |
| 2 | 进入 2 | `dfn[2]=low[2]=2`，1 的 child_cnt=1 |
| 3 | 进入 3 | `dfn[3]=low[3]=3`，2 的 child_cnt=1 |
| 4 | 3 无未访问邻居，回溯 | `low[3]=3` 保持 |
| 5 | 回到 2，用孩子 3 更新 | `low[2]=min(2,3)=2`；`low[3]=3 >= dfn[2]=2` 且 fa=1 非根 → **2 是割点**，cnt=1 |
| 6 | 2 枚举邻居 4（未访问） | 进入 4，child_cnt[2]=2 |
| 7 | 进入 5 | `dfn[5]=low[5]=5` |
| 8 | 回到 4 | `low[4]=min(4,5)=4`；`low[5]=5 >= dfn[4]=4`，fa=2 非根 → **4 是割点**，cnt=2 |
| 9 | 回到 2 | `low[2]=min(2,4)=2`；low[4]>=dfn[2]，但 2 已标记，不重复计数 |
| 10 | 回到 1，枚举完毕 | 1 是根，child_cnt=1 < 2 → 不是割点 |

**结论**：割点为 2 和 4 ✓

## 七、复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | $O(n + m)$ | 每个点恰好访问一次，每条无向边在邻接表中各遍历一次 |
| 空间 | $O(n + m)$ | 邻接表 + dfn/low/is_cut 三个数组 |
| 递归深度 | 最坏 $O(n)$ | 链状图会达到最深。本题规模下安全；$n$ 达 $10^5$ 以上需改迭代版或加大栈空间 |

## 八、常见陷阱

1. **返祖边误用 `low[to]`**：应使用 `dfn[to]`。割点场景下恰好不出错，但割边会出 bug，养成正确习惯。
2. **忘记跳过父亲边**：树边被当返祖边，low 全部失效，所有点都判不出割点。
3. **根没有特判**：或误用 `low >= dfn` 判根，导致根永远 / 永不判中。
4. **用图的度数代替 DFS 树的孩子数**：重边、多入口都会使度数失真（见星形图反例）。
5. **忘记处理非连通图**：必须对每个未访问点都启动一次 DFS。
6. **割点判定写在递归之前**：用到未定型的 `low[to]`，判断错误。
7. **忘记去重**：一个点被多个孩子的条件反复触发时多计 cnt。
8. **重边与割点/割边的区别**：割点中"跳过所有 fa 边"没问题；但这个模板不能直接改成割边（桥）——桥必须只跳过"来时的那一条树边"（通常用边编号判断），否则有重边时桥会被漏判。

## 九、适用场景

- **求割点**：找出无向图中所有关节点
- **点双连通分量**：割点是点双连通分量的交界点，求割点是求点双的基础
- **网络可靠性分析**：判断哪些节点故障会导致网络分裂
- **2-SAT 问题**：某些变体需要借助割点分析
- **图的缩点**：点双连通分量缩成"圆方树"，割点是公共点

## 十、与强连通分量 Tarjan 的对比

| 维度 | 强连通分量 Tarjan | 割点 Tarjan |
|------|------------------|------------|
| 图类型 | 有向图 | 无向图 |
| 核心结构 | 栈维护当前 SCC | 无栈，靠 dfn/low 直接判定 |
| 判定条件 | `low[u] == dfn[u]` 弹出栈 | 非根：`low[child] >= dfn[u]`；根：child_cnt >= 2 |
| 父节点处理 | 不需要跳过父边 | 必须跳过父边（`to == fa` continue） |
| 输出 | 每个 SCC 的点集 + 颜色数组 | 割点标记数组 |
| 延伸算法 | 缩点 → DAG → 拓扑 DP | 点双连通分量、圆方树 |
