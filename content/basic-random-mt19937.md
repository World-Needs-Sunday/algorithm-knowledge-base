## 算法原理

解决的问题：在 C++ 里生成**高质量、可控**的随机数，用于造数据、对拍、随机化算法（如随机化快速选择）。

核心思想：C++11 的 `<random>` 库把随机数的生成拆成**引擎**和**分布**两个正交的部分：

- **引擎**（如 `std::mt19937`）负责产生伪随机序列。它是确定性的——给定同一个种子，产生的序列完全一样。种子决定序列的起点。
- **分布**（如 `std::uniform_int_distribution`）负责把引擎输出的均匀原始值映射为目标分布（指定类型与范围）。

标准流程只有三步：**种子初始化引擎 → 定义分布对象 → 用 `分布对象(引擎)` 生成随机数**。引擎只创建一次，分布对象可反复调用。

选择 `<random>` 而不是传统 `rand()` 的原因：`rand()` 质量差、周期短，且 `rand() % n` 会因模数不整除周期而引入**取模偏差**；`<random>` 的引擎与分布都更现代、更可控。

## 核心公式 / 状态定义与转移方程

三个常用分布的定义与取值区间：

- **整数均匀分布**：$X\sim U[a,b]$，闭区间，含两端点 $a,b$

$$
P(X=x)=\frac{1}{b-a+1},\quad x\in\{a,a+1,\dots,b\}
$$

- **实数均匀分布**：$X\sim U[a,b)$，左闭右开区间

$$
f(x)=\frac{1}{b-a},\quad x\in[a,b)
$$

- **正态分布**：$X\sim N(\mu,\sigma)$，参数为均值 $\mu$ 与标准差 $\sigma$

$$
f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

引擎侧的递推（了解即可）：`mt19937` 是梅森旋转算法，内部维护 624 个 32 位字的状态向量，每次生成按固定线性规则批量更新。种子只影响初始状态，所以「相同种子 → 相同序列」。

记忆口诀：**种子决定起点，分布决定形状，`dist(gen)` 生成最终随机数。**

## 逐行代码解析

```cpp
#include<iostream>
#include<ctime>//获取时间头文件
#include <random>//随机数头文件
using namespace std;
int main()
{
	//第一步,获取种子
	//std::mt19937 是随机数种子，有3种常见的获取方法

	//1,固定种子,每次生成的序列相同
	std::mt19937 reg_gen(13331);

	//2,简单时间种子,精确到秒
	std::mt19937 time_gen(static_cast<unsigned int>(std::time(nullptr)));

	//3,操作系统获取熵种子,从操作系统获取熵后处理出来的种子(最常用)
	std::random_device rd;
	std::mt19937 gen(rd());

	/*----------------------------------------------------------------------*/

	//第2步,定义分布对象(默认熵种子)

	//1,整形,均匀分布   范围; [0,100]
	std::uniform_int_distribution<int> number_dist(0, 100);
	
	//2,浮点型,均匀分布   范围: [0.0,1.0)
	std::uniform_real_distribution<double> float_dist(0.0, 1.0);

	//3,浮点型,正态分布   均值:10.0 , 标准差:2.0
	std::normal_distribution<double> nd_dist(10.0, 2.0);

	/*----------------------------------------------------------------------*/

	//第三步,生成随机数
	//格式: 分布对象(随机种子);
	
	//例子:   生成10个 整形,均匀分布   范围; [0,100] 的随机数
	for (int i = 0; i < 10; ++i) cout << number_dist(gen) << ' ';

	return 0;
}
```

- 头文件：`<ctime>` 提供 `std::time(nullptr)`（Unix 时间戳，秒级）；`<random>` 提供引擎与分布。
- `std::mt19937 reg_gen(13331);`：固定种子。每次运行序列完全相同，适合调试、复现。
- `std::mt19937 time_gen(static_cast<unsigned int>(std::time(nullptr)));`：以当前秒数作种子。缺陷是同一秒内启动的多个进程会产生相同序列。
- `std::random_device rd; std::mt19937 gen(rd());`：从操作系统取熵作种子，随机性最好，是最常用的写法。注意 `rd` 只在初始化时用一次。
- 三个分布对象：`number_dist(0, 100)` 生成闭区间 `[0,100]` 的 `int`；`float_dist(0.0, 1.0)` 生成 `[0.0,1.0)` 的 `double`；`nd_dist(10.0, 2.0)` 生成均值 $10.0$、标准差 $2.0$ 的正态分布 `double`。
- `number_dist(gen)`：把引擎 `gen` 传给分布对象，得到最终随机数；每次调用引擎内部状态前进一步。

## 复杂度分析

- **时间复杂度**：每生成一个随机数 $O(1)$（引擎递推是常数次位运算，分布映射是常数次缩放/查表）。
- **空间复杂度**：$O(1)$。`mt19937` 内部状态固定为 624 个 32 位字（约 2.5 KB），与生成数量无关。

## 适用场景

- **造数据 / 对拍**：按数据范围生成随机输入，配合暴力程序对拍验正确性；需要复现某个 bug 数据时换固定种子。
- **随机化算法**：需要随机 pivot、随机初始点、随机扰动打破坏数据时（如本库「快速选择」里的随机化选主元）。
- **随机打乱**：`std::shuffle(v.begin(), v.end(), gen)` 生成随机排列。
- 不适用：密码学相关需求（应使用 CSPRNG，如操作系统提供的安全随机源）、要求「真随机」的场景——`mt19937` 本质是**伪随机**，种子可被预测整个序列。

## 常见陷阱与注意事项

1. **在循环里反复播种**：每次循环都 `std::mt19937 gen(rd())` 是错误的——若循环执行得比熵源更新快，会反复拿到相同种子，产生相同序列。引擎放循环外，只创建一次。
2. **开闭区间记混**：`uniform_int_distribution` 是闭区间 `[a,b]`；`uniform_real_distribution` 是左闭右开 `[a,b)`。造数据时右端点差 1 会导致边界值缺失。
3. **正态分布不能用 `int` 模板参数**：`std::normal_distribution<int>` 不能编译。只能生成 `double`，需要整数时用 `std::lround` 四舍五入后再转。
4. **时间种子的精度只有秒**：同一秒内多次运行 `time(nullptr)` 种子相同，序列相同（对拍的重启间隔小于 1 秒时尤其明显）；要区分进程就用 `random_device` 或混合进程 ID。
5. **旧接口的取模偏差**：`rand() % n` 在 `RAND_MAX+1` 不整除 `n` 时分布不均；且 `rand()` 周期短、质量差。新代码统一用 `<random>`。
6. **需要固定小数位数**：不要生成 `double` 再硬截断。先生成整数再除 $10^k$，如 `uniform_int_distribution<int> dist(0, 99); double x = dist(gen) / 100.0;`。
7. **多线程共享引擎**：多个线程共用同一个引擎既有数据竞争问题，又会因为调度顺序不定而难以复现。每个线程应创建独立引擎（可用线程 ID 参与种子混合）。

## 对比与扩展

| 项目 | 旧式 `rand()` | 本知识点 `<random>` |
|---|---|---|
| 引擎 | 全局 `rand()`，实现定义 | 可显式选 `mt19937`、`mt19937_64` 等 |
| 种子 | `srand()`，全局生效 | 每个引擎独立持有种子 |
| 分布 | 只有均匀，靠取模变造 | 均匀/正态/伯努利/泊松等全家桶 |
| 取模偏差 | `rand()%n` 引入偏差 | 分布对象内部做无偏映射 |
| 随机打乱 | `random_shuffle`（C++17 已移除） | `std::shuffle` + 引擎对象 |

- **相关知识点**：随机化快速选择（`basic-quickselect-kth`）用随机 pivot 把最坏情况概率化，正是本库随机数的一个典型应用。
- **延伸**：`std::shuffle` 洗牌、`std::bernoulli_distribution` 伯努利分布（随机 01）、`mt19937_64` 64 位引擎、`std::seed_seq` 组合多来源种子（多个 `random_device` 值、线程 ID、时间戳混合）。
