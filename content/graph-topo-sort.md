## 算法原理

拓扑排序用于将有向无环图（DAG）的所有顶点排成一个线性序列，使得对每条有向边 $(u, v)$，$u$ 在序列中排在 $v$ 之前。Kahn 算法采用 BFS 风格的实现：反复取出当前入度为 $0$ 的顶点加入拓扑序列，并删除该顶点的所有出边（即将其后继节点的入度减一），当某个后继的入度降为 $0$ 时将其加入队列。

算法初始化时扫描所有顶点，将入度为 $0$ 的顶点一次性入队。随后进入主循环：每次从队列中取出一个顶点，遍历其所有出边，将目标顶点的入度减一。若入度降为 $0$，说明该顶点不再有未处理的前驱，将其入队并加入拓扑序列。这一过程持续直到队列为空。

拓扑排序的一个重要性质是判环能力：若图是 DAG，则所有 $n$ 个顶点都会被输出；若图中存在环，则环上顶点的入度永远无法降为 $0$（因为环中每个顶点至少有一条来自环内其他顶点的入边未被删除），最终输出的顶点数小于 $n$。代码中用 `cnt` 计数已输出顶点，初始为 $n$，每输出一个减一，结束时若 `cnt != 0` 则说明存在环。

## 核心公式

拓扑序约束（对每条边 $(u, v) \in E$）：
$$\text{pos}(u) < \text{pos}(v)$$

Kahn 算法的迭代规则（$d^-(v)$ 为入度）：
$$v \in Q \iff d^-(v) = 0 \text{ 且尚未输出}$$

取顶点 $u$ 出队后对其后继 $v$ 更新入度：
$$d^-(v) \leftarrow d^-(v) - 1, \quad \text{if } d^-(v) = 0 \text{ then } v \text{ 入队}$$

判环条件（输出顶点数 $C$）：
$$\text{有环} \iff C < n$$

## 逐行代码解析

```cpp
#include<bits/stdc++.h>
using namespace std;
vector<vector<int>> edges;   // 邻接表
int n, m;
int main()
{
	cin >> n >> m;
	edges.resize(n + 1);
	vector<int> q(n + 1, 0);   // q[i] = 顶点 i 的入度
	vector<int> ans;           // 拓扑序列
	int cnt = n;               // 剩余未输出顶点计数

	for(int i = 0; i < m; i++)
	{
		int a, b;
		cin >> a >> b;
		edges[a].emplace_back(b);   // 建边 a -> b
		q[b]++;                      // b 的入度 +1
	}

	queue<int> que;
	for(int i = 1; i <= n; i++)      // 初始化：入度为 0 的点入队
	{
		if(q[i] == 0)
		{
			que.emplace(i);
			ans.emplace_back(i);
			cnt--;
		}
	}

	while(!que.empty())
	{
		int i = que.front();
		que.pop();
		for(int idx : edges[i])      // 遍历 i 的所有出边
		{
			q[idx]--;                // 后继入度 -1（删除边 i->idx）
			if(q[idx] == 0)          // 入度降为 0，入队
			{
				que.emplace(idx);
				ans.emplace_back(idx);
				cnt--;
			}
		}
	}

	if(cnt) cout << "有环" << endl;  // 未输出全部顶点 -> 存在环
	else
	{
		for(int i = 0; i < n; i++) cout << ans[i] << " ";
	}
	return 0;
}
```

**关键解析：**

- `edges[a].emplace_back(b)` 与 `q[b]++`：建邻接表的同时统计入度，一遍读入完成图结构的构建。
- 初始化扫描 `for(i=1; i<=n; i++)`：将所有入度为 $0$ 的顶点一次性入队。这保证了多源并行推进——图中可以有多个无前驱的起点同时开始拓扑。
- `q[idx]--`：取出顶点 $i$ 后，删除其所有出边，等价于将后继的入度减一。这是"删除边"的隐式实现，无需真正修改邻接表。
- `if(q[idx] == 0)`：入度降为 $0$ 意味着该顶点的所有前驱已被输出，可以安全加入拓扑序列。
- `cnt` 判环：初始 `cnt = n`，每输出一个顶点 `cnt--`。若最终 `cnt != 0`（即 `cnt` 为真），说明有顶点未被输出，这些顶点处于环中（入度永远无法归零），因此存在环。
- `ans` 存储拓扑序：顶点入队的顺序即为一种合法的拓扑序。

## 复杂度分析

每个顶点最多入队、出队各一次，每次出队时遍历其所有出边。所有顶点的出边总数等于边数 $m$，因此总遍历次数为 $O(n + m)$。入度的维护（初始化扫描和每次减一）均为 $O(1)$ 操作。空间上邻接表存储 $m$ 条边、入度数组和队列各 $O(n)$，总空间复杂度为 $O(n + m)$。这是图遍历类算法的最优复杂度。

## 适用场景

任务调度与依赖关系排序（如编译顺序、课程先修关系）、判断有向图是否有环（判环）、DAG 上动态规划的预处理（按拓扑序处理保证状态依赖已就绪）、关键路径分析的前置步骤等。

## 常见陷阱与注意事项

1. **入度为 0 的初始化遗漏**：必须在建图后扫描所有顶点找出初始入度为 $0$ 的点。若遗漏则队列始终为空，所有顶点都不被输出，错误判定为有环。
2. **`cnt` 初值与判环逻辑**：`cnt` 初始为 $n$，每输出一个减一。判环时检查 `cnt != 0`（即 `cnt` 为真）。若误将 `cnt` 初始为 $0$ 且递增，则逻辑反转容易出错。
3. **拓扑序不唯一**：当多个顶点同时入度为 $0$ 时，入队顺序不同会导致不同的拓扑序。若题目要求字典序最小的拓扑序，应用优先队列（小根堆）代替普通队列。
4. **自环与重边**：自环 $(u, u)$ 使 $u$ 的入度永远无法归零，会被正确判定为环。重边会增加入度计数但不会影响正确性（多条边删除后入度才归零）。
5. **顶点编号不从 1 开始**：代码假设顶点编号为 $1 \sim n$。若编号从 $0$ 开始或离散，需调整循环范围或使用映射。
6. **队列 vs 栈**：用队列（FIFO）得到的是 BFS 风格拓扑序，用栈（LIFO）得到的是 DFS 风格拓扑序。两者都是合法拓扑序，但具体顺序不同。

## 对比与扩展

与基于 DFS 的拓扑排序（逆后序）相比，Kahn 算法（BFS 风格）更直观且天然支持判环，无需处理递归栈深度问题。DFS 拓扑排序利用"完成时间"的逆序，在需要同时求强连通分量时更方便（如 Tarjan 算法）。扩展方向包括：用优先队列求字典序最小/最大的拓扑序、在拓扑排序过程中同步进行 DAG 上 DP（如最长路、最短路、关键路径）、以及将 Kahn 算法推广到求最小拓扑序约束下的顶点染色等问题。
