## 算法原理

**一句话结论**：分层图的本质不是「真的建很多层图」，而是**把普通最短路的状态从 $u$ 扩展成 $(u,\ state)$**。普通最短路节点是城市 $u$；分层图最短路节点是状态 $(u,s)$（城市 $u$、资源/状态为 $s$），「层」只是状态 $s$ 的取值，「跨层边」只是状态转移。

**两种实现路线**：

- **显式建 $k+1$ 层图**：把状态 $(u,s)$ 展开成编号为 $u+s\cdot n$ 的大图，层内连原边、层间连跨层边，然后直接跑普通 Dijkstra。优点是直观；缺点是节点数 $n(k+1)$、边数约 $(k+1)m+km$，克隆边多、空间与常数都被放大。**适合理解模型和 $k$ 很小的题。**
- **隐式状态扩展（更通用）**：不建大图，邻接表只存原图，队列元素里直接携带状态 $s$，转移时再按状态变化入队。空间从 $O(k(n+m))$ 降到 $O(n+m+\text{队列大小})$，常数也更低——这是本笔记与代码采用的重点写法。

**例题模型（洛谷 P4568 [JLOI2011] 飞行路线；题号与出处来自思路笔记）**：$n$ 个城市、$m$ 条双向边有花费，从 $s$ 到 $t$，最多 $k$ 次机会让某条边花费变为 $0$，求最小总花费。关键资源是「还剩多少次免费机会」，状态 $(u,r)$ = 在城市 $u$、还剩 $r$ 次免费。初始 $(s,k)$，目标集合 $T=\{(t,r)\mid 0\le r\le k\}$（题目是「最多 $k$ 次」不是「恰好 $k$ 次」，到 $t$ 时剩多少次都行）。

**两类核心转移**（从 $(u,r)$ 出发）：

1. 不使用免费：走原边 $u\to v$ 花 $w$，$(u,r)\to(v,r)$；
2. 使用免费：走原边 $u\to v$ 花 $0$，$(u,r)\to(v,r-1)$（要求 $r>0$）。

原图双向边就建双向；跨层边**单向**——剩余次数只减不增，「到了下一层就回不来」。

**一维 `vis` 支配剪枝（本代码的关键优化）**：标准隐式写法用二维 `dist[u][r]`（空间 $O(nk+m)$）；本写法用一维 `vis[u]` = **城市 $u$ 已经出队过的状态中最大的剩余免费次数**（初始化为 $-1$）。弹出一个状态 $(u,r)$ 时，若 `vis[u] >= r` 就直接跳过：Dijkstra 按距离非降出队，之前出队的 $(u,r')$ 满足 $d'\le d$ 且 $r'\ge r$——花费不更多、免费机会不更少，从它出发能走出当前状态能走的任何后续且不更差，当前状态被**完全支配**。注意这不是通用优化：它依赖「剩余次数越多越优」的单调偏序；层表示「方向 / 是否持有股票 / 红绿灯状态」等没有这种简单全序时，必须用二维 `dist` 或显式建层。

**同距离时剩余次数大的先出**：比较器在 $w$ 相同时让 $k$ 大的先出，使 `vis[u]` 更早变大、增强剪枝减少无效出队。这是效率优化，不影响正确性。

**正确性证明要点**：

- 引理 1（首次出队即最短）：状态图边权非负，Dijkstra 按距离非降出队，$(u,r)$ 第一次弹出时不可能还有更短路径未被处理，否则那个更短状态会先出队。
- 引理 2（支配剪枝安全）：已出队 $(u,r')$，当前弹出 $(u,r)$，若 $r'\ge r$（且 Dijkstra 序保证 $d'\le d$），则 $(u,r)$ 被支配，跳过不影响最优解。
- 定理（提前终止正确）：目标集合是 $\{(t,r)\mid 0\le r\le k\}$，Dijkstra 第一次弹出其中任意状态时的距离就是到目标集合的最小距离，所以 `u == t` 直接返回 `d`；无须跑完整张状态图再遍历各 $r$ 取 $\min$。

## 核心公式 / 状态定义与转移方程

**状态定义**：

- 状态：$(u,r)$——城市 $u$、剩余 $r$ 次免费机会；初始 $(s,k)$，末状态任意 $(t,r)$；
- 距离定义：到状态 $(u,r)$ 的最小花费 $d(u,r)$；
- 支配量：`vis[u] = max{r' : (u,r') 已出队}`，初始 $-1$。

**转移方程**（对每条原边 $(u,v,w)$）：

$$(u,r)\xrightarrow{w}(v,r)\qquad\text{（不用免费）}$$

$$(u,r)\xrightarrow{0}(v,r-1)\quad(r>0)\qquad\text{（用免费，不加边权）}$$

**支配剪枝条件**（出队时）：若 `vis[u] >= r` 则丢弃当前状态；否则 `vis[u] = r` 后继续扩展。入队剪枝同理：新状态 $(v,r')$ 若 `vis[v] >= r'` 就不入队。

**目标判定**：`if (u == t) return d;`——「最多 $k$ 次」的版本；若题目是「恰好 $k$ 次」，目标只剩 $(t,0)$，需改判 `u == t && r == 0`。

**比较器语义**（`priority_queue` 的 cmp 与 `sort` 相反）：`a.w > b.w` 表示花费大的优先级低 → 花费小先出；`a.w == b.w` 时 `a.k < b.k` 表示剩余次数小的优先级低 → 剩余次数大先出。

**手算示例**：$n=3$，边 $(1,2,4)、(2,3,4)$，$s=1,\ t=3,\ k=1$。

- 弹出 $(1,1)$（$d=0$）：免费到 $(2,0)$（$d=0$）、正常到 $(2,1)$（$d=4$）。
- 弹出 $(2,0)$（$d=0$）：$r=0$ 不能再免费；正常到 $(3,0)$（$d=4$）。
- 弹出 $(2,1)$（$d=4$）：`vis[2]` 已从 0 升到 1 之前的状态顺序下继续扩展正常到 $(3,1)$（$d=8$）。
- 弹出 $(3,0)$（$d=4$）：$u=t$ → 返回 4。

本代码实测该例输出 4；同图 $k=0$ 输出 8。另验含直连边 $(1,3,7)$ 且 $k=1$ 时输出 0（免费掉直连边）。

## 逐行代码解析

代码拆成 3 个模块，按顺序拼接即完整程序。

### 模块 1 全局变量与状态结构体

```cpp
#include<bits/stdc++.h>
using namespace std;
vector<vector<pair<int,int>>> edges;
struct node
{
	long long w;
	int dist,k;
	node(){}
	node(long long a,int b,int c)
	{
		w = a;
		dist = b;
		k = c;
	}
};
struct cmp
{
	bool operator() (node& a,node& b)
	{
		if(a.w == b.w) return a.k < b.k;
		else return a.w > b.w;
	}
};
void init(int n)
{
	edges.assign(n + 1,vector<pair<int,int>>());
}


```

- `edges` 只存**原图**（隐式写法的关键：不为每层克隆边）；`init` 按 $n+1$ 个点分配。
- `node` 是队列状态：`w` 是当前花费（`long long`，边权累加可能超 int）、`dist` 是城市编号、`k` 是剩余免费次数。
- `cmp` 是小根堆比较器：花费小先出；同花费时剩余次数大先出（让 `vis` 更早变大、剪枝更狠，纯效率优化）。

### 模块 2 隐式状态扩展的 Dijkstra

```cpp
long long dij(int s,int t,int n,int k)
{
	priority_queue<node,vector<node>,cmp> que;
	vector<int> vis(n + 1,-1);
	que.emplace(0,s,k);
	while(!que.empty())
	{
		node tmp = que.top();
		que.pop();
		if(vis[tmp.dist] >= tmp.k) continue;
		vis[tmp.dist] = tmp.k;
		if(tmp.dist == t) return tmp.w;
		
		if(tmp.k >= 1)
		{
			for(pair<int,int>& p : edges[tmp.dist])
			{
				if(vis[p.first] >= tmp.k - 1) continue;
				que.emplace(tmp.w , p.first , tmp.k - 1);
			}
		}
		
		for(pair<int,int>& p : edges[tmp.dist])
		{
			if(vis[p.first] >= tmp.k) continue;
			que.emplace(tmp.w + p.second , p.first , tmp.k);
		}
	}
	return -1;
}

```

- `vis` 初始化为 $-1$：剩余次数可以是 0，若用 0 初始化会把「剩 0 次」的合法状态误判成已访问。
- 出队剪枝：`vis[tmp.dist] >= tmp.k` 就丢弃（被花费不更多、次数更多的旧状态支配）；否则 `vis[tmp.dist] = tmp.k`——因为只有 `tmp.k > vis[u]` 才走到这，`vis[u]` 严格单调递增，每个点最多出队 $k+1$ 次。
- `tmp.dist == t` 提前返回：P4568 是「最多 k 次」，任意剩余次数到达 $t$ 都算答案，且 Dijkstra 序保证这是目标集合的最小距离。
- 免费转移在前：注意入队的是 `tmp.w`（**不加边权**），次数减一；正常转移在后：`tmp.w + p.second`。
- 两处入队都带 `vis[p.first] >= 新次数` 的支配剪枝，与出队剪枝配合显著抑制队列膨胀。
- 队列清空仍未返回靶状态说明不可达，返回 $-1$。

## 复杂度分析

- **时间（最坏）**：状态数 $n(k+1)$；每个点出队次数受「`vis` 严格递增」限制至多 $k+1$ 次，每次出队把原邻接边扫两遍（免费 + 正常），边转移总量最坏 $O(km)$，堆操作最坏 $O(km\log(km))$。
- **空间**：邻接表 $O(n+m)$ + 一维 `vis` $O(n)$ + 队列 $Q$，其中 $Q$ 最坏 $O(km)$；整体 $O(n+m+Q)$。
- **三种写法对比**：

| 写法 | 空间 | 时间（最坏） | 特点 |
|---|---|---|---|
| 显式建 $k+1$ 层图 | $O(k(n+m))$ | $O(km\log(kn))$ | 直观，克隆边多、常数大 |
| 隐式 + 二维 `dist[u][r]` | $O(nk+m)$ | $O(km\log(kn))$ | 通用分层图写法 |
| 隐式 + 一维 `vis` 支配（本代码） | $O(n+m+Q)$ | $O(km\log(km))$，实际更小 | 依赖「次数越多越优」偏序的专项优化 |

## 适用场景

**分层图建模适用信号**：最短路（或 BFS/DP）的每个节点需要携带一个**有限取值的附加状态**——剩余免费次数、已用次数、方向、是否持有（股票/钥匙）、红绿灯相位、状态机所处的阶段等；层间转移对应「消耗资源 / 改变状态」的动作。P4568 免费边、P4822 边权减半（转移代价 $w/2$）、换乘加附加费等都是同一框架。

**隐式 vs 显式怎么选**：$k$ 大、图大 → 隐式状态扩展；$k$ 很小、想直接套普通 Dijkstra 板子 → 显式建层也可以；「越多越优」的单调偏序存在时 → 一维 `vis` 支配剪枝（本代码）；没有该偏序（方向层、买卖状态机）→ 二维 `dist` 或多维数组。

**不要用**：状态取值连续不可枚举时不叫分层（那是另一类问题）；层数极大（指数级）应转 DP 或状态压缩；边权非负前提下的 Dijkstra 正确性在分层图同样依赖「跨层边权非负」。

## 常见陷阱与注意事项

1. **`vis` 写成 `bool`**：同一点不同剩余次数是不同的状态，`bool` 会丢掉「剩余次数更多」的更优状态；`int` 存最大剩余次数才是对的。
2. **「最多」与「恰好」搞混**：P4568 是「最多 k 次」，`u == t` 即返回；「恰好 k 次」必须 `u == t && r == 0`。
3. **免费转移加了边权**：用免费时入队距离是 `d`，不是 `d + w`；只有正常转移才加 $w$。
4. **原图双向、跨层单向**：原边两个方向都建；免费跨层只从 $r$ 到 $r-1$，单向不可逆回。
5. **`priority_queue` 比较器写反**：它的 cmp 返回 true 表示「优先级低」；花费大的返回 true 才实现小根堆。同花费时次数大先出是效率优化，写反不影响正确性、只影响剪枝效率。
6. **入队剪枝方向写反**：正确是 `vis[v] >= nr` 时跳过（即仅当 `vis[v] < nr` 才入队）；写成 `>` 会漏掉可支配状态。
7. **`vis` 初始化成 0**：剩余次数可以为 0，必须初始化 $-1$，否则「剩 0 次」被误判已访问。
8. **距离用了 `int`**：边权累加可能超 int，`w` 用 `long long`。
9. **一维 `vis` 当成万能模板**：它依赖「剩余次数越多越优」的全序；对方向层 / 状态机层 / 多资源层，老老实实用二维 `dist` 或显式建层。
10. **提前终止条件的正确性**：`u == t` 返回的前提是目标集合含全部剩余次数；若某题要求「到达终点时必须剩恰好某次数」，提前返回条件要相应改。

## 对比与扩展

**显式建层 vs 隐式状态 vs 支配剪枝**：见「复杂度分析」的对比表——三者是同一模型的三种实现，取舍在空间与常数；学习顺序建议先懂显式（直观），再掌握隐式（通用），最后按题目偏序决定是否上支配剪枝。

**同类题迁移（题名来自思路笔记 §16，未独立核对题号）**：

| 题目 | 层是什么 | 转移 | 能否一维支配 |
|---|---|---|---|
| P2939 改造路 | 剩余免费次数 | 免费 → 边权 0 | 能 |
| P4822 冻结 | 已用次数 | 使用 → 边权减半 | 能 |
| P3831 回家的路 | 横向 / 纵向 | 换乘附加代价 | 否，用二维 dist |
| P1073 最优贸易 | 未买 / 持有 / 已卖 | 状态机转移 | 否，用多维 dist |
| P9549 路虽远 | 多维状态 | 按题目定义 | 否 |

**压常数（可选，思路 §15）**：同距离次数大先出（已做）、出队懒惰删除（已做）、邻接表换链式前向星、优先队列换 `pb_ds` 配对堆、快读快写——先保证正确性与剪枝，再考虑这些。

**预提案扩展（经你确认写入）**：① 免费次数上限其实是 $n-1$——任意简单路径至多 $n-1$ 条边，$k\ge n-1$ 时额外次数无意义，可以先 `k = min(k, n-1)` 再跑；② 若边权只有 $0/1$ 两种取值，可用双端队列 BFS（0 权插队头、1 权插队尾）替代 Dijkstra 常数更小，分层转移同样适用。
