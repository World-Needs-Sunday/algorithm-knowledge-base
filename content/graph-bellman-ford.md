## 算法原理

Bellman-Ford 算法是求解**含负权边**图中单源最短路的经典算法，基于动态规划思想：最短路最多经过 $n-1$ 条边（$n$ 为节点数），因此只需对所有边进行 $n-1$ 轮松弛操作即可收敛。

与 Dijkstra 的贪心策略不同，Bellman-Ford 不依赖"已确定节点不会被更新"这一假设。它反复遍历所有边，尝试通过每条边 $(u, v, w)$ 松弛 $A[v] = \min(A[v], A[u] + w)$。在非负权图中，Dijkstra 的贪心选择保证每轮确定一个节点，但负权边的存在可能使已"看似确定"的节点获得更短路径，因此贪心失效，必须用 Bellman-Ford 的全量松弛策略。

算法的核心定理：若图中不存在从源点可达的负环（总权为负的环），则最短路最多经过 $n-1$ 条边。证明：若最短路经过 $\geq n$ 条边，由鸽巢原理必存在重复节点，即存在环；最短路中的环权值必为 $0$（正权环可去掉，负权环则无最短路），因此去掉环后边数 $\leq n-1$。故 $n-1$ 轮松弛后所有最短路必然收敛。

本代码使用邻接表存储图，遍历所有节点的出边等价于遍历所有边。额外引入了**提前终止优化**：若某一轮松弛无任何更新（`tmp` 保持 `true`），说明所有距离已收敛，提前 `break`，避免剩余无意义的迭代轮次。

## 状态定义与转移方程

距离数组定义：

$$A[v] = \text{从源点 } s \text{ 到节点 } v \text{ 的当前最短距离估计值}$$

初始化：

$$A[s] = 0, \quad A[v] = +\infty \quad (v \neq s)$$

松弛转移方程（对每条边 $(u, v, w)$）：

$$A[v] = \min\big(A[v],\; A[u] + w\big)$$

迭代轮数：外层循环执行 $n-1$ 次（$n$ 为节点数），每轮对所有 $m$ 条边做一次松弛。

收敛性保证：若图中无负环，$n-1$ 轮后必有 $A[v] = \text{dist}(s, v)$（最短路长度）。

负环检测（扩展）：若第 $n$ 轮仍有松弛发生，则图中存在从源点可达的负环，此时最短路无定义（可以无限变短）。

提前终止条件：

$$\text{若第 } t \text{ 轮中所有边均未能松弛} \;\Rightarrow\; \forall v,\; A[v] \text{ 已收敛} \;\Rightarrow\; \text{break}$$

## 数据结构图示

```
输入示例：n=4, m=5, s=1（含负权有向图）

  边: 1→2(2)  1→3(6)  2→3(-3)  3→4(1)  4→2(-1)

  邻接表：
  edges[1] = {(2,2), (3,6)}
  edges[2] = {(3,-3)}
  edges[3] = {(4,1)}
  edges[4] = {(2,-1)}

  执行过程（n-1 = 3 轮松弛）：

  初始:  A = [INF, 0, INF, INF, INF]

  第 1 轮（遍历节点 1→4 的所有出边）:
    1→2: A[2] = min(INF, 0+2) = 2        ← 更新
    1→3: A[3] = min(INF, 0+6) = 6        ← 更新
    2→3: A[3] = min(6, 2+(-3)) = -1      ← 更新
    3→4: A[4] = min(INF, (-1)+1) = 0     ← 更新
    4→2: A[2] = min(2, 0+(-1)) = -1      ← 更新
    tmp=false → 继续

  第 2 轮:
    1→2: A[2] = min(-1, 0+2) = -1        无变化
    1→3: A[3] = min(-1, 0+6) = -1        无变化
    2→3: A[3] = min(-1, (-1)+(-3)) = -4  ← 更新
    3→4: A[4] = min(0, (-4)+1) = -3      ← 更新
    4→2: A[2] = min(-1, (-3)+(-1)) = -4  ← 更新
    tmp=false → 继续

  第 3 轮:
    1→2: 无变化, 1→3: 无变化
    2→3: A[3] = min(-4, (-4)+(-3)) = -7  ← 更新
    3→4: A[4] = min(-3, (-7)+1) = -6     ← 更新
    4→2: A[2] = min(-4, (-6)+(-1)) = -7  ← 更新
    tmp=false → 继续
    （此例含负环 2→3→4→2，总权 -3，实际不会收敛）

  正常无负环的情况：最多 n-1 轮收敛
```

## 核心操作详解

### 建图：邻接表

- **数据结构**：`vector<vector<pair<int,int>>> edges(n+1)`，`edges[u]` 存储 $u$ 的所有出边 `(v, w)`。
- **关键细节**：Bellman-Ford 需要遍历所有边，用邻接表存储时通过双重循环（外层遍历节点、内层遍历出边）实现。也可用边集数组 `struct Edge { int u, v, w; }` 存储，遍历更直接但需要额外结构。

### 松弛操作

- **条件**：`A[j.first] > A[i] + j.second`，即通过边 $i \to j$ 能否缩短 $A[v]$。
- **执行**：`A[j.first] = A[i] + j.second; tmp = false;`
- **关键细节**：松弛是 Bellman-Ford 的唯一操作，每轮对所有边做一次松弛尝试。`tmp` 标记本轮是否有更新，若全轮无更新则提前终止。松弛的顺序不影响最终结果（但影响收敛速度）。

### 提前终止优化

- **策略**：每轮开始前 `tmp = true`，若松弛发生则 `tmp = false`，轮末检查 `if(tmp) break`。
- **效果**：若图的最短路在第 $k$ 轮就收敛（$k < n-1$），则提前退出，避免 $n-1-k$ 轮无意义遍历。实际场景中多数图在远少于 $n-1$ 轮就收敛。
- **关键细节**：提前终止不改变最坏复杂度（仍为 $O(VE)$），但平均情况下显著加速。

### 负环检测（扩展用法）

- **方法**：在 $n-1$ 轮松弛后再执行第 $n$ 轮，若仍有松弛发生，则存在从源点可达的负环。
- **关键细节**：本代码未实现负环检测（仅执行 $n-1$ 轮），但扩展时只需在循环后加一轮检查。注意负环必须从源点可达才影响最短路定义。

## 逐行代码解析

```cpp
#include<bits/stdc++.h>
using namespace std;
const long long INF = INT_MAX;          // 用 long long 存距离，INF 取 INT_MAX
int main()
{
    ios::sync_with_stdio(false);        // 加速 I/O
    cin.tie(nullptr);cout.tie(nullptr);
    int n,m,s;
    cin >> n >> m >> s;                 // n 个节点，m 条边，源点 s

    vector<vector<pair<int,int>>> edges(n + 1);  // 邻接表
    for(int i = 1;i <= m;i++)
    {
        int u,v,w;
        cin >> u >> v >> w;
        edges[u].emplace_back(v,w);    // 有向边 u→v，权重 w
    }

    vector<long long> A(n + 1,INF);     // 距离数组，long long 防负权溢出
    A[s] = 0;                           // 源点距离为 0

    for(int t = 1;t < n;t++)           // n-1 轮松弛
    {
        bool tmp = true;                // 标记本轮是否有更新
        for(int i = 1;i <= n;i++)       // 遍历每个节点
        {
            for(pair<int,int> j : edges[i])  // 遍历 i 的所有出边
            {
                if(A[j.first] > A[i] + j.second)  // 松弛条件
                {
                    A[j.first] = A[i] + j.second;  // 更新距离
                    tmp = false;                    // 标记有更新
                }
            }
        }
        if(tmp) break;                 // 本轮无更新 → 已收敛，提前退出
    }

    for(int i = 1;i <= n;i++) cout << A[i] << ' ';  // 输出各点最短距离
    return 0;
}
```

**关键解析：**

- `const long long INF = INT_MAX`：距离数组用 `long long` 避免负权导致的溢出问题。但 `INF = INT_MAX` 本身仍有风险：当 `A[i] = INF` 且 `j.second` 为负数时，`A[i] + j.second` 可能溢出为正数，导致错误的松弛。更安全的做法是 `INF = 1e18` 或在松弛前加判断 `if(A[i] == INF) continue`（跳过未到达的节点）。
- `edges[u].emplace_back(v, w)`：构建有向图邻接表。若为无向图需同时添加 `edges[v].emplace_back(u, w)`。
- `for(int t = 1; t < n; t++)`：执行 $n-1$ 轮松弛。这是因为最短路最多经过 $n-1$ 条边（$n$ 个节点的简单路径），每轮松弛使最短路的边数上限 $+1$。
- `bool tmp = true`：提前终止标记。若本轮遍历所有边后 `tmp` 仍为 `true`，说明没有任何距离被更新，所有最短路已收敛，后续轮次不会有变化，`break` 退出。
- `A[j.first] > A[i] + j.second`：松弛判断。`j.first` 是终点 $v$，`j.second` 是边权 $w$。若当前 $A[v]$ 大于 $A[u] + w$，则通过 $u$ 到达 $v$ 更优。
- 输出 `A[i]`：若某节点不可达，输出 `INF`。

## 复杂度分析

- **时间复杂度**：外层 $n-1$ 轮，每轮遍历所有 $m$ 条边（通过遍历所有节点的出边实现），最坏时间复杂度为 $O(V \times E)$。提前终止优化使平均情况更优：若图在第 $k$ 轮收敛（$k \ll n-1$），实际时间为 $O(k \times E)$。
- **空间复杂度**：邻接表 $O(V + E)$，距离数组 $O(V)$，总空间复杂度为 $O(V + E)$。

与堆优化 Dijkstra（$O((V+E)\log V)$）相比，Bellman-Ford 在非负权图中明显更慢，但能处理 Dijkstra 无法应对的负权边。与 SPFA（Bellman-Ford 的队列优化版）相比，SPFA 均摊 $O(kE)$（$k$ 为平均入队次数，通常 $k \approx 2\sim3$），但最坏退化为 $O(VE)$，且 SPFA 容易被构造数据卡到最坏。

## 适用场景

含负权边的单源最短路问题、需要检测负环的场景（如差分约束系统求解、最短路可行性判断）、图规模不大且边权可能为负的通用最短路问题。常见于竞赛中的负权最短路模板题（如洛谷 P3385），也是差分约束系统建模后求解的标准工具。

## 常见陷阱与注意事项

1. **INF 溢出**：`INF = INT_MAX` 时，松弛 `A[i] + j.second` 可能溢出。当 `A[i] = INF` 且 `j.second < 0` 时，`INT_MAX + 负数` 可能溢出为正大值，导致错误松弛。解决方案：① 将 `INF` 设为 `1e18`（`long long` 范围内安全）；② 松弛前加 `if(A[i] == INF) continue` 跳过未到达节点。
2. **负环检测遗漏**：本代码仅执行 $n-1$ 轮松弛，不检测负环。若图中存在从源点可达的负环，输出的距离值无意义（会持续变小但未收敛）。需在第 $n$ 轮额外检查：若仍有松弛，则存在负环。
3. **无向图负权**：无向图中一条负权边等价于一个负权环（来回走），因此无向图中存在负权边即存在负环，Bellman-Ford 不会收敛。
4. **松弛顺序影响效率**：虽然松弛顺序不影响最终结果（$n-1$ 轮必收敛），但影响收敛速度。若按最短路顺序松弛，1 轮即可收敛；若逆序松弛，需 $n-1$ 轮。提前终止优化在多数情况下能自动处理这一问题。
5. **long long 与 int 混用**：`A` 是 `long long` 数组，但 `j.second`（边权）是 `int`。运算 `A[i] + j.second` 会隐式提升为 `long long`，安全。但若边权也用 `long long`，需确保输入读取正确。
6. **节点编号从 1 开始**：代码中节点编号为 $1 \sim n$，邻接表和距离数组大小为 $n+1$。若题目编号从 $0$ 开始，需调整循环范围和数组大小。

## 对比与扩展

与堆优化 Dijkstra（$O((V+E)\log V)$）相比，Bellman-Ford 能处理负权边但复杂度更高（$O(VE)$），适合图规模不大或含负权的场景。与 SPFA 相比，SPFA 是 Bellman-Ford 的队列优化版，只松弛"上轮有更新的节点的出边"，均摊更快但最坏复杂度相同且易被构造数据卡。与 Floyd（$O(V^3)$ 全源最短路）相比，Bellman-Ford 求单源最短路，规模互补。

扩展方向包括：① **负环检测**：在 $n-1$ 轮后加第 $n$ 轮检查，若有更新则存在负环；② **差分约束系统**：将不等式 $x_v - x_u \leq w$ 建为边 $u \to v$ 权 $w$，跑 Bellman-Ford 后 $A[v]$ 即为满足约束的解；③ **SPFA 优化**：用队列仅存储上轮更新的节点，避免全量遍历；④ **Bellman-Ford 的队列优化（SPFA）** 在实践中更常用，但需注意构造数据下的退化风险；⑤ **Johnson 全源最短路**：先用 Bellman-Ford 求各点到虚拟源点的最短路 $h(v)$（并检测负环），再用 $h$ 对边重赋权（$w'(u,v) = w(u,v) + h(u) - h(v) \geq 0$），最后对每个点跑 Dijkstra。
