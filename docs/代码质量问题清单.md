## 一、高危：疑似逻辑 bug（可能 WA / RE，建议优先看）

| 文件 | 问题 |
|---|---|
| `dp-linear-lis-binary` | `find()` 二分比较方向写反：`x >= B[mid]` 应为 `B[mid] >= x`，输入 `[4,1,3,2]` 会输出 1 而非 2。 |
| `ds-segtree-basic` | `init` 建树把叶子硬编码为 `tree[rt]=l`（下标），未从输入读初始数组——与 P3372 原题不符，真实数据会错。 |
| `ds-segtree-discretize` | `getleft()` 用 `lower_bound` 定位"包含值 i 的段"，i 落在间隙段内部时返回下一段（应 `upper_bound-1`）；`getleft/getright` 未被调用（死代码）；`insert` 用 `unsigned long long` 存 `lazy/tree`，无法表示负增量。 |
| `basic-two-pointer-cycle` | 只读入 `n-1` 条边，但"含环链"需要 `n` 条边闭合（off-by-one，应 `i <= n`）；`to[to[fast]]` 依赖 `to[0]=0` 且编号在 `[1,n]`。 |
| `dp-01bag-2d` | "传播行" `dp[i][j]=max(max(dp[i-1][j],dp[i][j-1]),dp[i][j])` 恒为 no-op（误导性死代码）；且 `v=0/m=0` 时会访问 `dp[-1][j]` / `dp[i][-1]` 越界。 |
| `dp-linear-lis-bit-count` | 用 `ans_cnt ? ans_cnt : 1` 判断"有无前驱"，当方案数恰为 `1e9+7` 的倍数时被误判为无前驱、方案数被重置为 1（应改用 `ans_len > 0`）。 |
| `math-quick-pow-basic` | `q==0` 时 `% q` 除零；`b==0` 时 `return 1` 未对 q 取模（`q==1` 时错）；底数 `a<0` 未归一化；指数 `b<0` 会死循环。 |
| `ds-dual-heap` | `n=0` 时对空堆 `L.top()` 未定义行为；`op==3` 的 `k` 未校验，`L.size()>k` 是无符号/有符号比较（负 k 转巨大无符号数）；注释"第k大"实为"第k小"。 |
| `str-minimal-representation` | `fn` 对 `k==n` 返回 `-1`、main 打印"有重复"，把正常输入当异常；`n=1` 与 `n≥2` 全相同串的边界处理不一致；末尾残留被注释的暴力做法。 |
| `graph-bellman-ford` | `INF=INT_MAX` 且松弛前未判 `A[i]==INF`，负权图里未到达节点被错误松弛；未做负环检测。 |
| `graph-spfa` | 同上：`INF=INT_MAX` 会被负权边错误松弛；负环检测缺失。 |
| `graph-dijkstra-heap` | `INF=INT_MAX`，`tmp.first+i.second` 会溢出回绕成负；距离用 `int` 会溢出（长路径应 `long long`）。 |
| `math-matrix-multiplication` | `n/m=0`（空矩阵）时 `A[1]`/`B[1]` 越界；`write_mat` 输出 `"NO mull"` 疑似拼写错误（应为 mul）；`ans=move(...)` 冗余。 |
| `ds-diff-1d` | 未校验 `l≤r`，`r=N+1` 时 `A[r+1]` 越界访问 `A[N+2]`。 |
| `ds-mo-team` | `query::operator<` 未加 `const`（换 `std::less`/libc++ 会编译失败）；`cnt` 只 `resize(k+1)` 却按 `A[i]` 访问，颜色 >k 越界。 |
| `ds-prefix-sum-2d` | 未校验 `x1≤x2/y1≤y2`；`N=0/M=0` 空矩阵时越界。 |
| `io-fast-io` | `read()` 用 `char` 存 `getchar()` 丢 EOF（输入耗尽死循环）；`write()` 对 `LLONG_MIN` 取负溢出。 |
| `ds-st-table-1` | `write()` 对 `INT_MIN` 取负溢出；`read()` 未判 EOF 死循环；`init` 只压入 `2^0..2^29`（注释声称 31 个，少 `2^30`）；`N=0` 时 `get_h(0)` 得负维越界。 |
| `ds-st-table-2` | `write()` 对 `INT_MIN` 取负溢出；`get_h` 对 0/负 `sz` 调 `__builtin_clz(0)` 是未定义行为；`read` 未判 EOF。 |
| `ds-stack-prefix-max` | `op==2/3` 空栈时 `--id` 变 `-1` 越界；`op==1` 未判 `id<nmax`；查询分支残留中文演示输出。 |
| `math-lcm-pair-count` | `i*i<=n` 当 n 接近 `LLONG_MAX` 时 `i*i` 溢出（应 `i<=n/i`）；`dfs` 对每个合法有序对都打印（残留调试输出，纯计数题应只返回 ans）。 |
| `math-quick-pow-highprecision` | `mul()` 对全零数组 `while(!tA[na-1]) --na` 会减到负越界；`num=q*log10(2)+1` 浮点求位数有 ±1 误差风险。 |
| `basic-digit-power-cycle-self` | `read()` `tmp.v[idx++]` 未判 `idx<105` 越界写；`add()` `ans/tmp` 固定 200 位无上限校验；`getchar()` 用 `char` 存丢 EOF；`main` `n-=1` 注释与实际不符。 |
| `str-kmp` | 模式串空 `m==0` 时访问 `b[0]` 越界；`kmp` 只向全局 `ans` 追加不清空（依赖调用方先 `clear`）。 |

## 二、边界缺失（n=1 / 空 / 0 / 极值）

| 文件 | 问题 |
|---|---|
| `ds-persistent-segtree-3919` | `n=1` 时递归 `init` 无 `l>r` 终止条件，无限递归越界；`nd.resize(n*4 + m*ceil(log2 n))` 在 `n=1` 时 `ceil(log2)=0` 预分配不足。 |
| `ds-persistent-segtree-template` | 同 `n=1` 无限递归；`nd.resize(n*40)` 是经验上界非严格上界；main 读入版本号 `v` 未校验，非法 `v` 会访问 `root[v]` 未初始化 → `nd[-1]` 越界。 |
| `dp-tree-01bag` | 链状树递归 `dfs` 栈溢出；根节点缺失时 `root=0` 误调 `dfs(0)`。 |
| `dp-tree-dance` | `n=0` 越界；`while(fa[root])` 依赖编号连续且恰一个无父节点；链状栈溢出。 |
| `dp-complete-bag` | 未处理重量 `0`（`dp[i][j-0]` 退化为自引用导致错误）。 |
| `dp-multi-bag-monotone` | `w==0` 时整段跳过、零重量物品价值漏算。 |
| `dp-group-bag` | 组号 `c` 未校验（≥101 越界）；组号从 0 开始会静默丢弃。 |
| `ds-prefix-sum-tree` / `ds-diff-tree` | 链状树递归 DFS 栈溢出；用 `fa[i]!=0` 判断已访问，依赖编号从 1 起。 |
| `ds-uf-basic` | 无按秩合并，`unity(1,2);unity(2,3);...` 把树退化成深链，`find` 递归深度 O(n) 有栈溢出风险。 |
| `ds-monoqueue-1d` | 未校验 `1≤k≤n`，`k>n` 或 `k≤0` 时逻辑破坏。 |
| `ds-uf-weighted-old` | 查询分支 `x==y` 时 `max-min-1` 得到 `-1` 而非 0（需确认题面是否保证 x≠y）。 |
| `ds-splay` | `getval(k)` 当 k 超出实际元素数时死循环；`del(v)` 未校验 v 存在；哨兵 `±0x3f3f3f3f` 与真实值域冲突风险。 |

## 六、命名 / 格式 / 性能 / 可移植性（低优先级，可顺手改）

- **有符号/无符号比较告警**：`int i` vs `size()` 比较，几乎遍布全库（如 `dp-linear-lcs-*`、`str-kmp`、`graph-johnson`、`str-minimal-representation` 等）。
- **输出末尾无换行 / 行尾多空格**：`dp-count-01bag`、`dp-linear-edit-distance`、`dp-linear-triangle`、`dp-multi-bag-binary`、`dp-tree-01bag`、`graph-topo-sort`（行尾多一个空格）、`ds-diff-2d`。
- **`cout << endl` 频繁刷新**：`str-hash`、`ds-monoqueue-1d`（建议 `'\n'`）。
- **命名易混**：`dp-count-01bag`（v/V/m）、`graph-spfa`（idx/id）、`dp-multi-bag-monotone`（W/w）、`graph-topo-sort`（入度数组叫 `q`）。
- **按值拷贝 pair**：`graph-bellman-ford`、`graph-spfa`、`graph-johnson`（应 `const auto&`）。
- **非标准/冗余**：`ds-monoqueue-2d` 的 `bits/stdc++.h`；`basic-random-mt19937` 的 `using namespace std` 与显式 `std::` 并存；`ds-st-table-2` 用 `vector<vector<int>>` 内存不连续。
- **低效**：`dp-multi-bag-binary` 内层循环 `j` 降到 1 而非重量，多遍历无用区间。
